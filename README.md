# 动手学系统科学

以人体与生命系统为主要贯穿案例，通过数学解释、可运行代码和计算实验，逐步学习系统科学的基础知识、理论、方法与研究实践。

项目仓库：[xuxu-wei/-](https://github.com/xuxu-wei/-)。

**Jupyter Notebook 是核心教学入口。网页在需要时提供核心概念的可视化解释和 playground，并链接到对应 Notebook。** 教学形式参考[《动手学深度学习》](https://zh.d2l.ai/)的文字、公式、图示与代码结合方式，课程内容按本项目的读者基础和学习目标重新组织。

## 面向谁

读者已经掌握基础 Python 和中学数学。无需预先修完微积分、线性代数、概率或控制理论；所需大学数学会在第一次使用前逐步建立，并在后续案例中反复练习。

默认采用中文正文，科学术语首次出现时标注英文。优先支持个人自学，基础实验面向普通电脑上的 CPU 环境设计。

## 学完能够做什么

1. 从人体、生命和群体系统现象中提出可研究的问题，明确系统边界、状态、输入、观测与建模假设。
2. 把问题写成数学模型和可运行程序，分析动态行为、数值误差、随机性及模型适用范围。
3. 从数据估计参数和状态，设计实验与反馈策略，比较模型和方法。
4. 独立完成建模、验证和解释，并逐步复现代表性的进阶研究方法。

核心方法需要讲清假设、关键推导、实现和适用范围；较难的证明进入拓展材料。模拟现象、数学结论和经验解释分别说明依据。

## 教材如何组织

全书采用统一的推荐阅读顺序，以三组案例反复深化：**物质积累、交换与清除；生理稳态与节律；细胞、个体与种群交互**。

| 内容阶段 | 包含的篇章 | 主要能力 |
|---|---|---|
| 基础体系 | 1. 看见系统；2. 系统随时间演化；3. 多变量相互作用；4. 非线性动态行为 | 描述系统，建立和分析动态模型 |
| 观测、辨识与调控 | 5. 随机性与信息；6. 从测量走向模型；7. 反馈、估计与控制；8. 目标、优化与约束 | 从不完整数据认识系统，并设计调控方法 |
| 复杂系统 | 9. 网络上的系统；10. 个体与集体现象；11. 临界变化与韧性 | 理解结构、个体交互和集体动态 |
| 融合与研究 | 12. 融合方法与研究实践 | 比较机制与学习方法，开展可复现研究 |

章级目标、先修知识、数学索引、案例和参考资料以[教材设计](docs/教材设计.md#curriculum)为准。这里的内容概览是长期建设范围，不代表相应教材已经完成。

## 各组成部分的职责

| 组成 | 职责 |
|---|---|
| Jupyter Notebook | 完整承载学习目标、问题引入、数学解释、推导、代码、实验、结果分析、练习与参考资料；一个小节是最小可运行单元 |
| 配套网页 | 根据章节需要提供可视化解释；有明确教学收益时增加 playground；与相应 Notebook 双向链接 |
| 轻量教学包 | 支持数据加载、统一绘图、重复实验和结果整理；核心教学算法在 Notebook 中显式展示 |
| 教学数据 | 提供已经通过验收的数据文件及教学所需的数据说明，可独立用于实验 |

Notebook 的核心教学内容保持自洽。网页围绕特定学习问题设计，是否需要网页、是否需要 playground，逐节判断。涉及计算的网页与 Notebook 对照验证模型、参数和结果；简化模型明确写出简化假设。

成熟科学计算库承担通用计算任务。轻量教学包的接口以普通数组、表格和绘图对象为主；具体安装方式随 M1 的实际交付公布。

## 教学项目与数据的独立性

教学项目只接收**验收通过的数据文件与教学使用说明**。数据制备软件在项目外独立管理，不作为教材的导入包、安装前提、运行服务或代码依赖。

教材不保存数据制备工具的名称、路径、配置、版本、生成种子或调用记录。需要记录的是数据本身的变量、单位、采样含义、允许的教学用途、质量检查结果，以及数据文件的一致性信息。

教学实验自身的随机操作应记录实验随机种子和运行环境；这属于实验复现要求。已接收的数据应能直接读取和验证，无需重新调用外部工具。涉及辨识和预测时，学习者可见数据与核验用答案分别管理。详细要求见[教学数据验收](docs/教材设计.md#data-contract)。
