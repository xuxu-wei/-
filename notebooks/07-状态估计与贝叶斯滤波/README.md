# 第7篇：状态估计与贝叶斯滤波

由已知模型和不完整观测恢复状态：先建立概率递推，再推导线性高斯精确解、非线性近似与离线平滑。核心算法在各节中逐步实现。

| 课节 | 学习内容 |
|---|---|
| [7.1.1 从有噪读数建立状态模型](01-状态空间与能观性/01-从有噪读数建立状态模型.ipynb) | 区分状态、过程噪声和测量噪声，明确估计器能使用的信息。 |
| [7.1.2 传感器与可区分的状态](01-状态空间与能观性/02-传感器与可区分的状态.ipynb) | 构造能观矩阵，解释秩、采样和噪声放大各自决定的问题。 |
| [7.2.1 从条件概率到预测与更新](02-贝叶斯递推与隐马尔可夫模型/01-从条件概率到预测与更新.ipynb) | 由边缘化和Bayes公式推导滤波，正确处理缺测和零证据。 |
| [7.2.2 隐状态序列与路径枚举](02-贝叶斯递推与隐马尔可夫模型/02-隐状态序列与路径枚举.ipynb) | 在隐马尔可夫模型中实现在线递推，并用全路径枚举核验。 |
| [7.3.1 多元高斯与条件分布](03-卡尔曼滤波/01-多元高斯与条件分布.ipynb) | 解释协方差几何，从分块高斯推导条件均值和条件协方差。 |
| [7.3.2 线性高斯预测与观测更新](03-卡尔曼滤波/02-线性高斯预测与观测更新.ipynb) | 从条件高斯推导Kalman递推，检验时刻约定与缺测分支。 |
| [7.3.3 创新、误差与区间覆盖](03-卡尔曼滤波/03-创新、误差与区间覆盖.ipynb) | 用独立重复检验创新和区间覆盖，区分误差与不确定性校准。 |
| [7.4.1 局部线性化与扩展滤波](04-非线性高斯滤波/01-局部线性化与扩展滤波.ipynb) | 推导EKF并保留雅可比求值位置，解释局部近似失效。 |
| [7.4.2 无迹变换与后验形状](04-非线性高斯滤波/02-无迹变换与后验形状.ipynb) | 构造确定性采样点，比较UKF矩近似、EKF与低维积分后验。 |
| [7.5.1 重要性采样与稳定权重](05-粒子滤波/01-重要性采样与稳定权重.ipynb) | 从期望积分推导重要性权重，解释自归一化与提议支持条件。 |
| [7.5.2 粒子传播、退化与重采样](05-粒子滤波/02-粒子传播、退化与重采样.ipynb) | 实现自助粒子滤波，比较ESS、样本贫化及固定预算下的重复误差。 |
| [7.6.1 前向后向与未来信息](06-平滑与缺测处理/01-前向后向与未来信息.ipynb) | 从联合路径推导有限状态平滑，并保持在线和离线的信息边界。 |
| [7.6.2 RTS平滑与连续缺测](06-平滑与缺测处理/02-RTS平滑与连续缺测.ipynb) | 推导线性高斯后向平滑，检验末端一致性、缺测和联合条件参照。 |
| [篇末综合 部分观测下的状态恢复](07-篇末综合/01-部分观测下的状态恢复.ipynb) | 建立估计问题，计算滤波与平滑，诊断近似和观测失效。 |

本篇13节加篇末综合，共63题；普通节4题，关键算法节5题，综合8题分四层计100分。

所有参数与人工观测仅用于方法教学；状态真值只进入核验。安装与打开方式见[项目说明](../../README.md#run-m1)，篇章设计见[第7篇大纲](../../docs/07-状态估计与贝叶斯滤波.md)。
