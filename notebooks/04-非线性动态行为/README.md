# 第 4 篇：非线性动态行为

按顺序在 Notebook 中学习，每节末尾都有对应的实际答题入口。

| 小节 | Notebook | 学习重点 |
|---|---|---|
| 4.1.1 | [从三个平衡进入多稳态](01-多稳态与吸引域/01-从三个平衡进入多稳态.ipynb) | 能用一维流向和局部导数区分平衡的稳定性，推导开关模型的解析解，并说明精确停在平衡与抵抗扰动的区别。 |
| 4.1.2 | [吸引域扰动与有限时间扫描](01-多稳态与吸引域/02-吸引域扰动与有限时间扫描.ipynb) | 能区分初始扰动和持续偏置，用显式中点法扫描初值，保留有限时间未决标签，并用解析解检查数值误差。 |
| 4.2.1 | [阻尼受迫与自维持振荡](02-自维持振荡与极限环/01-阻尼受迫与自维持振荡.ipynb) | 能通过方程与输入对照区分阻尼、受迫和自维持振荡，从二维方程推导径向运动，并解释稳定极限环与精确原点的例外。 |
| 4.2.2 | [周期振幅与相位的测量](02-自维持振荡与极限环/02-周期振幅与相位的测量.ipynb) | 能明确暂态窗口、峰值和过零规则，计算振幅与周期，分开采样误差、动力学暂态和扰动后的相位差。 |
| 4.3.1 | [平衡分支折叠与滞后](03-分岔与参数变化/01-平衡分支折叠与滞后.ipynb) | 能从平衡方程和零导数求折叠点，区分解析分支与有限扫描，比较接续/重启及正反方向，并保留转变区间的分辨率。 |
| 4.3.2 | [从平衡到周期的Hopf转变](03-分岔与参数变化/02-从平衡到周期的Hopf转变.ipynb) | 能连接原点特征值、径向方程与周期分支，解释超临界 Hopf 转变及临界慢衰减，区分长期半径和单点观测。 |
| 4.4.1 | [离散映射的不动点与周期](04-混沌与可预测范围/01-离散映射的不动点与周期.ipynb) | 能区分代次映射和微分方程，证明 logistic 映射的区间保持性，用扰动倍率判断不动点稳定，并识别周期二行为。 |
| 4.4.2 | [邻近轨迹与预测期限](04-混沌与可预测范围/02-邻近轨迹与预测期限.ipynb) | 能量化两个初值的逐代距离，按明确阈值报告有限预测期限，解释增长、饱和和精度合并，并区分三类误差来源。 |
| 4.4.3 | [有限时间增长率与算术精度](04-混沌与可预测范围/03-有限时间增长率与算术精度.ipynb) | 能推导切向扰动的有限时间对数增长率，处理零导数，比较 float 与 Decimal 轨迹，并把有限证据与长期混沌性质分开。 |
| 4.5.1 | [候选函数与局部稳定性证明](05-用%20Lyapunov%20函数分析稳定性/01-候选函数与局部稳定性证明.ipynb) | 能从正定性和沿轨迹导数构造稳定性论证，解释子水平集与局部区域，区分稳定、渐近稳定和全局结论。 |
| 4.5.2 | [非严格衰减与不能省略的条件](05-用%20Lyapunov%20函数分析稳定性/02-非严格衰减与不能省略的条件.ipynb) | 能用二维反例区分不增与吸引，分析零导数集合中的运动，并为新区域写出可检查的充分不等式。 |
| 篇末综合 | [非线性行为与证据边界](06-篇末综合/01-非线性行为与证据边界.ipynb) | 能把模型假设、数值协议和结论条件连接起来，独立核对吸引去向、周期、精度敏感性和区域稳定性，并指出证据尚未覆盖的范围。 |
