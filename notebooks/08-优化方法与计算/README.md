# 第8篇：优化方法与计算

从目标与尺度出发，显式实现迭代、正则化和约束优化，并用独立证据检查结果。

| 课节 | 学习内容 |
|---|---|
| [8.1.1 从拟合误差到二次目标](01-目标函数与优化几何/01-从拟合误差到二次目标.ipynb) | 把物质收支拟合写成有尺度的目标，推导值、梯度与Hessian。 |
| [8.1.2 曲率凸性与局部极值](01-目标函数与优化几何/02-曲率凸性与局部极值.ipynb) | 用方向曲率区分凸性、严格极小与驻点，解释非凸反例。 |
| [8.2.1 梯度下降的步长与条件数](02-梯度、曲率与迭代算法/01-梯度下降的步长与条件数.ipynb) | 推导二次目标上的步长范围，解释振荡、病态与变量缩放。 |
| [8.2.2 牛顿方向与非凸曲率](02-梯度、曲率与迭代算法/02-牛顿方向与非凸曲率.ipynb) | 从二阶近似推导牛顿方向，用反例判断方向是否下降。 |
| [8.2.3 回溯与可信的停止条件](02-梯度、曲率与迭代算法/03-回溯与可信的停止条件.ipynb) | 实现Armijo回溯，区分步长接受、残差达标与预算耗尽。 |
| [8.3.1 岭回归与参数收缩](03-正则化与稀疏优化/01-岭回归与参数收缩.ipynb) | 推导二范数惩罚解，解释共线性、正则强度与不唯一。 |
| [8.3.2 软阈值与近端梯度](03-正则化与稀疏优化/02-软阈值与近端梯度.ipynb) | 由绝对值惩罚推导软阈值，显式实现近端梯度并核验边界。 |
| [8.3.3 缩放选参与独立预测](03-正则化与稀疏优化/03-缩放选参与独立预测.ipynb) | 只从训练集估计预处理量，只用验证集选参并保留最终评估。 |
| [8.4.1 约束乘子与最优性条件](04-约束与最优性条件/01-约束乘子与最优性条件.ipynb) | 推导等式及不等式的乘子条件，区分必要性、充分性与残差。 |
| [8.4.2 活跃集与可行性核验](04-约束与最优性条件/02-活跃集与可行性核验.ipynb) | 枚举小型二次规划的活跃集，区分可行最优、不可行与数值失败。 |
| [篇末综合 拟合、稀疏与约束优化](05-篇末综合/01-拟合稀疏与约束优化.ipynb) | 在统一尺度与信息边界下构造目标、实现下降与稀疏拟合，并核验约束解。 |

十节正文加篇末综合，共50题。普通节4题，关键节5题，综合8题分四层计100分。

实验使用明示的人工观测与无量纲参数，只用于方法学习；模型结论受目标、尺度、假设与信息边界限定。

运行与打开方式见[项目说明](../../README.md#run-m1)，篇章设计见[第8篇大纲](../../docs/08-优化方法与计算.md)。
