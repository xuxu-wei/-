# 第 5 篇：随机性与信息

按顺序在 Notebook 中学习，每节末尾都有对应的实际答题入口。

| 小节 | Notebook | 学习重点 |
|---|---|---|
| 5.1.1 | [事件分布与一次实现](01-从重复实验建立概率/01-事件分布与一次实现.ipynb) | 能区分事件、随机变量、分布和一次实现；用总概率与曲线下面积检查离散概率和连续密度，解释测量舍入。 |
| 5.1.2 | [把抽样变成可比较的重复实验](01-从重复实验建立概率/02-把抽样变成可比较的重复实验.ipynb) | 能区分一组样本、重复实验和随机种子；比较样本量改变后的频率波动，区分组平均与合并频率。 |
| 5.2.1 | [用期望与方差描述随机量](02-期望、方差、协方差与噪声/01-用期望与方差描述随机量.ipynb) | 能从离散分布推导期望与方差，区分描述性方差与总体估计；解释高斯误差、标准差和均值波动的单位。 |
| 5.2.2 | [联合变化与协方差](02-期望、方差、协方差与噪声/02-联合变化与协方差.ipynb) | 能从联合分布得到边缘分布，展开和的方差并计算协方差；用反例区分不相关与独立，识别共享误差。 |
| 5.2.3 | [过程测量与个体差异](02-期望、方差、协方差与噪声/03-过程测量与个体差异.ipynb) | 能辨认三类变异进入模型的位置；推导独立扰动下的状态与观测方差，限定方差极限和经验分位带的含义。 |
| 5.3.1 | [由条件概率推导贝叶斯更新](03-条件概率与贝叶斯更新/01-由条件概率推导贝叶斯更新.ipynb) | 能从联合表计算条件概率，区分先验、似然、证据概率与后验；处理零证据和反复使用同一份数据的条件独立边界。 |
| 5.3.2 | [固定未知量的高斯更新](03-条件概率与贝叶斯更新/02-固定未知量的高斯更新.ipynb) | 能通过平方配方推导高斯均值与方差更新，解释精度相加、先验敏感性和独立性；区分知识更新与状态演化。 |
| 5.4.1 | [状态路径与概率分布的两种推进](04-随机过程与马尔可夫模型/01-状态路径与概率分布的两种推进.ipynb) | 能写出马尔可夫与时间齐次假设，按行向量传播分布，用指定均匀数抽取路径，并对照多路径频率的不确定性。 |
| 5.4.2 | [不变分布与长期收敛的条件](04-随机过程与马尔可夫模型/02-不变分布与长期收敛的条件.ipynb) | 能求两态不变分布，区分存在、唯一与逐时刻收敛；用周期链和多吸收态解释不可约、非周期等条件。 |
| 5.4.3 | [随机游走中的漂移与扩散](04-随机过程与马尔可夫模型/03-随机游走中的漂移与扩散.ipynb) | 能推导独立二值步长的均值与方差，比较有偏与无偏游走，说明位置相关性、边界和连续极限的适用范围。 |
| 5.5.1 | [熵与互信息的离散定义](05-熵、互信息与测量价值/01-熵与互信息的离散定义.ipynb) | 能推导离散熵、条件熵与互信息，处理零概率和对数单位；用独立、复制、翻转通道检查信息含义及因果边界。 |
| 5.5.2 | [有限样本分箱与信息偏差](05-熵、互信息与测量价值/02-有限样本分箱与信息偏差.ipynb) | 能按明确边界构造联合计数、比较嵌套分箱的离散信息量；用重复独立样本识别插件偏差，限定观测价值结论。 |
| 篇末综合 | [噪声概率更新与信息的综合实验](06-篇末综合/01-噪声概率更新与信息的综合实验.ipynb) | 能在统一细胞观测案例中组织重复、分开噪声贡献、更新概率与传播分布，并依据有限样本限制信息量结论。 |
