# 制作样章：体内物质的积累与清除

本目录独立于正式教材，用于参考内容与样式；可复制改编，正式章节完成后删除。

从基础 Python 和中学数学开始，按顺序学习下面六节。概念依赖前一节，代码可分别从全新内核独立执行。

| 顺序 | Notebook | 本节完成后能够做什么 |
|---|---|---|
| 1 | [系统边界、变量与单位](01-boundaries-units.ipynb) | 区分存量与流量，用单位与收支核对结果 |
| 2 | [用 Python 表达积累与清除](02-accumulation-clearance.ipynb) | 写出显式更新循环，检查前三步与收支 |
| 3 | [平衡、负反馈与参数变化](03-equilibrium-feedback.ipynb) | 分别解释平衡位置与靠近速度，处理零清除 |
| 4 | [从变化率进入微分方程](04-rates-ode.ipynb) | 联系导数、积分、初值问题与解析解 |
| 5 | [检查数值模拟](05-numerical-checks.ipynb) | 对照解析解，区分精度、稳定性与非负性 |
| 6 | [独立迁移实验](06-transfer-experiment.ipynb) | 修改输入时序，计算轨迹并核验误差 |

先按[项目运行说明](../../../README.md#run-m1)安装环境，再在系统默认 IDE 中打开第一节，并选择项目虚拟环境的 Python 内核。Notebook 保存图形与输出，可先阅读，再重启内核运行；也可自行使用 JupyterLab。

[概念可视化](http://127.0.0.1:8000/samples/accumulation-clearance/explore/)集中解释“流量怎样改变存量”和“步长怎样扭曲动态”。按[学习指南](../../../docs/学习指南.md)启动本地程序后使用；页面按钮在默认 IDE 中打开相应 Notebook 原文件。“从变化率进入微分方程”和“独立迁移实验” 的必要图示与完整实验均在 Notebook 中。

单位 U 与 T、所有参数均用于理想模型教学。本单元不需要外部数据、浏览器计算服务或 GPU。核心模型与数值算法直接展示在 Notebook 内，`systems_science` 仅统一绘图和结果表格。

学习时间尚未经过目标读者试学估算；执行环境、实际耗时和检查范围见 [M1 验收记录](../../../docs/M1验收.md)。

每节 3—5 题，共 14 道选择题和 8 道 Python 计算题。Notebook 保留完整题面，每题链接到[交互练习页](http://127.0.0.1:8000/samples/accumulation-clearance/practice/)中的对应题目；提交后获得逐项解析或计算反馈。也可阅读[逐题核验提示](../../../docs/M1练习核验.md)复习。样例运行不计完整通过，计算与作答记录都保存在本机。
