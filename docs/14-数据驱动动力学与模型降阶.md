# 第 14 篇：数据驱动动力学与模型降阶

本文为新版篇章大纲，正式教学内容待按 [M15](../ROADMAP.md#milestone-m15) 交付。总目录、数学和参考编号见[教材设计](教材设计.md#part-14)。前篇：[13-临界变化与韧性](13-临界变化与韧性.md)。后篇：[15-可微分建模与机制融合](15-可微分建模与机制融合.md)。

教学、术语与题型规则统一引用[教材规范](教材设计.md#lesson-standard)和[练习设计](教材设计.md#assessment-design)；网页与本机执行分别见[网页规范](网页设计规范.md)及[判题设计](交互练习与判题系统设计.md)。E1—E3 是章级出题方向，正式每节题量按总纲实施，核心实验是教学演示，不增加报告或自由文本提交。

## 1. 定位、先修与学习目标

从已验证的机制模型和观测进入低秩表示、线性提升和稀疏方程发现。每种方法先手工实现低维核心步骤，再用传统线性模型和完整模型对照；拟合好不能直接证明找到了真实机制。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 构造低秩表示 | 解释奇异值和能量截断，比较投影误差与动态误差 | 14.1 的解析矩阵和完整模型对照 |
| T2 识别有限表示的动态 | 实现动态模态分解（dynamic mode decomposition，DMD）与有限字典提升，解释表示和外推条件 | 14.2—14.3 的精确线性例和字典失配 |
| T3 发现稀疏候选方程 | 构造字典、显式求解并验证稀疏模型 | 14.4 的已知机制、独立初值和阈值路径 |
| T4 检查结构与迁移 | 设计含噪、分布外和结构保持对照，区分发现与拟合 | 14.5 的守恒、正性和长期预测检查 |

## 2. 各章内容、实验与练习

### 14.1 低秩分解与模型降阶

- **直接先修**：3.2、6.4、8.3；数学：数06、数07、数17、数40。
- **教学目标**：从快照矩阵构造低秩表示，推导截断误差并区分重建精度与动态预测精度。
- **内容顺序**：①建立快照、中心化与变量尺度约定，推导奇异值分解（singular value decomposition，SVD）及伪逆；②由投影误差引入本征正交分解（proper orthogonal decomposition，POD）与截断秩；③将机制方程投影到低维坐标，检查初值映射、守恒和截断影响。
- **核心实验**：复用多室交换与反应扩散的小规模快照，只在训练轨迹上求基；比较低秩重建、投影动力学及新初值预测。
- **练习 E1（选择题）**：根据奇异值与训练重建误差选择秩及能支持的结论，辨认保留方差多必然保留关键动态。
- **练习 E2（计算题）**：输入快照矩阵与截断秩，返回投影重建、投影矩阵和残差范数；按子空间与残差判定，不强求基向量符号。
- **练习 E3（选择题）**：比较用全部轨迹求基与只用训练轨迹求基的协议，识别泄漏及罕见动态被丢失的风险。
- **核验与反馈**：截断误差与舍弃奇异值平方和对照；正交性及秩零/满秩边界核验。中心化均值来自训练集，降阶不自动保证非负性或守恒。
- **编写参考**：R04、R28（资料与主题对应见本篇末表）。


### 14.2 动态模态分解

- **直接先修**：14.1、6.5；数学：数17、数40。
- **教学目标**：由配对快照拟合线性传播，计算动态模态分解并验证离散与连续时间解释。
- **内容顺序**：①从最小二乘传播矩阵进入动态模态分解（dynamic mode decomposition，DMD）；②在截断子空间计算特征值与模态，解释重建和滚动预测；③讨论采样间隔、模态混叠及对数分支，区分一步误差和长期行为。
- **核心实验**：用已知二室线性模型验证精确情形，再对非线性振子局部数据拟合；按完整轨迹划分训练与评估。
- **练习 E1（选择题）**：选择离散特征值与衰减/振荡的正确关系，识别忽略采样间隔或对数分支。
- **练习 E2（计算题）**：输入配对快照、截断秩与起点，返回题定伪逆规则下的传播矩阵及有限步预测；重复奇异值按投影等价判定。
- **练习 E3（选择题）**：根据一步拟合好但长期发散的结果，选择可支持的模型结论和必要检查。
- **核验与反馈**：完整秩线性例子与已知传播矩阵、独立轨迹对照；测试零奇异值和秩不足，不用训练重建替代预测验证。
- **编写参考**：R28、R17（资料与主题对应见本篇末表）。


### 14.3 Koopman 表示与有限字典

- **直接先修**：14.2；数学：数07、数17、数19、数26、数40。
- **教学目标**：理解作用于观测函数的线性传播，实现有限字典近似并解释闭合误差。
- **内容顺序**：①从非线性状态更新引入 Koopman 算子（Koopman operator），先讲函数与算子的必要定义；②构造扩展动态模态分解（extended dynamic mode decomposition，EDMD）的字典与数据矩阵；③比较字典、投影、正则化（regularization）与状态重建，限定有限字典的闭合条件。
- **核心实验**：用可精确闭合的小型三角多项式系统核验，再对饱和清除模型改变字典；保持训练样本和正则选择协议一致。
- **练习 E1（选择题）**：选择观测空间线性与原状态非线性的正确关系，辨认有限字典一定精确闭合。
- **练习 E2（计算题）**：输入固定字典特征快照、正则系数和读出矩阵，返回字典传播与状态预测；固定矩阵左右作用约定。
- **练习 E3（选择题）**：根据字典扩大后训练误差与外推误差的分离，选择有效复杂度判断。
- **核验与反馈**：精确闭合系统用代数递推核验；一般系统报告投影与重建误差，真值方程不用于选择最终字典。
- **编写参考**：R17、R28（资料与主题对应见本篇末表）。


### 14.4 稀疏动力学辨识

- **直接先修**：14.3、8.3、4.6；数学：数17、数34、数40、数44。
- **教学目标**：构造候选机制字典并实施稀疏回归，区分方程拟合、结构恢复与可辨识性。
- **内容顺序**：①从导数或离散增量的回归引入稀疏动力学辨识（sparse identification of nonlinear dynamics，SINDy）；②显式实现顺序阈值最小二乘，公开阈值、列缩放和停止规则；③比较候选项共线性、导数估计与观测噪声，使用完整轨迹留出验证。
- **核心实验**：先用带明确导数观测的理想种群模型核验，再从含噪轨迹估计导数；补充复用 4.6 的 Lorenz 基准。相同候选字典下比较系数、结构、独立短时预测及限定窗口的长期几何，训练与评估使用不同完整轨迹。
- **练习 E1（选择题）**：选择候选字典、阈值与单位缩放的正确处理，辨认稀疏方程自动等同于真实机制。
- **练习 E2（计算题）**：输入题定字典、导数观测、阈值和迭代上限，返回系数及活动列；空支持与秩不足按公开规则处理。
- **练习 E3（选择题）**：根据多组近等价方程与留出轨迹，判断可辨识范围及需要追加的激励。
- **核验与反馈**：无噪可辨识小例子与已知系数核验；含噪例子分别检查导数误差、短时预测和长期结构，不以混沌轨迹长时逐点失配单独判定方程错误。标准化与阈值只由训练/验证集决定，4.6 的 Lorenz 实验为课程基准，原论文复现留到第 17 篇。
- **编写参考**：R18、R28（资料与主题对应见本篇末表）。


### 14.5 噪声、外推与结构保持

- **直接先修**：14.4、13.4；数学：数17、数24、数34、数40。
- **教学目标**：在共同协议下比较降阶与动力学发现，检查守恒、非负性、外推和噪声敏感性。
- **内容顺序**：①对齐物理变量、采样、数据量和预测时域，固定结构误差与数值误差的分项指标；②由多室交换的列和及符号条件检查候选线性模型的守恒与非负性；③在新初值、新输入和噪声变化下评价预测与结构，保留失败轨迹。
- **核心实验**：机制模型、低秩投影、有限字典与稀疏模型共享一个交换/清除案例；分别改变训练范围和观测通道，报告预算和约束残差。
- **练习 E1（选择题）**：从模型矩阵与变量定义判断哪些守恒条件适用，区分物质量与浓度坐标。
- **练习 E2（计算题）**：输入多模型配对轨迹、真实输入输出和题定守恒权重，返回预测误差、收支残差、非负性违反与失败数。
- **练习 E3（选择题）**：根据相同预算下的噪声和外推实验，选择成立的表示能力与机制结论。
- **核验与反馈**：纯交换极限用总量恒定核验；解析线性基线检查指标。低秩重建、一步误差与长期可用性分别报告，失败不作为缺失样本丢弃。
- **编写参考**：R28、R10（资料与主题对应见本篇末表）。


## 3. 篇末综合任务：交换系统的降阶与动力学发现

同一人工多室交换系统固定观测位置、训练轨迹和独立初值，比较完整模型、线性辨识、低秩和稀疏候选；参数真值只用于核验。

以下为待交付题组设计，统一梯度、分值、等级及首次/练习成绩规则见[篇末分层评分](教材设计.md#capstone-assessment)。章内题不因综合题组调整而改变。

| 层次 | 子题与分值 | 形式 | 主要计分目标 | 核验与反馈重点 |
|---|---|---|---|---|
| 1 基础辨析 | 1. 投影误差与模型误差（10 分） | 选择 | T1 | 根据奇异值和动态证据判断截断维数，排除能量高即预测准。 |
| 1 基础辨析 | 2. 线性提升能保证什么（10 分） | 选择 | T2 | 区分原状态线性、观测空间线性与有限字典近似。 |
| 2 方法应用 | 3. 低秩投影与重建（15 分） | Python | T1 | 给定小矩阵、秩和符号约定，按投影矩阵和误差判等价子空间。 |
| 2 方法应用 | 4. 动态模态与字典回归（15 分） | Python | T2 | 输入快照和已定义字典，返回提升预测及残差；精确线性例独立核验。 |
| 3 综合验证 | 5. 稀疏阈值辨识（15 分） | Python | T3 | 给定归一化字典、导数、阈值和迭代规则，返回系数与独立预测。 |
| 3 综合验证 | 6. 结构与外推评估（15 分） | Python | T4 | 给出真值隔离的评估轨迹，汇总守恒误差、正性、外推和失败。 |
| 4 迁移挑战 | 7. 噪声下的方程选择（10 分） | 选择 | T3 | 对比导数估计和多个阈值的结果，判断激励不足与伪稀疏性。 |
| 4 迁移挑战 | 8. 改变输入后的结论边界（10 分） | 选择 | T4 | 新输入或未观测状态下识别模型表示限制，不以训练残差代替外推依据。 |

每题提供独立且完整的输入，不读取其他子题的作答；选择题提供逐项解释，计算题以公开契约、容差及独立参考判定。随机算法提供固定随机数、增量、索引或已生成结果，重复实验效果用于教材解释，不按一次随机效果判分。复习入口按本篇 T1—T4 对应章节建立，正式身份和版本随题库发布。

## 4. 教学资源与衔接

- **网页安排**：14.1 奇异值与截断重建；14.2 模态和预测；14.3 字典变化；14.4 稀疏路径；14.5 噪声与守恒残差。训练/验证边界在页面标明。
- **数据与案例**：沿用总纲 A（物质交换与清除）、B（稳态与节律）、C（个体与种群）三组生命系统案例；课程生成观测与核验状态/参数分离，同一方法比较使用相同观测、数据划分与预算。
- **独立验证**：解析低秩矩阵、精确线性快照、已知生成方程和留出初值分别核验；计算题对奇异向量符号、重根和等价模型用不变量判定。
- **出口**：为第 15 篇提供传统数据驱动基线，为第 17 篇的稀疏辨识原论文复现提供可检查实现；本篇课程改编不提前宣称复现原论文。
