# 第 9 篇：概率建模与近似推断

本文为新版篇章大纲，正式教学内容待按 [M10](../ROADMAP.md#milestone-m10) 交付。总目录、数学和参考编号见[教材设计](教材设计.md#part-09)。前篇：[08-优化方法与计算](08-优化方法与计算.md)。后篇：[10-反馈与最优控制](10-反馈与最优控制.md)。

教学、术语与题型规则统一引用[教材规范](教材设计.md#lesson-standard)和[练习设计](教材设计.md#assessment-design)；网页与本机执行分别见[网页规范](网页设计规范.md)及[判题设计](交互练习与判题系统设计.md)。E1—E3 是章级出题方向，正式每节题量按总纲实施，核心实验是教学演示，不增加报告或自由文本提交。

## 1. 定位、先修与学习目标

本篇把静态参数和隐变量（latent variable）的不确定性建模、近似推断与模型检验连成完整过程。变分推断（Variational Inference，VI）先采用可显式计算的小模型；自动微分（automatic differentiation，AD）训练在 15.1 引入后再比较。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 建立后验问题 | 明确先验、似然、后验和预测，计算可核验的局部近似 | 9.1 的共轭/数值积分参考 |
| T2 实现采样并诊断 | 实现马尔可夫链采样，检查初始化、多链、相关性与计算预算 | 9.2 的固定随机输入和已知后验 |
| T3 推导近似与隐变量学习 | 推导变分下界、均值场（mean-field approximation）更新和期望最大化（expectation-maximization，EM），辨别各自目标 | 9.3—9.4 的解析更新与枚举对照 |
| T4 检验模型和不确定性 | 比较后验预测（posterior predictive inference）、区间覆盖与独立预测，解释模型失配 | 9.5 的配对评估和失效题 |

## 2. 各章内容、实验与练习

### 9.1 贝叶斯建模与后验近似

- **直接先修**：5.3、6.4、7.3、8.2；数学：数12、数17、数19、数31、数36。
- **教学目标**：构造参数后验，比较点估计与分布估计，并计算高斯共轭和局部后验近似。
- **内容顺序**：①从清除参数及个体差异声明似然、先验与后验，先用可解析模型解释归一化；②比较极大似然和最大后验估计（maximum a posteriori estimation，MAP），说明先验和参数化的作用；③在模态附近用曲率构造 Laplace 近似（Laplace approximation），说明多峰和边界的限制。
- **核心实验**：标量高斯未知偏差先用精确后验核验，再对非线性清除参数进行一维网格积分与局部近似；参数变换含雅可比。
- **练习 E1（选择题）**：选择先验、似然、后验及点估计的正确关系，区分后验曲率与全部模型误差。
- **练习 E2（计算题）**：输入高斯先验与独立观测参数，返回后验均值、方差和预测矩；另一子题按给定模态与 Hessian 返回局部高斯协方差。
- **练习 E3（选择题）**：根据边界截断或双峰后验，判断单个局部近似遗漏的概率质量及可支持的结论。
- **核验与反馈**：共轭模型使用闭式结果，非共轭一维模型使用收敛网格积分；局部曲率须正定，点估计不等于后验均值，近似不声称消除模型偏差。
- **编写参考**：R26、R29（资料与主题对应见本篇末表）。


### 9.2 马尔可夫链采样与诊断

- **直接先修**：9.1、5.4；数学：数12、数13、数36、数37。
- **教学目标**：实现马尔可夫链蒙特卡洛（Markov chain Monte Carlo，MCMC）采样，检查平稳目标与混合质量。
- **内容顺序**：①从难积分的后验进入构造具有目标平稳分布的转移；②推导 Metropolis–Hastings 接受率与提议比，给出满足条件的详细平衡核验；③比较多链、预热、自相关与有效样本量，区分接受率、混合和有限样本误差。
- **核心实验**：对有精确矩的高斯后验和一维双峰后验运行多个初值与步幅，网格积分作参照；记录多链的模式覆盖和估计波动。
- **练习 E1（选择题）**：选择非对称提议所需的接受比，识别只看接受率判断收敛。
- **练习 E2（计算题）**：输入目标对数密度参数、候选点序列、提议对数比与固定均匀数，返回接受标记和状态序列；不在判题函数中另抽随机数。
- **练习 E3（选择题）**：根据多链停留在不同模态的结果，选择有效诊断和不能宣称的收敛结论。
- **核验与反馈**：有限状态小例子核验转移矩阵的平稳分布；连续例子与解析/网格矩比较。有效样本量的相关性修正与粒子权重的定义分别说明，有限诊断不能证明遍历性。
- **编写参考**：R29、R26（资料与主题对应见本篇末表）。


### 9.3 变分推断

- **直接先修**：9.2、5.5、8.3；数学：数12、数14、数19、数33、数38。
- **教学目标**：推导变分推断（variational inference，VI）的优化目标，实施均值场更新并量化近似偏差。
- **内容顺序**：①由相对熵（Kullback–Leibler divergence，KL divergence）和 Jensen 不等式建立证据下界（evidence lower bound，ELBO）；②推导后验距离、证据与下界的恒等式，以及均值场变分推断（mean-field variational inference）的坐标更新；③用显式公式或解析梯度优化小模型，比较近似族、初值和优化误差；自动微分留到 15.1。
- **核心实验**：相关二维高斯先验/后验提供精确参照，比较全协方差与独立因子近似；再对小型混合模型观察初始化和模式覆盖。
- **练习 E1（选择题）**：选择下界恒等式、相对熵方向及因子独立假设的正确解释，辨认优化收敛就等于后验精确。
- **练习 E2（计算题）**：输入给定高斯目标的精度矩阵、均值及当前因子矩，完成一轮坐标更新并计算下界差或解析相对熵；全部表达式在正文推导。
- **练习 E3（选择题）**：根据采样、网格参照和两种近似族的结果，区分优化未收敛与近似族不能表示相关性的误差。
- **核验与反馈**：二维高斯后验用闭式均值、协方差和相对熵核验；小模型枚举或网格作另一参照。比较方差和相关结构，不把任何变分近似概括为必然低估所有不确定性。
- **编写参考**：R27、R29（资料与主题对应见本篇末表）。


### 9.4 隐变量与参数学习

- **直接先修**：9.3、7.6；数学：数12、数31、数38、数39。
- **教学目标**：用隐变量分解参数学习问题，推导期望最大化并区分状态推断与参数更新。
- **内容顺序**：①从混合观测与未知状态建立完整数据和观测数据似然；②推导期望最大化（expectation–maximization，EM）的条件期望步骤与最大化步骤；③用已学平滑连接状态空间模型的参数学习，说明局部最优、退化解及近似步骤的限制。
- **核心实验**：小型双高斯混合观测先显式计算责任度和参数更新，再对线性状态空间模型展示一次平滑与参数更新的连接；分开拟合与独立预测。
- **练习 E1（选择题）**：选择隐变量后验、完整数据期望和参数更新中使用的信息，辨认把估计状态当作无误差真值。
- **练习 E2（计算题）**：给定一维混合模型、固定方差和观测，返回责任度、混合权重和均值的一次更新；零责任度分量按题定规则处理。
- **练习 E3（选择题）**：比较不同初始化和近似平滑步骤，判断似然单调性的适用条件及不能推出的全局最优。
- **核验与反馈**：小样本责任度与直接密度计算对照；固定方差避免无限似然退化。精确 E/M 步的单调性与近似变体分开，测试标签置换等价。
- **编写参考**：R26、R29（资料与主题对应见本篇末表）。


### 9.5 后验预测与模型检验

- **直接先修**：9.4、6.5；数学：数11、数17、数36、数38。
- **教学目标**：构造后验预测并评价区间覆盖和模型失配，在独立数据上比较点预测与分布预测。
- **内容顺序**：①由参数后验积分得到预测分布，区分参数不确定性与观测/过程随机性；②用后验预测检验比较统计特征，明确检查量与目标问题；③对齐留出数据、信息和预算，比较预测误差、对数预测分数和覆盖；保留错误机制与范围外条件。
- **核心实验**：对同一清除观测比较固定参数、精确后验、采样和变分近似；使用固定留出时段与新的输入条件，单独报告模型错设。
- **练习 E1（选择题）**：选择预测方差各部分及可信区间、预测区间的含义，识别把覆盖好等同于机制正确。
- **练习 E2（计算题）**：输入固定后验参数样本或带权节点、各节点预测均值与方差，返回混合预测矩、给定区间的经验覆盖与评分汇总。
- **练习 E3（选择题）**：根据同分布与外推评估，选择对模型复杂度和近似方法公平的比较结论。
- **核验与反馈**：总方差公式与共轭预测闭式核验；独立评估集不用于选择检查阈值或调参。有限覆盖率带抽样不确定性，缺失或失败样本不静默剔除。
- **编写参考**：R29、R26、R27（资料与主题对应见本篇末表）。


## 3. 篇末综合任务：同一观测下的后验与预测比较

固定低维清除参数模型和小型高斯混合模型，提供相同先验、似然与观测；用精确积分或共轭结果作参考，报告计算代价与不确定性偏差。

以下为待交付题组设计，统一梯度、分值、等级及首次/练习成绩规则见[篇末分层评分](教材设计.md#capstone-assessment)。章内题不因综合题组调整而改变。

| 层次 | 子题与分值 | 形式 | 主要计分目标 | 核验与反馈重点 |
|---|---|---|---|---|
| 1 基础辨析 | 1. 先验、似然与预测（10 分） | 选择 | T1 | 区分参数区间与未来观测区间，识别重复使用观测和不适定先验。 |
| 1 基础辨析 | 2. 收敛与正确性的边界（10 分） | 选择 | T2 | 依据多链和相关性结果选择可支持的结论，不把轨迹稳定当作充分证明。 |
| 2 方法应用 | 3. 后验局部近似（15 分） | Python | T1 | 给定可微对数后验及小问题参数，返回众数、曲率和近似方差，与积分核验。 |
| 2 方法应用 | 4. 一次采样接受与拒绝（15 分） | Python | T2 | 提供提议值、提议密度和均匀数，检查接受率及后续状态。 |
| 3 综合验证 | 5. 均值场更新与下界（15 分） | Python | T3 | 固定可解模型和初始化，返回坐标更新与下界；对照精确后验和独立计算。 |
| 3 综合验证 | 6. 后验预测的公平比较（15 分） | Python | T4 | 提供预测分布、留出观测和区间，返回评分、覆盖与预算摘要。 |
| 4 迁移挑战 | 7. 隐变量学习的退化（10 分） | 选择 | T3 | 给出混合模型责任度与似然轨迹，判断局部最优、标签交换和退化条件。 |
| 4 迁移挑战 | 8. 噪声失配后的校准（10 分） | 选择 | T4 | 在新观测条件下区分后验近似不足与模型错误，选择必要的预测检查。 |

每题提供独立且完整的输入，不读取其他子题的作答；选择题提供逐项解释，计算题以公开契约、容差及独立参考判定。随机算法提供固定随机数、增量、索引或已生成结果，重复实验效果用于教材解释，不按一次随机效果判分。复习入口按本篇 T1—T4 对应章节建立，正式身份和版本随题库发布。

## 4. 教学资源与衔接

- **网页安排**：9.1 联动先验、似然和后验；9.2 展示多链与相关性；9.3 对比精确后验和均值场轮廓、下界；9.4 展示责任度；9.5 展示预测区间与覆盖。每个随机演示显示种子与重复信息。
- **数据与案例**：沿用总纲 A（物质交换与清除）、B（稳态与节律）、C（个体与种群）三组生命系统案例；课程生成观测与核验状态/参数分离，同一方法比较使用相同观测、数据划分与预算。
- **独立验证**：共轭后验、低维积分、固定随机数链步骤、显式变分更新和有限混合枚举；比较均值、方差、预测与时间，保留多峰和模型错误反例。
- **出口**：为第 10 篇提供模型与估计误差评估，为第 13—17 篇提供不确定性、独立验证和公平比较；不把采样或下界收敛当作科学模型正确的证据。
