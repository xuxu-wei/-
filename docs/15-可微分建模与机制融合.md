# 第 15 篇：可微分建模与机制融合

本文为新版篇章大纲，正式教学内容待按 [M16](../ROADMAP.md#milestone-m16) 交付。总目录、数学和参考编号见[教材设计](教材设计.md#part-15)。前篇：[14-数据驱动动力学与模型降阶](14-数据驱动动力学与模型降阶.md)。后篇：[16-自适应、鲁棒与学习控制](16-自适应、鲁棒与学习控制.md)。

教学、术语与题型规则统一引用[教材规范](教材设计.md#lesson-standard)和[练习设计](教材设计.md#assessment-design)；网页与本机执行分别见[网页规范](网页设计规范.md)及[判题设计](交互练习与判题系统设计.md)。E1—E3 是章级出题方向，正式每节题量按总纲实施，核心实验是教学演示，不增加报告或自由文本提交。

## 1. 定位、先修与学习目标

建立小型神经网络、计算图和自动微分（Automatic Differentiation，AD），再连接离散动力学、神经微分方程（neural differential equation）、方程残差与机制混合。模型在普通 PC 上完成小规模实验，核心计算、损失和训练数据边界可见。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 核验可微计算 | 实现小网络和反向传播（backpropagation），解释求导对象并独立检查梯度 | 15.1 的手推和有限差分对照 |
| T2 学习动态映射 | 比较一步/多步训练与神经微分方程，检查求解误差和稳定性 | 15.2—15.3 的解析 ODE 和跨步长验证 |
| T3 融合方程与数据 | 构造物理约束和机制残差模型，检查损失尺度与可辨识性 | 15.4—15.5 的边界/初值及参数混淆实验 |
| T4 评估学习收益与失败 | 与线性、稀疏、数值求解基线在相同数据预算下比较 | 独立初值、稀疏观测、外推和消融结果 |

## 2. 各章内容、实验与练习

### 15.1 神经网络与自动微分

- **直接先修**：3.4、8.2、9.5；数学：数08、数19、数33、数27。
- **教学目标**：从计算图推导小网络的反向传播，用独立差分核验梯度并区分训练与评估。
- **内容顺序**：①引入小型神经网络（neural network）的参数、激活和计算图；②从链式法则推导反向模式自动微分（automatic differentiation，AD），逐项实现小图反传；③组织损失、批次、初始化和训练/验证边界，解释自动微分与数值差分的区别。
- **核心实验**：对同一一层及两层标量网络手推梯度、显式反传与自动微分对照；改变差分步长，保留不可微点的反例。
- **练习 E1（选择题）**：选择链式法则、共享参数梯度累加和计算图依赖的正确结果。
- **练习 E2（计算题）**：输入小网络参数、输入与目标，返回预测、均方损失和题定参数顺序的解析梯度；不要求训练大网络。
- **练习 E3（选择题）**：根据差分步长扫描和不同初始化，区分梯度错误、舍入、非光滑及优化误差。
- **核验与反馈**：光滑点用中心差分步长扫描，线性网络用闭式核验；自动微分准确求程序导数，不保证程序或模型本身正确。
- **编写参考**：R01、R28（资料与主题对应见本篇末表）。


### 15.2 离散动力学学习

- **直接先修**：15.1、14.5；数学：数17、数27、数33。
- **教学目标**：学习离散状态转移模型，区分一步训练、自由滚动和训练分布外预测。
- **内容顺序**：①以离散转移映射定义网络输入、输出、时间间隔和尺度；②比较一步损失与有限滚动损失，避免将未来真实状态混入自由运行；③在新初值与输入下比较机制、线性和小网络基线，记录稳定性与预算。
- **核心实验**：同一人工清除系统用完整轨迹划分训练和评估；网络规模固定，分别比较一步拟合和长期预测。
- **练习 E1（选择题）**：选择正确的训练/评估输入边界，识别滚动预测中偷用真实下一状态。
- **练习 E2（计算题）**：给定固定网络权重、初态和输入序列，返回一步与自由运行预测以及题定误差；只计算有界步骤。
- **练习 E3（选择题）**：根据长时漂移与改变采样间隔的结果，判断模型学习的对象及可迁移范围。
- **核验与反馈**：线性网络与已知状态转移矩阵对照；空时域和零输入测试。离散转移网络不未经说明当作连续导数使用。
- **编写参考**：R28、R01（资料与主题对应见本篇末表）。


### 15.3 神经微分方程

- **直接先修**：15.2、2.4；数学：数04、数05、数27、数33、数42。
- **教学目标**：以网络表示连续动力学右端，推导前向和伴随灵敏度，核验两种求导路线并区分求解误差和模型误差。
- **内容顺序**：①建立神经常微分方程（neural ordinary differential equation，Neural ODE）的右端与观测损失；②先对固定步长求解程序显式求导，用链式法则推导连续前向灵敏度方程；③引入分部积分与伴随灵敏度（adjoint sensitivity），完整推导低维伴随终值方程、参数梯度积分及固定观测时刻的跳跃条件；④声明固定初态、可微右端与固定观测时刻，比较离散求导与连续伴随后数值离散的误差；⑤比较容差、反向状态重建、观测稀疏与不同初值，一般函数空间证明作为拓展。
- **核心实验**：低维人工交换模型先使用线性网络，对照解析解、解析参数梯度、前向灵敏度、离散反向传播与连续伴随，再学习小型非线性修正；机制基线使用相同观测，另设反向重建误差放大的失败实验。
- **练习 E1（选择题）**：从右端函数、离散转移和求解器的关系中选择正确项，辨认减小训练损失必然改善连续模型。
- **练习 E2（计算题）**：给定小网络、固定初态、观测时刻与显式积分规则，返回预测、前向灵敏度或伴随更新与参数梯度；包含独立给定的观测损失梯度和跳跃位置。
- **练习 E3（选择题）**：根据网格细化、梯度检查和新初值实验，定位求解、梯度、优化或模型偏差。
- **核验与反馈**：线性标量模型用指数解及解析参数导数独立核验前向和伴随；固定离散程序另作有限差分检查，两种路线的数值梯度不要求在有限步长完全相同。观测网格与求解网格分开，检查观测时刻跳跃、反向重建误差与细化收敛；超预算单独记录。
- **编写参考**：R19、R28（资料与主题对应见本篇末表）。


### 15.4 物理约束学习

- **直接先修**：15.3、12.4；数学：数08、数23、数27、数33。
- **教学目标**：构造数据、方程及初边值残差损失，评价物理约束学习（physics-informed learning）的权重、覆盖与失效。
- **内容顺序**：①建立物理信息神经网络（physics-informed neural network，PINN）的函数表示和残差；②用自动微分计算所需导数，明确配点、数据和初边值损失及单位尺度；③比较权重、配点覆盖和错误机制；先做常微分方程，再给小型空间问题。
- **核心实验**：有解析解的衰减方程核验残差与梯度；一维扩散作为有界扩展，比较正确/错误边界与配点覆盖。
- **练习 E1（选择题）**：选择函数表示、导数和损失项的对应，辨认在有限配点残差小就已证明全域准确。
- **练习 E2（计算题）**：给定可显式求导的小网络、配点和边界数据，返回各损失项及指定梯度；输入规模与导数阶次固定。
- **练习 E3（选择题）**：根据误差分布与不同损失权重的结果，区分训练不足、尺度失衡、覆盖不足和机制错误。
- **核验与反馈**：解析函数同时核验方程、初值/边界与导数；独立评估点不参与训练，残差和解误差分别报告，不能以网络替代必要的数值基线。
- **编写参考**：R20、R28（资料与主题对应见本篇末表）。


### 15.5 混合模型与可辨识性

- **直接先修**：15.4、9.5；数学：数17、数27、数36、数38。
- **教学目标**：构造机制与学习修正的混合模型，检查可辨识性、约束和预测不确定性。
- **内容顺序**：①以已知收支项加可学习修正构成混合模型，明确修正进入的位置与单位；②在固定参数与联合学习两种条件下讨论机制参数和网络补偿的混淆；③复用后验预测（posterior predictive inference）与变分基础比较不确定性、独立预测和错误机制；完整贝叶斯网络作为拓展。
- **核心实验**：对饱和清除与未建模输入两种机制分别增加小修正网络，比较纯机制、纯网络与混合模型；用新增输入实验检查参数混淆。
- **练习 E1（选择题）**：选择机制参数、网络修正和观测偏差的可区分条件，识别拟合改善就证明学到真实机制。
- **练习 E2（计算题）**：输入固定机制参数、网络权重和状态/输入，返回混合右端、收支残差及固定后验节点下的预测矩。
- **练习 E3（选择题）**：根据新输入、机制消融和区间覆盖，判断混合模型的有效范围及仍无法确定的部分。
- **核验与反馈**：修正为零时恢复机制基线；不同参数组合产生相同输出的反例必须保留。模型、求解、优化和后验近似误差分别解释。
- **编写参考**：R19、R20、R27、R28（资料与主题对应见本篇末表）。


## 3. 篇末综合任务：机制与学习模型的独立比较

人工交换/清除系统固定训练轨迹、观测与预算；比较机制参数拟合、离散学习、神经微分方程和混合模型。方程残差任务另给具有解析解的低维例子。

以下为待交付题组设计，统一梯度、分值、等级及首次/练习成绩规则见[篇末分层评分](教材设计.md#capstone-assessment)。章内题不因综合题组调整而改变。

| 层次 | 子题与分值 | 形式 | 主要计分目标 | 核验与反馈重点 |
|---|---|---|---|---|
| 1 基础辨析 | 1. 可微不等于正确（10 分） | 选择 | T1 | 区别计算图梯度、连续系统灵敏度和数值近似。 |
| 1 基础辨析 | 2. 机制约束与可辨识性（10 分） | 选择 | T3 | 根据损失和传感器条件判断哪些机制和参数结论成立。 |
| 2 方法应用 | 3. 小网络梯度（15 分） | Python | T1 | 给定权重、输入和光滑激活，返回输出及梯度；有限差分独立核验。 |
| 2 方法应用 | 4. 离散与连续滚动预测（15 分） | Python | T2 | 给定参数和固定时间网格，执行显式滚动及已定义求解步骤，与解析例对照。 |
| 3 综合验证 | 5. 方程与边界损失（15 分） | Python | T3 | 给定解析候选和配点，返回数据、方程、初边值分项及缩放后总损失。 |
| 3 综合验证 | 6. 公平基线与外推统计（15 分） | Python | T4 | 提供配对预测与预算，计算多步误差、守恒和失败统计。 |

| 4 迁移挑战 | 8. 混合模型消融（10 分） | 选择 | T4 | 给定去机制、去数据和改变观测后的结果，区分收益来源与参数补偿。 |

每题提供独立且完整的输入，不读取其他子题的作答；选择题提供逐项解释，计算题以公开契约、容差及独立参考判定。随机算法提供固定随机数、增量、索引或已生成结果，重复实验效果用于教材解释，不按一次随机效果判分。复习入口按本篇 T1—T4 对应章节建立，正式身份和版本随题库发布。

## 4. 教学资源与衔接

- **网页安排**：15.1 计算图与有限差分；15.2 一步/多步误差；15.3 求解步长；15.4 损失分项和边界；15.5 参数补偿与外推。网页只使用小型已给参数的前向计算，训练与自动微分框架保留在 Notebook。
- **数据与案例**：沿用总纲 A（物质交换与清除）、B（稳态与节律）、C（个体与种群）三组生命系统案例；课程生成观测与核验状态/参数分离，同一方法比较使用相同观测、数据划分与预算。
- **独立验证**：手推/有限差分检查梯度，解析 ODE 检查求解，传统模型与独立轨迹检查预测；小损失不能替代边界、守恒、可辨识性或外推检查。
- **出口**：向第 16 篇提供经独立验证的候选模型，向第 17 篇提供神经微分方程复现准备；固定离散求导与连续伴随均须独立核验，复现时标明所用路线与原论文是否一致。
