# 第 12 篇：融合方法与研究实践

本文为篇章大纲，教学内容尚待实施。章号、数学与参考编号见[教材设计](教材设计.md#part-12)，实施与验收见 [M13](../ROADMAP.md#milestone-m13)。前篇：[11-临界变化与韧性](11-临界变化与韧性.md)。

本篇全部习题只使用选择题和提交 Python 代码的计算题。E1—E3 仅是维护者记录概念、实现和迁移出题方向的索引，不向学生展示。每节配置 3—5 道题，重难点优先 4—5 道；本大纲的章级三条设计不限制最终题量。选择题提交后显示判定与逐项解析，计算题在本机教材 Python 子进程中按公开契约运行判定，作答以 JSON 文件记录。核心实验是 Notebook 讲解与演示内容，核验提示用于标准答案和程序测试，不增加报告或自由文本提交。规则见[本地判题系统设计](交互练习与判题系统设计.md)；每章均有独立网页和练习入口，页面及 Notebook 图表共同遵循[网页与图表设计规范](网页设计规范.md)。

## 1. 定位、先修与学习目标

在已建立的机制、统计、控制与复杂系统基础上学习融合方法。12.1—12.5 每章交付小型核心实验和客观题，12.6 固定一个有界复现案例并完成关键计算与评价题组；不能用单个选题替代前五章。首次数学为数25—数28，均在章内先讲解再应用。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 按问题选择控制方法 | 区分非线性、模型不确定性、随机性与通信限制，构造适用基线 | 控制计算与假设辨析 |
| T2 比较动力学表示 | 实现有限字典、稀疏与小型神经方法，分开评价拟合、外推和约束 | 字典/梯度计算和结果题 |
| T3 评价学习决策 | 定义 MDP、训练与独立策略评估，公平报告信息和预算差异 | 策略评价与协议选择 |
| T4 完成研究复现 | 明确原论文范围、基线、消融、失败与可复现入口 | 复现关键函数及消融题组 |

核心任务以普通 CPU 可尝试的小模型、小网络和有限搜索为设计目标；实际运行预算在实施中测量后写入教材，不提前声称已达到性能。成熟方法与研究问题分别标注，不以所在篇章代替新颖性判断。

## 2. 各章内容、实验与练习

### 12.1 非线性、鲁棒与自适应控制

- **直接先修**：8.4、4.5、11.4；数学：数09、数19、数20。
- **教学目标**：区分已知非线性、未知但有界参数和在线参数变化，说明设计条件与失效边界。
- **内容顺序**：① 复习局部线性策略的适用域；② 一种基于 Lyapunov 思路的简单非线性设计；③ 鲁棒与自适应的区别，选择一种作计算基线，另一种说明核心假设。
- **核心实验**：同一人工稳态模型比较线性反馈、一个非线性方法，以及一个针对参数区间的鲁棒或简单自适应基线；固定约束和观测条件。
- **练习 E1（选择题）**：从给定非线性控制推导中选择所需已知量、Lyapunov 条件与适用区域，区分鲁棒和自适应假设。
- **练习 E2（计算题）**：按限定控制律计算状态和输入，返回失配/饱和场景的跟踪误差、约束残差及题定函数导数。
- **练习 E3（选择题）**：给定激励不足但跟踪改善的自适应结果，选择能支持的性能结论及不能宣称的参数收敛结论。
- **核验与反馈**：有限参数扫描是经验核验，不替代全参数区间的鲁棒证明；设计条件、实际观测与执行限制必须一致。

### 12.2 随机与分布式控制

- **直接先修**：12.1、5.4、9.4；数学：数13、数20、数21、数25。
- **教学目标**：解释 Brownian 增量和 Itô SDE 的基本含义，正确离散噪声，并区分随机扰动与局部通信的影响。
- **内容顺序**：① Brownian 增量、随机积分直觉；② Euler–Maruyama、强弱误差的入门区分；③ 网络局部反馈与集中信息基线，先分别验证再组合。
- **核心实验**：随机线性调节与小网络一致性分为两个最小实验；先用无噪或解析矩检查，再增加噪声和通信限制。
- **练习 E1（选择题）**：对 dX=a dt+σ dW，选择均值、方差和噪声增量缩放的正确表达，区分强弱误差的比较对象。
- **练习 E2（计算题）**：接收固定 Brownian 细增量，合并为粗增量并实现题定 Euler–Maruyama 更新，返回路径和比较量。
- **练习 E3（选择题）**：给定断边、通信延迟和噪声对照，选择能区分信息限制与随机扰动影响的实验及结论。
- **核验与反馈**：E1 均值为 X₀ + aT、方差为 σ²T；独立路径之间比较分布，同路径细化才用于路径误差；不把一种误差指标当作另一种收敛证据。

### 12.3 Koopman 与稀疏动力学辨识

- **直接先修**：12.2、6.5；数学：数07、数17、数19、数26。
- **教学目标**：解释函数观测与有限字典投影，实现小型 EDMD 和稀疏方程辨识，评估字典与噪声的作用。
- **内容顺序**：① 状态、观测函数与算子，不默认泛函分析；② 有限字典 EDMD 及数据矩阵；③ 候选项、稀疏性、导数估计和机制基线。
- **核心实验**：使用同一低维已知机制模型，按完整轨迹或初值划分训练、验证、最终评估，比较一步误差、长期滚动和范围外预测。
- **练习 E1（选择题）**：从有限字典、线性传播和原状态非线性的说法中选择正确项，辨认近似闭合与真实线性的混淆。
- **练习 E2（计算题）**：对固定字典特征和小型训练矩阵，完成题定 EDMD 或稀疏回归步骤并返回预测与残差；子题分别固定算法契约。
- **练习 E3（选择题）**：根据噪声、采样率与字典消融结果，选择可支持的预测或机制结论，排除使用最终评估答案调参。
- **核验与反馈**：先用可精确表示的线性小例子核验实现；真值方程只用于独立评估，字典与超参数不依据最终评估答案选择。

### 12.4 神经动力学与物理约束学习

- **直接先修**：12.3、10.4；数学：数08、数19、数23、数27。
- **教学目标**：从网络与计算图理解自动微分，构造神经 ODE 和方程残差约束的最小训练任务，分析不同误差来源。
- **内容顺序**：① 小网络、参数、训练/验证与自动微分；② 以网络表示 ODE 右端并训练；③ 方程、初值/边界与数据损失，比较残差约束学习。
- **核心实验**：在一个低维 ODE 上分别实现两种小型方法，与机制模型及简单拟合基线比较；更大的 PDE、复杂伴随推导和 GPU 扩展为可选拓展。
- **练习 E1（选择题）**：从小计算图的链式法则、梯度和有限差分对照中选择正确结果及误差解释。
- **练习 E2（计算题）**：对给定小网络、参数与点集返回数据损失、方程残差、初值损失及题定梯度；限定输入规模，不要求长时间训练。
- **练习 E3（选择题）**：给定新初值、范围外输入和错误机制约束的结果，选择插值、外推及误差来源的正确解释。
- **核验与反馈**：求解误差、梯度误差、优化未收敛和模型偏差分别记录；训练损失低不替代独立验证，多种初始化需报告波动与预算。

### 12.5 强化学习与模型决策

- **直接先修**：12.4、8.4；数学：数12、数13、数20、数28。
- **教学目标**：定义状态、动作、转移、回报和终止，连接随机 Bellman 方程、策略评估与改进，并设计公平决策比较。
- **内容顺序**：① MDP 与回报及折扣；② 小型有限状态任务中的策略评估与简单表格学习；③ 在人工调节任务上比较学习策略与 MPC。
- **核心实验**：先在可枚举 MDP 上核验，再使用低维离散化调节环境；训练和最终评估轨迹隔离。
- **练习 E1（选择题）**：对给定两状态两动作的转移和回报表，选择一次 Bellman 更新结果及回报/约束含义。
- **练习 E2（计算题）**：按小型有限 MDP 的输入表实现策略评估或一次改进，返回价值、动作与固定评估指标；并列动作按公开规则处理。
- **练习 E3（选择题）**：从学习策略与 MPC 的候选比较协议中选择信息、训练预算、独立评估和失败统计交代充分的方案。
- **核验与反馈**：训练回报不作为独立效果证据；共同约束与传感信息一致，无法对齐的模型知识差异明确报告；失败回合纳入统计。

### 12.6 完整研究复现与综合项目

- **直接先修**：12.5；数学：数17、数19、数24。
- **教学目标**：把论文主张缩成一个可验证问题，形成从证据来源到实验、比较、失败与限制的完整记录。
- **内容顺序**：① 选择原始论文、具体版本与待复现结论；② 建立最小基线、固定数据与评估协议；③ 执行复现、消融及失败分析，整理运行入口。
- **核心实验**：从三组贯穿案例选择一个，仅复现一个明确方法或结果；复用前五章已核验组件，但独立评估数据不进入调参。
- **练习 E1（选择题）**：给定原论文结论摘要和候选复现协议，选择问题、假设、数据、基线与指标对应正确的方案。
- **练习 E2（计算题）**：对固定的小型复现场景实现指定关键函数，返回基线/方法预测或统一评估量；正常、消融与失效输入均进入测试。
- **练习 E3（计算题）**：根据预先固定的多条件复现结果计算效果差值、消融差值和失败统计；结论边界另以选择题检验，不提交自由研究报告。
- **核验与反馈**：未复现结果如实报告并检查实现、数据、指标和预算差异；不得为了与论文一致而只保留有利随机种子。

## 3. 篇末综合任务：研究方法复现与评价题组

提供一项有明确原始文献范围的小型机制/学习比较案例。选择题检查假设、基线、数据划分、消融和结论边界；Python 题实现前五章的有限关键步骤及综合评价函数；以固定正常、消融和失效输入判定结果。

覆盖 T1—T4；12.1—12.5 的核心题不能由单个专题代替。长实验作为 Notebook 演示，网页判定有界算法和结论理解，不要求上传论文式报告。
