## 2. 各章内容、实验与练习

### 5.1 从重复实验建立概率

- **直接先修**：2.4、1.4；数学：数03、数10。
- **教学目标**：区分事件、随机变量、概率分布与一次实现，说明频率近似的波动。
- **内容顺序**：① 重复测量与事件；② 离散、连续分布及概率密度；③ 抽样、实验种子与 Monte Carlo 重复。
- **核心实验**：对固定理想观测加入已说明的随机误差，比较不同样本量；计划以 200 次独立重复观察统计量分布，实际预算和重复次数在实施时固定并报告。
- **练习 E1（选择题）**：从连续密度、点概率和区间概率的说法中选择正确项，并辨认一次实现与概率分布的混淆。
- **练习 E2（计算题）**：输入按实验分组的固定二值样本，返回每组成功频率及题定汇总量；样本量变化和空组处理在契约中明确。
- **练习 E3（选择题）**：给定细胞抽样方案，选择满足题设独立重复要求的方案，以及共享随机序列或共同环境造成的反例。
- **核验与反馈**：频率落在 [0, 1]，分布总概率为 1；记录种子列表或确定的派生方式，不把重复使用同一随机序列称为独立重复。

### 5.2 期望、方差、协方差与噪声

- **直接先修**：5.1、3.1；数学：数06、数10、数11。
- **教学目标**：计算与解释均值、方差、协方差及 Gaussian 分布，区分三类变异来源。
- **内容顺序**：① 从样本摘要走向期望与方差；② 联合分布、协方差及相关性；③ 状态更新噪声、观测噪声和固定个体参数差异。
- **核心实验**：使用人工偏差模型 xₙ₊₁ = axₙ + wₙ、yₙ = xₙ + vₙ，分别开启过程噪声与测量噪声；再改变不同个体的固定 a，避免把 Gaussian 偏差误称非负物质量。
- **练习 E1（选择题）**：从噪声进入状态或观测的位置图和方差解释中选择正确项，区分个体固定差异。
- **练习 E2（计算题）**：输入 a、过程噪声方差、初始方差和步数，返回状态方差递推；公开例前两步为 0.04、0.0656。
- **练习 E3（选择题）**：给定独立测量误差与共享偏移两种情形，选择增加测量次数后误差变化的正确结论。
- **核验与反馈**：E2 方差为 0.04、0.0656；重复样本误差需与理论量区分，经验分位带只是样本分布摘要，不能未经说明称为参数置信区间。

### 5.3 条件概率与贝叶斯更新

- **直接先修**：5.2；数学：数11、数12。
- **教学目标**：区分先验、似然和后验，计算离散与简单 Gaussian 更新，并说明条件独立假设。
- **内容顺序**：① 二维概率表与条件概率；② Bayes 公式与归一化；③ 重复观测、Gaussian 均值和方差更新，衔接未来状态估计。
- **核心实验**：先在有限假设表上更新，再对一个固定未知偏差进行重复测量；当前对象不随时间变化，避免提前混入动态滤波。
- **练习 E1（选择题）**：两个状态的先验为 0.2、0.8，某观测的似然为 0.9、0.1，选择观测出现后第一个状态的后验及解释；包含把似然当后验和漏归一化的干扰项。
- **练习 E2（计算题）**：输入 Gaussian 先验与独立观测序列，返回逐次后验均值和方差；覆盖不同观测精度及空序列。
- **练习 E3（计算题）**：对给定的多组先验和同一观测序列返回最终后验与差异指标；核验信息较少和较充分的固定场景。
- **核验与反馈**：E1 后验为 9/13；概率归一，Gaussian 方差保持非负；“多次输入同一数据”不等于增加独立信息。

### 5.4 随机过程与马尔可夫模型

- **直接先修**：5.3、3.1；数学：数06、数12、数13。
- **教学目标**：写出转移约定，分别计算状态分布和模拟单条路径，说明长期分布的条件。
- **内容顺序**：① 时间索引随机量和马尔可夫假设；② 转移矩阵及分布递推；③ 长期分布、吸收状态与随机游走，给出不收敛反例。
- **核心实验**：理想细胞两状态切换；统一采用行概率向量和行随机矩阵，核对多路径频率与矩阵传播。
- **练习 E1（选择题）**：对 P=[[0.8, 0.2], [0.1, 0.9]]、初始分布 [1, 0]，选择正确的前两步分布及不变分布，辨认行列约定错误。
- **练习 E2（计算题）**：输入行随机矩阵、初始分布和步数，返回逐步分布；测试包括吸收态、周期链及不变初始分布。
- **练习 E3（选择题）**：从二状态交替链的长期行为结论中选择成立项，区分不变分布存在与任意初始分布收敛。
- **核验与反馈**：E1 不变分布为 (1/3, 2/3)，前两步为 (0.8, 0.2)、(0.66, 0.34)；矩阵行和、概率非负性与随机误差分别检查。

### 5.5 熵、互信息与测量价值

- **直接先修**：5.4；数学：数12、数14。
- **教学目标**：从离散概率计算熵与互信息，说明单位、样本偏差及因果解释的边界。
- **内容顺序**：① 信息量、熵与对数底；② 条件熵和互信息；③ 分箱、有限样本和观测通道比较。
- **核心实验**：对具有已知联合分布的二值状态及噪声通道，先精确求和再抽样估计；连续观测只做显式分箱的比较。
- **练习 E1（选择题）**：从公平二值状态、准确通道和独立通道的熵/互信息数值及单位中选择正确项。
- **练习 E2（计算题）**：输入联合频数表，按以 2 为底的插件估计返回边缘熵和互信息；覆盖零频数、独立及确定对应情形。
- **练习 E3（选择题）**：给定不同样本量、分箱和通道的信息结果，选择可支持的观测价值结论，排除因果作用与热力学熵的错误解释。
- **核验与反馈**：E1 熵为 1 bit，互信息分别为 1、0 bit；处理零概率项，区分离散熵与连续变量分箱后的量。

## 3. 篇末综合任务：噪声、概率更新与信息题组
