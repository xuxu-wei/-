## 1. 定位、先修与学习目标

在已知模型反馈基线上处理非线性、不确定性、在线学习、随机扰动和多主体决策。七章各自给出成立条件和失效实验；鲁棒、自适应和强化学习（Reinforcement Learning，RL）之间不互相代替保证。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 核验非线性与鲁棒设计 | 建立适用域和不确定集合，检查稳定条件、约束与最坏情形 | 16.1—16.2 的 Lyapunov 与顶点验证 |
| T2 处理在线变化与随机扰动 | 连接递推辨识、自适应闭环与随机数值离散，检查激励和统计误差 | 16.3—16.4 的漂移、弱激励和强/弱误差实验 |
| T3 实现分布式与学习策略 | 解释局部信息、图连通与有限决策过程，实现共识和策略评估（policy evaluation） | 16.5—16.6 的解析图谱和枚举参考 |
| T4 比较模型学习与约束决策 | 统一数据、预算和信息，保留模型偏差、违约与失败 | 16.7 的 MPC 基线和独立配对测试 |

## 2. 各章内容、实验与练习

### 16.1 非线性反馈设计

- **直接先修**：4.5、10.7；数学：数08、数09、数19。
- **教学目标**：为低维非线性系统构造反馈与稳定性论证，明确适用域和执行约束。
- **内容顺序**：①复习局部线性反馈的适用范围，从候选 Lyapunov 函数建立非线性设计；②对已知输入作用方向推导一个标量反馈或低维能量整形例子；③分别检查饱和、模型失配与区域外初值，不把局部结论扩展为全局保证。
- **核心实验**：人工稳态系统分别用线性反馈和显式非线性反馈，在相同执行上限下比较恢复；解析验证候选函数导数的符号范围。
- **练习 E1（选择题）**：从控制律推导中选择必要已知量、正定条件与不变区域条件。
- **练习 E2（计算题）**：输入低维模型、反馈参数和状态，返回请求输入、实际饱和输入及题定函数沿实际轨迹的导数。
- **练习 E3（选择题）**：根据区域内外初值与饱和结果，判断哪些稳定性结论仍有依据。
- **核验与反馈**：无饱和标量例子用解析解或导数不等式核验；实际输入代入模型与导数，有限扫描只作数值证据。
- **编写参考**：R14、R09（资料与主题对应见本篇末表）。


### 16.2 模型不确定性与鲁棒控制

- **直接先修**：16.1、8.4；数学：数09、数19、数35、数41。
- **教学目标**：在明确的不确定参数集合上检验鲁棒性能，区别共同证据与有限场景经验。
- **内容顺序**：①定义模型集合、扰动界和性能指标，区分鲁棒与平均性能目标；②从矩阵二次型建立共同 Lyapunov 条件，给出仿射多面体模型的顶点核验依据；③比较保守性、执行约束与超出假设集合的失效；完整鲁棒最优理论作为拓展。
- **核心实验**：二维人工调节模型使用给定参数区间和候选共同矩阵，先核验顶点条件，再比较区间内部与外部的轨迹。
- **练习 E1（选择题）**：选择有限随机扫描与共同函数证明各自支持的结论，识别缺少模型集合的鲁棒声明。
- **练习 E2（计算题）**：输入闭环顶点矩阵与候选正定矩阵，返回对称导数矩阵和最坏特征值；按公开容差判断各条件。
- **练习 E3（选择题）**：根据保守设计和平均性能较优设计的对照，选择条件充分的性能结论。
- **核验与反馈**：一维区间模型用解析不等式核验；顶点结论限定在仿射凸组合和共同函数条件下。加入饱和后的结论另行验证。
- **编写参考**：R14、R09、R11（资料与主题对应见本篇末表）。


### 16.3 递推辨识与自适应控制

- **直接先修**：16.1、16.2、6.6、10.7；数学：数09、数17、数29。
- **教学目标**：将递推参数估计接入反馈，区分自适应跟踪改善、激励充分和参数收敛。
- **内容顺序**：①连接第 6 篇递推辨识与控制输入，明确估计、决策和状态推进的时间顺序；②构造有界标量自校正调节例子，声明输入增益符号、参数范围和估计噪声条件；③比较参数漂移、激励不足、闭环相关误差与执行饱和，限定参数收敛解释。
- **核心实验**：单室人工调节模型在固定和漂移清除率下运行固定增益与自校正策略；共同扰动和执行限制，测试缺乏激励的跟踪改善。
- **练习 E1（选择题）**：选择估计量进入控制律的正确时刻，辨认跟踪误差小就说明参数已被准确辨识。
- **练习 E2（计算题）**：给定回归数据、初始估计、范围与控制目标，执行题定递推—限幅—推进步骤，返回参数、输入和误差序列。
- **练习 E3（选择题）**：根据闭环残差相关性和输入激励的结果，判断无偏/一致性声明所缺条件。
- **核验与反馈**：参数已知极限恢复固定基线；每步估计与独立重算对照。参数投影、激励与饱和的作用分别说明，错误输入符号作为失效条件。
- **编写参考**：R10、R14、R30（资料与主题对应见本篇末表）。


### 16.4 随机动力学与控制

- **直接先修**：5.4、7.3、10.5；数学：数04、数05、数13、数20、数25。
- **教学目标**：正确离散随机动态，比较有噪反馈的均值、波动与风险，并区分路径误差与分布误差。
- **内容顺序**：①引入布朗运动（Brownian motion）、Itô 随机微分方程（stochastic differential equation，SDE）及随机积分的必要直觉；②推导 Euler–Maruyama 方法（Euler–Maruyama method）的噪声缩放，区分强弱误差；③在随机线性调节中比较期望代价、分位和违反约束频率；不提前声称硬约束保证。
- **核心实验**：有解析矩的线性随机清除模型先检查均值与方差，再接入已知线性反馈；同路径细化和独立重复分别设计。
- **练习 E1（选择题）**：对 dX=a dt+σ dW 选择增量均值、方差与时间步长缩放，区分同路径误差和分布统计误差。
- **练习 E2（计算题）**：输入固定细网格布朗增量、合并因子和反馈参数，返回粗细轨迹及题定指标；不自行重新抽样。
- **练习 E3（选择题）**：根据有限重复的尾部事件和约束违反记录，判断平均性能与风险结论的范围。
- **核验与反馈**：无反馈或线性反馈下用解析矩核验；同路径使用细增量求和形成粗增量，报告重复次数及统计误差。完整随机分析证明为拓展。
- **编写参考**：R26、R14（资料与主题对应见本篇末表）。


### 16.5 分布式控制与通信限制

- **直接先修**：11.4、10.3；数学：数07、数21。
- **教学目标**：由局部通信构造协同反馈，检查连通性、权重和延迟对收敛与性能的影响。
- **内容顺序**：①从网络扩散推导一致性控制（consensus control），明确有向/无向图与局部可用信息；②分析离散步长、连通分量和不变总量，区别状态一致与平均一致；③加入固定通信延迟、断边和输入上限，与集中信息基线公平比较。
- **核心实验**：小型组织调节网络在相同图和初值下比较局部与集中策略；无向无延迟条件先核验，再逐项引入信息限制。
- **练习 E1（选择题）**：从图、权重和通信方向选择可支持的一致性与守恒结论。
- **练习 E2（计算题）**：给定邻接矩阵、局部状态历史、步长和延迟，返回有限次同步更新及分量内差异；按公开更新顺序判定。
- **练习 E3（选择题）**：根据断连或通信受限的结果，判断观察到的一致现象是否符合设计假设。
- **核验与反馈**：无向无延迟情形与图拉普拉斯谱及矩阵幂对照；断连时逐分量比较，不将有向权重下的极限都解释为算术平均。
- **编写参考**：R13、R14（资料与主题对应见本篇末表）。


### 16.6 强化学习与策略评估

- **直接先修**：5.4、10.5、9.5；数学：数12、数13、数20、数28。
- **教学目标**：在有限马尔可夫决策模型中实现策略评价和简单学习，区分训练回报与独立策略效果。
- **内容顺序**：①建立马尔可夫决策过程（Markov decision process，MDP）的状态、动作、转移、回报和终止；②连接随机 Bellman 方程，推导策略评价、改进及表格 Q 学习（Q-learning）更新；③明确探索、训练预算与独立评估，比较已知模型规划和从样本学习。
- **核心实验**：离散化人工调节模型先精确枚举最优策略，再从固定采样经验训练表格策略；使用独立场景统计回报和约束违反。
- **练习 E1（选择题）**：选择回报、折扣、终止和 Bellman 更新的正确表达，辨认把训练回报当作最终评估。
- **练习 E2（计算题）**：输入有限转移表或固定经验序列，完成题定策略评价或 Q 更新并返回价值；子题分别固定接口与并列规则。
- **练习 E3（选择题）**：从不同模型知识和训练预算的比较中，选择信息差异交代充分的结论。
- **核验与反馈**：小型模型用线性方程或有限时域穷举核验；终止后不继续累积回报，失败回合纳入统计，深度强化学习作为拓展。
- **编写参考**：R21、R14（资料与主题对应见本篇末表）。


### 16.7 模型学习与约束决策

- **直接先修**：16.3、16.6、10.6、14.5、15.5；数学：数17、数20、数27、数28。
- **教学目标**：把学得模型接入滚动决策，在共同观测和执行限制下评价误差、风险与失效。
- **内容顺序**：①比较固定机制、在线辨识和学习模型作为预测器的接口与误差来源；②将估计状态与模型预测接入约束决策，检查外推和不可行处理；③对齐训练、调参、观测和执行预算，比较模型策略与无模型策略并说明信息差异。
- **核心实验**：同一人工稳态模型比较已知模型控制、递推辨识后控制和小型学习模型控制；测试参数漂移及训练范围外目标。
- **练习 E1（选择题）**：选择预测器、估计器、求解器与实际系统各自承担的任务，识别用真实隐藏状态给某一策略额外优势。
- **练习 E2（计算题）**：给定多策略的固定配对轨迹、执行限制和失败标记，返回误差、输入代价、违反频率与配对效果差。
- **练习 E3（选择题）**：根据正常、失配和不可行场景的结果，选择可以推广的结论及仍需补充的证据。
- **核验与反馈**：零模型误差极限与第 10 篇基线对照，逐项独立重算指标；求解失败不冒充有效控制，备用动作的条件与结果单独记录。
- **编写参考**：R14、R21、R28（资料与主题对应见本篇末表）。


## 3. 篇末综合任务：不确定系统中的决策与边界

人工调节系统提供参数集合、漂移轨迹、固定噪声增量及小型多主体或有限状态子问题。每题重新给出完整输入；总分不由一次随机训练的回报决定。

以下为待交付题组设计，统一梯度、分值、等级及首次/练习成绩规则见[篇末分层评分](教材设计.md#capstone-assessment)。章内题不因综合题组调整而改变。

| 层次 | 子题与分值 | 形式 | 主要计分目标 | 核验与反馈重点 |
|---|---|---|---|---|
| 1 基础辨析 | 1. 非线性稳定的区域条件（10 分） | 选择 | T1 | 对候选函数、输入限制和初值集合判断成立域与反例。 |
| 1 基础辨析 | 2. 噪声与数值离散（10 分） | 选择 | T2 | 区分轨迹误差、统计误差和随机稳定结论，辨认错误的步长比较。 |
| 2 方法应用 | 3. 不确定顶点闭环核验（15 分） | Python | T1 | 给定共同二次函数与多面体顶点，返回特征值/残差并解释覆盖条件。 |
| 2 方法应用 | 4. 递推辨识与控制更新（15 分） | Python | T2 | 给定历史、激励、遗忘和控制规则，返回参数与实际输入；核对批量加权参考。 |
| 3 综合验证 | 5. 局部通信下的共识（15 分） | Python | T3 | 给定图、步长和初值，返回更新与平均量；检查连通和谱条件。 |
| 3 综合验证 | 6. 有限决策的策略评估（15 分） | Python | T3 | 给定转移、回报、折扣和策略，返回价值与 Bellman 残差；枚举核验。 |
| 4 迁移挑战 | 7. 模型学习后的约束评价（10 分） | Python | T4 | 给定独立场景、学习预测与实际轨迹，返回代价、违约和失败比例。 |
| 4 迁移挑战 | 8. 改变环境后的方法选择（10 分） | 选择 | T4 | 同时给出弱激励、分布变化和预算证据，选择有条件支持的迁移结论。 |

每题提供独立且完整的输入，不读取其他子题的作答；选择题提供逐项解释，计算题以公开契约、容差及独立参考判定。随机算法提供固定随机数、增量、索引或已生成结果，重复实验效果用于教材解释，不按一次随机效果判分。复习入口按本篇 T1—T4 对应章节建立，正式身份和版本随题库发布。

## 4. 教学资源与衔接

- **网页安排**：16.1 显示稳定区域；16.2 不确定集合与最坏结果；16.3 参数漂移和激励；16.4 共同噪声下步长比较；16.5 通信图；16.6 小型价值表；16.7 模型误差与实际违约。计算预算可见，长训练不在网页执行。
- **数据与案例**：沿用总纲 A（物质交换与清除）、B（稳态与节律）、C（个体与种群）三组生命系统案例；课程生成观测与核验状态/参数分离，同一方法比较使用相同观测、数据划分与预算。
- **独立验证**：Lyapunov 区域和顶点矩阵独立核验；RLS 与加权批量对照；随机离散与已知矩对照；图谱和有限 MDP 枚举；所有闭环报告实际违约与失败。
- **出口**：第 17 篇仅使用这里已经建立的决策原理做研究比较；没有证明的鲁棒性、约束满足或稳定性只能作为经限定的实验结果。
