# 第 10 篇：个体与集体现象

本文为篇章大纲，教学内容尚待实施。章号、数学与参考编号见[教材设计](教材设计.md#part-10)，实施与验收见 [M11](../ROADMAP.md#milestone-m11)。前篇：[09-网络上的系统](09-网络上的系统.md)；后篇：[11-临界变化与韧性](11-临界变化与韧性.md)。

本篇全部习题只使用选择题和提交 Python 代码的计算题。E1—E3 仅是维护者记录概念、实现和迁移出题方向的索引，不向学生展示。每节配置 3—5 道题，重难点优先 4—5 道；本大纲的章级三条设计不限制最终题量。选择题提交后显示判定与逐项解析，计算题在本机教材 Python 子进程中按公开契约运行判定，作答以 JSON 文件记录。核心实验是 Notebook 讲解与演示内容，核验提示用于标准答案和程序测试，不增加报告或自由文本提交。规则见[本地判题系统设计](交互练习与判题系统设计.md)；每章均有独立网页和练习入口，页面及 Notebook 图表共同遵循[网页与图表设计规范](网页设计规范.md)。

## 1. 定位、先修与学习目标

从局部个体规则走向频率、场与宏观模型，首次引入收益与复制动态（数22）、空间偏导和反应扩散（数23）。区分更新约定、有限种群随机性、空间离散与机制解释。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 写清局部规则 | 给出状态、邻域、更新时序与边界，验证最小实例 | 局部更新测试 |
| T2 区分演化机制 | 从收益推到频率变化，比较选择、漂变和变异 | 演化函数与机制辨析 |
| T3 检查空间模拟 | 从反应和交换建立网格模型，检查边界、步长和空间精度 | 空间更新及边界测试 |
| T4 评价宏观近似 | 比较个体与平均场描述，明确被忽略的相关性和尺度 | 聚合函数与尺度结论题 |

## 2. 各章内容、实验与练习

### 10.1 多主体模型与元胞自动机

- **直接先修**：9.1、5.4；数学：数02、数10、数13。
- **教学目标**：把局部规则写成可复现程序，区分同步、随机顺序和异步更新。
- **内容顺序**：① 个体状态、邻域和转移；② 双缓冲同步更新与原地更新；③ 更新次序、周期/固定边界和观测指标。
- **核心实验**：小网格上的细胞占据/空缺规则，先手算一次同步更新，再比较随机顺序更新；统一每次扫过的事件数量。
- **练习 E1（选择题）**：从三格局部更新示例中选择同步与原地更新的正确结果，辨认读取新状态造成的差异。
- **练习 E2（计算题）**：按给定局部规则、邻域、初态及更新次序实现一次或多次更新，返回网格；同步采用旧状态语义，异步顺序作为输入。
- **练习 E3（选择题）**：将周期边界改为固定边界后，选择正确的邻域变化与能隔离边界效应的对照方案。
- **核验与反馈**：规则表与实现逐项对照；异步实验记录抽样和时间计量方式；动画相似不代表更新机制相同。

### 10.2 合作与演化博弈

- **直接先修**：10.1、2.3；数学：数04、数22。
- **教学目标**：从收益矩阵计算频率依赖收益，推导两类型复制动态，解释个体模型与平均描述的假设。
- **内容顺序**：① 收益及其教学含义；② 平均收益与复制方程；③ 有限个体规则、混合假设与空间合作。
- **核心实验**：人工微生物合作情境，明确收益如何映射为非负繁殖概率；分别控制交互结构和更新规则。
- **练习 E1（选择题）**：从收益、平均收益与两类型复制动态表达式中选择正确项，解释 p(1-p) 的来源。
- **练习 E2（计算题）**：输入两类型收益矩阵与频率点，返回两类型收益、平均收益和 dp/dt；检查边界与内部平衡。
- **练习 E3（选择题）**：在收益与更新方式固定、只改变交互范围的实验中，选择合作变化能够支持的机制解释。
- **核验与反馈**：频率位于 [0, 1]，总频率为 1；收益是模型假设，不把某张收益表当成所有生物合作的定律。

### 10.3 选择、变异与适应

- **直接先修**：10.2、5.4；数学：数13、数22。
- **教学目标**：通过机制消融区分选择、随机漂变与变异，避免把适应叙述成预先设定的目标。
- **内容顺序**：① 有限种群抽样与漂变；② 加入选择及双向变异；③ 规模、固定/灭绝事件及确定性近似。
- **核心实验**：中性二类型种群先按二项抽样更新，再逐项加入选择和变异；每个机制组合重复实验。
- **练习 E1（选择题）**：从中性漂变、选择和适应的说法中选择正确项，辨认用一次上升或灭绝证明优势的错误。
- **练习 E2（计算题）**：输入 p、N 与固定重复计数，返回中性单代理论方差、经验频率统计及固定事件计数；覆盖 N=50、500。
- **练习 E3（选择题）**：根据关闭选择或变异的消融结果，选择吸收态、长期分布与观察窗口的正确结论。
- **核验与反馈**：E2 方差为 p(1 − p)/N；重复次数、事件定义和观察窗口明确；零变异时的吸收态不能直接类推到有变异模型。

### 10.4 空间自组织与反应扩散

- **直接先修**：10.3、4.3、9.2；数学：数05、数08、数23。
- **教学目标**：解释空间偏导、反应与扩散项，正确离散边界，区分机制失稳与数值伪模式。
- **内容顺序**：① 从一维网格交换进入 PDE；② 有限差分、边界与时间更新；③ 二成分反应扩散及均匀平衡的扰动，逐步进入模式形成。
- **核心实验**：先检验无反应纯扩散，再加入已明确方程的二成分反应；比较周期与无通量边界。模式案例需记录均匀态与扰动参数。
- **练习 E1（选择题）**：从扩散项的有限差分、单位与无通量边界处理方案中选择正确项。
- **练习 E2（计算题）**：按题定一维网格、边界与反应项实现一次更新并返回总量与参考误差；纯扩散、边界和失稳步长分别测试。
- **练习 E3（选择题）**：给定模式、关闭扩散、相同扩散系数和网格细化结果，选择能支持的机制解释，排除仅凭图案认定 Turing 失稳。
- **核验与反馈**：显式纯扩散的稳定条件只适用于所声明维数和离散方案；加入反应后重新检查。出现图案不足以证明 Turing 失稳，还须核查均匀态与相关模态条件。

### 10.5 从局部规则到宏观描述

- **直接先修**：10.4、5.5；数学：数14、数22、数23。
- **教学目标**：定义粗尺度变量，说明平均场忽略的相关性，比较哪些宏观量得到保留。
- **内容顺序**：① 从个体轨迹聚合频率、密度与相关量；② 平均场闭合的假设；③ 时间/空间聚合与信息损失，比较失效情形。
- **核心实验**：将同一局部交互模型与平均场方程比较，保持参数含义一致，分别考察充分混合和空间成团初态。
- **练习 E1（选择题）**：对总体比例相同但空间聚集不同的初态，选择平均场遗漏的信息和可能造成差异的机制。
- **练习 E2（计算题）**：输入个体状态、分组/邻域及宏观参考轨迹，返回密度、题定相关量和宏观误差；尺度与单位由契约固定。
- **练习 E3（计算题）**：实现题面指定的更丰富粗尺度统计量，并返回其在固定场景中的预测误差；以独立样例检验而非主观评价模型好坏。
- **核验与反馈**：比较尺度与误差定义事先固定；平均场失败应回到相关性或规则假设，不能只通过反复调参掩盖结构差异。

## 3. 篇末综合任务：局部规则与宏观近似题组

给定演化个体和空间反应两个小案例。选择题检查更新、收益、选择/漂变/变异与宏观假设；Python 题实现局部更新、复制动态、有限差分和聚合指标；依据固定尺度比较选择有效与失效条件。

覆盖 T1—T4；两类案例均有必做子题，演化采用固定重复输入，空间题明确网格、边界与时间步契约。各子题独立提交和判定；全部必做题通过后记为本版本题组完成。具体格式与发布要求见[客观题评价规范](教材设计.md#assessment-design)和[判题系统设计](交互练习与判题系统设计.md)。
