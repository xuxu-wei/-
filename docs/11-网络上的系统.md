# 第 11 篇：网络上的系统

本文为新版篇章大纲，正式教学内容待按 [M12](../ROADMAP.md#milestone-m12) 交付。总目录、数学和参考编号见[教材设计](教材设计.md#part-11)。前篇：[10-反馈与最优控制](10-反馈与最优控制.md)。后篇：[12-个体与集体现象](12-个体与集体现象.md)。

教学、术语与题型规则统一引用[教材规范](教材设计.md#lesson-standard)和[练习设计](教材设计.md#assessment-design)；网页与本机执行分别见[网页规范](网页设计规范.md)及[判题设计](交互练习与判题系统设计.md)。E1—E3 是章级出题方向，正式每节题量按总纲实施，核心实验是教学演示，不增加报告或自由文本提交。

## 1. 定位、先修与学习目标

把多变量相互作用推广到图结构，区分连接的语义、动力学规则与观测指标。首次建立数21；网络随机性与动态随机性分开组织重复实验。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 定义网络模型 | 明确节点、边、方向和权重，比较结构统计及随机基线 | 图统计测试与语义选择 |
| T2 解释网络扩散 | 构造图拉普拉斯，核验守恒并连接谱与时间尺度 | 拉普拉斯和守恒测试 |
| T3 比较传播机制 | 在公平接触条件下比较网络与平均混合传播 | 传播计算与预算辨析 |
| T4 分析集体节律 | 定义同步指标，控制异质性与耦合，限定结构结论 | 同步指标与结构结论题 |

## 2. 各章内容、实验与练习

### 11.1 从连接结构进入网络科学

- **直接先修**：3.2、5.4；数学：数06、数10、数21。
- **教学目标**：构造并解释邻接矩阵、度、路径、连通分量与社区，辨认随机网络、小世界和度分布的条件。
- **内容顺序**：①节点、边与有向/无向、加权/无权语义；②度、连通性、社区和图拉普拉斯的基础定义；③随机图、规则图与重连图，讨论度分布证据。
- **核心实验**：先手画小图核对矩阵，再在相同节点数及可比边数下比较结构；网络生成种子单独记录。
- **练习 E1（选择题）**：从四节点路径及闭环后的邻接矩阵、度和连通分量数中选择正确项。
- **练习 E2（计算题）**：输入明确语义的无向简单图，返回度、连通分量与题定路径长度统计；不连通情况按契约表示。
- **练习 E3（选择题）**：将接触次数作为权重时，选择与距离、交换强度和图布局相关的正确解释及必要转换。
- **核验与反馈**：无向简单图的度和等于两倍边数；图的绘制位置不默认具有空间含义；不凭双对数直线宣布幂律。
- **编写参考**：R13、R23（资料与主题对应见本篇末表）。


### 11.2 网络上的扩散与守恒

- **直接先修**：11.1、3.3；数学：数07、数21。
- **教学目标**：推导无向交换网络的 dx/dt = −Lx，说明守恒、连通分量和平衡模态的关系。
- **内容顺序**：①每条边的交换收支；②拉普拉斯零模态与连通性；③非零模态和趋近速度，限定等容积及对称交换假设。
- **核心实验**：在小网络中集中放入物质，对照矩阵指数和数值求解；比较连通和断连情况。
- **练习 E1（选择题）**：从图拉普拉斯、对称交换和总量守恒的推导步骤中选择成立项，识别错误的有向图类推。
- **练习 E2（计算题）**：构造题定无向图拉普拉斯并计算扩散轨迹、分量总量与误差；用断桥和大步长场景检验。
- **练习 E3（选择题）**：给定不同节点容积，选择总量守恒、浓度和平衡平均方式的正确结论。
- **核验与反馈**：无外部输入输出时检查总量守恒；谱关系只用于满足假设的算子，不能把有向或非对称网络未经说明套入同一结论。
- **编写参考**：R13、R23（资料与主题对应见本篇末表）。


### 11.3 接触结构与传播

- **直接先修**：11.2、5.4；数学：数13、数21。
- **教学目标**：定义个体状态和接触传播规则，比较平均混合与网络模型，说明初始位置及有限规模影响。
- **内容顺序**：①状态转移和接触定义；②平均混合与固定网络；③结构、初始节点与干预的对照，区分单次灭绝和平均传播规模。
- **核心实验**：选择小型感染/恢复式教学模型，明确每步概率或连续速率；比较规则图与重连图，并固定可比接触预算。
- **练习 E1（选择题）**：从每边固定传播概率与每个体固定总接触强度的对照中选择正确的预算和机制解释。
- **练习 E2（计算题）**：按题定同步传播规则，接收网络、初态与固定随机数输入，返回状态序列、传播规模和持续时间；避免不可复现随机判定。
- **练习 E3（计算题）**：根据同预算的随机/定向干预方案和固定重复结果，返回分层统计与干预差值；网络间和同网动态变异分别计算。
- **核验与反馈**：总个体数、状态合法性和更新规则一致；建议至少 20 个网络实现、每图 30 次动态重复，实际数量由预算与不确定性检查确定并写明。
- **编写参考**：R13（资料与主题对应见本篇末表）。


### 11.4 耦合振子与同步

- **直接先修**：11.3、4.2；数学：数08、数21。
- **教学目标**：区分相位接近、频率锁定与平均频率，说明同步指标和耦合归一化。
- **内容顺序**：①单体节律到相位模型的简化；②网络耦合、异质频率与同步指标；③扫描耦合及初相，比较结构和规模。
- **核心实验**：在相同固有频率集合下比较两类网络，用平均复相位的模定义 R，并同时查看相位差与频率。
- **练习 E1（选择题）**：从相位一致、均匀分布和分群反相三类例子的全局/局部同步指标中选择正确项。
- **练习 E2（计算题）**：输入相位与频率轨迹，返回 R、题定频率锁定指标和分群指标；检查整体相位平移不变性。
- **练习 E3（选择题）**：根据相同频率集合下不同网络的比较，选择有证据支持的结构结论及仍受暂态、初值或规模限制的判断。
- **核验与反馈**：R 在 [0, 1]，共同平移所有相位不改变 R；扫描结论检查暂态、步长和初值，不将单次跃变称为普遍同步阈值。
- **编写参考**：R05、R13（资料与主题对应见本篇末表）。


## 3. 篇末综合任务：网络结构、传播与同步题组

提供两类图及固定的接触/耦合预算。选择题检查图语义和对照条件；Python 题分别完成扩散守恒、给定随机输入的传播、同步指标及分层统计；依据结果选择结构效应的适用范围。

覆盖 T1—T4；各子题都具有完整输入，网络随机与动态随机的核验分开，不以布局图或单次轨迹判定机制。

以下为待交付题组设计，统一梯度、分值、等级及首次/练习成绩规则见[篇末分层评分](教材设计.md#capstone-assessment)。章内题不因综合题组调整而改变。

| 层次 | 子题与分值 | 形式 | 主要计分目标 | 核验与反馈重点 |
|---|---|---|---|---|
| 1 基础辨析 | 1. 图的节点、方向与权重（10 分） | 选择 | T1 | 辨认结构语义与归一化假设。 |
| 1 基础辨析 | 2. 传播比较需要控制什么（10 分） | 选择 | T3 | 固定接触预算与规模，不混淆密度差异。 |
| 2 方法应用 | 3. 图结构统计与随机基线（15 分） | Python | T1 | 小图统计量可手算核验。 |
| 2 方法应用 | 4. 构造守恒扩散算子（15 分） | Python | T2 | 拉普拉斯与总量检查，覆盖孤立节点。 |
| 3 综合验证 | 5. 给定随机输入的传播（15 分） | Python | T3 | 固定事件顺序与随机输入，返回传播量。 |
| 3 综合验证 | 6. 节律与同步指标（15 分） | Python | T4 | 组合相位、异质性与同步量核验。 |
| 4 迁移挑战 | 7. 改变连接后的扩散时间尺度（10 分） | Python | T2 | 同预算下计算新结构的谱及扩散对照量。 |
| 4 迁移挑战 | 8. 结构能解释哪些同步差异（10 分） | 选择 | T4 | 分开网络随机与动态随机，限定有限重复结论。 |

每题提供独立且完整的输入，不读取其他子题的作答；选择题提供逐项解释，计算题以公开契约、容差及独立参考判定。随机算法提供固定随机数、增量、索引或已生成结果，重复实验效果用于教材解释，不按一次随机效果判分。复习入口按本篇 T1—T4 对应章节建立，正式身份和版本随题库发布。

## 4. 教学资源与衔接

- **网页安排**：所有章都有独立页面、章内练习与篇末题组入口；以下仅说明可视化模块的取舍。11.1—11.2 用选点、断边、扩散轨迹与模态联动 playground；11.3—11.4 用规则与集体指标解释视图，批量统计仍在 Notebook 完成。
- **数据与案例**：沿用总纲 A（物质交换与清除）、B（稳态与节律）、C（个体与种群）三组生命系统案例；课程生成观测与核验状态/参数分离，同一方法比较使用相同观测、数据划分与预算。
- **独立验证**：逐章独立核验与反例见下列设计；随机实验对齐场景、重复次数和不确定性，不能用单次轨迹推断一般结论。
- **出口**：向第 12 篇提供局部相互作用和空间扩散，向第 13 篇提供级联与结构对照，向 16.5 提供分布式控制（distributed control）的图基础。
