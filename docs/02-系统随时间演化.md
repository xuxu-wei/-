# 第 2 篇：系统随时间演化

本文为篇章大纲，教学内容尚待实施。章号、数学与参考编号见[教材设计](教材设计.md#part-02)，实施与验收见 [M3](../ROADMAP.md#milestone-m3)。前篇：[01-看见系统](01-看见系统.md)；后篇：[03-多变量相互作用](03-多变量相互作用.md)。

本篇全部习题只使用选择题和提交 Python 代码的计算题。E1—E3 仅是维护者记录概念、实现和迁移出题方向的索引，不向学生展示。每节配置 3—5 道题，重难点优先 4—5 道；本大纲的章级三条设计不限制最终题量。选择题提交后显示判定与逐项解析，计算题在本机教材 Python 子进程中按公开契约运行判定，作答以 JSON 文件记录。核心实验是 Notebook 讲解与演示内容，核验提示用于标准答案和程序测试，不增加报告或自由文本提交。规则见[本地判题系统设计](交互练习与判题系统设计.md)；每章均有独立网页和练习入口，页面及 Notebook 图表共同遵循[网页与图表设计规范](网页设计规范.md)。

## 1. 定位、先修与学习目标

以单室积累与清除贯通离散更新、微积分、连续模型和数值验证。入口为第 1 篇；本篇依次建立数02—数05，不把大学微积分作为前提。可参考[六节样章](教材设计.md#pilot-unit)的变量、单位和模型，在正式 Notebook 中自洽定义。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 建立动态模型 | 从收支写出含初值与步长的递推，并区分离散规则与连续模型的近似 | 递推函数测试 |
| T2 连接变化与累积 | 解释导数、积分和初值问题，核验单室解析解 | 微积分与解析关系选择题 |
| T3 检查数值可信度 | 分别评估误差、收敛、稳定与非负性 | 误差函数与稳定性辨析 |
| T4 完成输入迁移 | 实现分段输入，用独立参考检查并解释不同轨迹 | 分段输入计算题组 |

## 2. 各章内容、实验与练习

### 2.1 用递推描述增长与清除

- **直接先修**：1.2、1.4；数学：数01、数02。
- **教学目标**：由逐段收支得到差分方程，明确状态、参数、初值、步长与有限求和的角色。
- **内容顺序**：① 从表格走向下标与递推；② 比较每步损失比例与每时间清除系数；③ 求固定点，并说明它与逐步轨迹的区别。
- **核心实验**：复制改编样章“用 Python 表达积累与清除”与“平衡、负反馈与参数变化” 的更新、平衡和边界分支；增加增长规则及不等步长的收支对照。
- **练习 E1（选择题）**：比较每步保留比例和每时间清除系数，选择不同 h 下符合题面离散模型或 Euler 近似约定的表达式。
- **练习 E2（计算题）**：输入 A0、u、k、h 和 n，按显式收支更新返回含初值的 amounts 与逐步 balance_residuals；公开例 A0=0、u=1、k=0.5、h=1、n=3，单位沿用共同模型；覆盖零清除、零输入和平衡初值。
- **练习 E3（计算题）**：输入逐段流率和实际时间间隔，返回动态轨迹与总输入；补充测试包括交替输入和不等步长，不能把恒定输入固定点代作每步结果。
- **核验与反馈**：E2 得到 1、1.5、1.75 U；E1 必须说明“离散模型参数”与“连续速率的数值离散”各自含义，不能只按数值相等判断。

### 2.2 变化率与累积：微积分入口

- **直接先修**：2.1；数学：数02、数03。
- **教学目标**：从有限变化率解释导数，从流量求和解释积分，并用基本定理连接二者。
- **内容顺序**：① 缩短区间、割线与局部斜率；② 矩形累积、积分记号和单位；③ 导数与积分的联系、指数导数及后续需要的简单链式法则。
- **核心实验**：复制改编样章“从变化率进入微分方程” 中的斜率与面积图；在已知曲线上同时比较差分近似和累计近似。
- **练习 E1（选择题）**：选择导数、积分和初值相关的正确单位与含义，辨认“累计流入直接等于终点存量”的遗漏。
- **练习 E2（计算题）**：对题设函数返回指定间隔下的前向差分与左端矩形累计值；公开例对 t² 在 t=1 求差分，对流率 2t 在 0—1 累计，补充测试改变位置和网格数。
- **练习 E3（选择题）**：给定分段恒定流率图及累计曲线候选，选择匹配曲线和有关跳变时刻的正确说法。
- **核验与反馈**：E2 的局部导数参考值为 2，累积参考值为 1；要求写出取样端点与误差，不能把离散求和定义成精确积分。

### 2.3 连续时间与一阶微分方程

- **直接先修**：2.2；数学：数03、数04。
- **教学目标**：推导并验证 dA/dt = u − kA 的恒定输入解，说明初值、平衡和时间尺度。
- **内容顺序**：① 从收支率形成初值问题；② 先解无输入衰减，再通过偏离平衡求一般解；③ 检查零清除、零输入和平衡初值，解释 1/k 的时间尺度。
- **核心实验**：复制改编样章“从变化率进入微分方程” 的解与边界分支，改变初值和 k；在图上区分平衡位置与靠近速度。
- **练习 E1（选择题）**：从指数解推导步骤、平衡和零清除分支中选择全部成立项，解释 u/k 不能直接用于 k = 0。
- **练习 E2（计算题）**：输入 A0、u、k 和 times，返回解析 amounts；包含 k = 0、u = 0、平衡初值和很小 k 的测试，按题面容差比较。
- **练习 E3（选择题）**：令 u 与 k 同时加倍，从平衡、特征时间和轨迹变化的候选结论中选择全部正确项。
- **核验与反馈**：使用初值、方程残差和已知边界作独立依据；E3 平衡不变而特征时间减半，结论限于该恒定输入线性模型。

### 2.4 数值模拟、误差与迁移

- **直接先修**：2.3；数学：数02、数04、数05。
- **教学目标**：推导 Euler 平衡误差递推，区分误差大小、渐近稳定性与非负性，并正确处理输入跳变。
- **内容顺序**：① Euler 与解析参考；② 网格细化、最大误差和观察阶；③ 从 1 − kh 解释伪振荡与负值，再用分段解析传播检查变化输入。
- **核心实验**：复制改编样章“检查数值模拟”与“独立迁移实验”，按样章既定的步长、边界与容差检查；保留失败曲线并解释原因。
- **练习 E1（选择题）**：根据给定 kh、初值与输入，从误差衰减、非负性和渐近稳定性的判断中选择正确项，区分三个概念。
- **练习 E2（计算题）**：输入名义步长、输入跳变表和终止时间，返回包含全部跳变的 grid 与按实际步长计算的 amounts；测试包含 3 T 跳变与 0.8 T 名义步长。
- **练习 E3（计算题）**：对指定的等总量输入方案返回终值、峰值、分段解析误差与网格细化误差；补充测试改变分段位置和清除系数。
- **核验与反馈**：严格区分公式浮点一致性容差和离散近似误差；E2 不得把不足一个名义步长的区间仍按 0.8 T 计算；收敛标准沿用样章约定。

## 3. 篇末综合任务：变化输入下的积累与清除题组

给定三种等总量输入方案及统一初值、清除系数和观察区间。选择题检查方程、输入解释与零清除边界；Python 题返回网格、轨迹、总输入、峰值、终值和分段解析误差；结果辨析选择题检查输入分布为何改变动态。

覆盖 T1—T4；时间跳变、实际步长、独立参考和非负性由程序测试检查，数值失败原因由选择题检查。各子题独立提交和判定；全部必做题通过后记为本版本题组完成。具体格式与发布要求见[客观题评价规范](教材设计.md#assessment-design)和[判题系统设计](交互练习与判题系统设计.md)。
