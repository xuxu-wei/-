# 第 2 篇：系统随时间演化

本篇已交付四章、十节 Notebook 和一节篇末综合，共 48 题（32 道选择、16 道 Python 计算）。[Notebook 目录](../notebooks/02-系统随时间演化/README.md)是学习入口；实施证据见 [M3](../ROADMAP.md#milestone-m3)。前篇：[看见系统](01-看见系统.md)；后篇：[多变量相互作用](03-多变量相互作用.md)。

## 1. 定位、先修与学习目标

沿用第 1 篇的系统边界与收支观念，从有限更新走到连续变化，再检查数值计算。数学按数02—数05依次引入：下标与有限求和 → 极限、导数与积分 → 指数、对数与链式法则 → 一阶初值问题 → 误差、收敛和稳定性。微积分不作为入门前提；同篇先修均指向前面的课节，跨篇复习链接指向正式第 1 篇。

| 目标 | 学完能够完成的动作 | 评价证据 |
|---|---|---|
| T1 建立动态模型 | 从收支写出含初值与实际时长的递推，区分每步比例与每时间速率 | 递推、收支、不等间隔题 |
| T2 连接变化与累积 | 解释导数与定积分，推导并检查单室解析解 | 差商、面积、链式法则与解析边界题 |
| T3 判断数值可信度 | 分开检查误差、收敛、渐近稳定和非负性 | 网格细化、观察阶、kh 边界与反例题 |
| T4 迁移到变化输入 | 在输入跳变处分段，比较等总量方案并核验结果 | 网格、分段传播与篇末综合题组 |

## 2. 各章内容、实验与练习

### 2.1 用递推描述增长与清除

- **直接先修**：第 1 篇 1.2、1.4；单位、函数与 Python 循环。下标、有限求和与等比和在本章引入。
- **教学目标**：由逐段收支形成差分方程，区分每步保留比例与每时间清除系数，求固定点并解释逐步过程。
- **内容顺序**：① 从逐步变化到递推规则；② 有限等比和与固定点；③ 让实际时间间隔进入收支更新。
- **核心实验**：用人工增长因子比较衰减、恒定和增长；手算前三步；改变更新间隔及输入，检查每段收支残差。
- **练习配置**：两节各 4 题，共 8 题；计算题实现增长、含残差的欧拉更新及不等间隔输入。选择题检查单位、固定点、速率和比例的区别。
- **核验与反馈**：以有限等比和和展开的加权输入和独立核验递推；覆盖零步数、零清除、零输入和平衡初值。改变 h 时，每步输入量和清除比例都随之改变。

### 2.2 变化率与累积：微积分入口

- **直接先修**：2.1；有限求和、函数读图与单位。极限、导数、定积分、指数和对数在本章从必要含义开始解释。
- **教学目标**：从差商进入导数，从矩形累积进入定积分，用微积分基本定理连接二者，再用链式法则解释指数衰减。
- **内容顺序**：① 从平均变化到导数；② 从矩形累积到定积分；③ 指数、自然对数与链式法则。
- **核心实验**：对 t² 比较差商与 2t，观察过小间隔的舍入问题；累积流率 2t 并核验精确面积；比较不同指数衰减系数的函数与导数。
- **练习配置**：三节各 4 题，共 12 题；计算题分别求差商、左端矩形累积、指数函数及导数。选择题解释局部变化、累积单位、基本定理条件和链式系数。
- **核验与反馈**：差商为 2t+h；左端和以等差求和独立检查，积分为 b²−a²；指数导数包含 −k。数值证据不替代极限定义，输入积分也不自动等于终点存量。

### 2.3 连续时间与一阶微分方程

- **直接先修**：2.2；导数、定积分、指数/对数和链式法则。分离变量与初值问题在本章引入。
- **教学目标**：推导 dA/dt=u−kA 的恒定输入解，检查初值、方程与边界；区分平衡位置、特征时间和半衰期。
- **内容顺序**：① 从收支率到初值问题；② 分离变量、偏离平衡与解析解；③ 比较平衡位置、到达比例与靠近速度。
- **核心实验**：逐项核验解析函数；处理 k=0 及很小 k；保持 u/k 相同并改变 u、k，用达到 90% 平衡量的时间比较速度。
- **练习配置**：两节各 4 题，共 8 题；计算题实现解析轨迹及从零起点到达指定比例的时间；选择题检查解、零清除分支及时间尺度。
- **核验与反馈**：用初值、导数残差和高精度指数计算检查；k=0 单独返回 A0+ut，小 k 用 expm1(z)/z 的连续极限避免相减损失与 u/k 中间溢出。到达比例使用 −log(1−f)/k，条件为 k>0、0≤f<1、从零起步且 u>0。

### 2.4 数值模拟、误差与迁移

- **直接先修**：2.3；递推、解析解、有限求和与对数。局部/全局误差、观察阶和稳定性条件在本章说明。
- **教学目标**：连接逐步误差与全程误差；推导 1−kh 的偏差传播；区分渐近稳定与非负性，正确处理输入跳变。
- **内容顺序**：① 误差与网格细化；② 稳定性与非负性不是一回事；③ 在输入跳变处分段计算。
- **核心实验**：同一初值问题上比较多个 h 与解析参考，解释一阶收敛；保留负值与发散曲线；在 3 T 跳变处切分 h=0.8 T 的网格。
- **练习配置**：三节各 5 题，共 15 题；计算题求误差、观察阶、稳定/非负标志、首步衰减、对齐网格和分段传播。选择题集中检查 kh=0/1/2、负值裁剪和跨越跳变的错误。
- **核验与反馈**：误差采用各自网格的最大绝对误差，细化时保持问题与观察终点一致；k>0 时 0<kh<2 才严格渐近稳定，0≤kh≤1 才保证任意非负初值/输入的非负性。最后一小步使用实际时长，不能继续套名义 h。

## 4. 共同模型、综合评价与完成条件

案例只表示充分混合池中的人工示踪物质。A 用 U，t 用 T，u 用 U/T，k 用 1/T；参数是教学选值，无外部数据或数据生成器依赖。假设一阶比例清除，无内部生成、瞬时注入或多室交换，各节另列使用条件。

篇末以等总量的均匀、前置和后置输入为共享案例。五题分别检查公平比较、总输入、同终值的条件、解析峰值/终值/误差与结果解释；覆盖 T1—T4。题目独立提交，不要求自由报告。k=0 的末量由总输入决定，k>0 时输入时机影响存留；分段常量下每段单调，解析峰值可从分段端点求出，不能把稀疏网格上的任意峰值当作一般精确结论。

正式验收要求：十一节从新内核顺序运行；48 题题面/链接/契约同步；所有计算样例可复制运行；参考值以闭式和、高精度计算或独立加权输入展开核对；网页与 Python 跨实现检查；真实点击动画、往返、练习判定、traceback 和默认 IDE 入口。确定性容差随题面声明；误差收敛与浮点一致性分开检查，不以两份相同循环互证。样章在这些内容验收后清理，清理后复验第 1、2 篇。历史证据留在 [M1 验收](M1验收.md)，不再作为学习入口。
