## 自动检查方式

在项目根目录、已安装 `.[learn,dev]` 的环境中运行：

```sh
python -m pytest -q
python tools/sync_m1_exercises.py --check
python tools/check_teaching.py
python tools/check_m1.py --write --preview
node --test tools/tests/web-model.test.mjs tools/tests/playback.test.mjs
python tools/sync_theme.py --check
python tools/export_m1_reference.py
node tools/compare_m1_models.mjs
python tools/serve.py --previews
```

`check_m1.py` 显式使用执行该命令的 Python 创建核验内核，避免误用机器上其他环境；执行报告与 HTML 预览保存在忽略的 `.work/m1/` 下。`--write` 会把运行输出保存回 Notebook，不改变讲解与算法。

可重复的浏览器检查脚本为 `tools/check_browser.mjs`，对照 Notebook 计算的参考值、操作网页并检查 PC 窗口布局。保持上面的预览服务运行，在另一终端执行：

```sh
python tools/export_m1_reference.py
node tools/check_browser.mjs
node tools/review_notebooks.mjs
```

这些浏览器工具需要 Node.js、可解析的 `playwright` 模块及 Chromium 浏览器。若已有独立安装，可用 `PLAYWRIGHT_MODULE` 指向模块目录、`PLAYWRIGHT_EXECUTABLE` 指向浏览器可执行文件；未设置时使用普通模块解析及 Playwright 管理的 Chromium。它们只用于开发验收，学习 Notebook 和使用网页不需要 Node.js。截图与详细报告写入忽略的 `.work/m1/`。修订后的脚本模拟 IDE 请求响应，避免自动检查启动六个 IDE；真实文件关联必须另用实际点击验收，不能用模拟成功代替。

`review_notebooks.mjs` 检查 Notebook 的结构和八幅图像；临时 HTML 预览采用 nbconvert 默认 MathJax CDN，离线时公式可能不排版。正式教学入口是 Notebook；初次验收在 JupyterLab 中检查了 S04 的公式排版，当前网页入口遵循系统默认 IDE。配套概念网页完全使用本地资源。

### 教学评审与练习核验

本轮由编写者逐节自审目标、先修、单位、推导、对照实验与练习。S01 从区间收支开始，S02 引入更新循环，S03 区分平衡与靠近速度；S04 在使用微分方程前引入导数与积分；S05 分开解释精度、稳定性与非负性；S06 以分段输入完成迁移。核心算法均在 Notebook 显式展示。

18 道练习均给出解释或示范方案，按题面检查逻辑、单位、可解性及适用条件；指定的计算实例另以程序复算。关键结果如下：

- S01-E2：区间改为 0.25 T 后终点为 2.375 U。
- S02-E2：默认前三步为 0.1、0.195、0.28525 U；S02-E3 的恒定流出反例一步得到 −0.1 U。
- S03-E2：保持平衡 2 U，k 为 0.25/T、0.5/T 时，h = 0.1 T 的离散轨迹首次达到 1 U 的时刻分别为 2.8、1.4 T。
- S04-E2：t = 5 T 的净流率约 0.082085 U/T，差商随区间缩短接近它；无输入时初值倍增性质及有输入反例均已核验。
- S05-E3：从 0.5 T 逐次减半，h = 0.03125 T 首次使最大误差小于 0.01 U，实际约 0.005786 U，需要 640 步。
- S06-E2：前置、后置输入总量均为 20 U，解析终点分别约为 0.026770、3.973048 U；三段迁移示例的终点约为 2.011264 U，分段衔接与步长减半检查通过。

审查后修正了手机端图轴标签、播放暂停时的重复动画调度、S01 的时间刻度、S03 的参数单位表述、分段网格的重复边界，以及 JupyterLab 启动时的根目录。数值检查保留负值和发散结果供解释，没有静默裁剪失败轨迹。

本轮没有独立同行评审或目标读者试学。学习时间、题目实际难度和其他平台兼容性仍待验证；记录的是当前环境的运行与编写者核验结果。标准章页面与交互判题尚未实现。按照已更新的规划，M2 复用 S01 源文件并建立页面与判题基础，M3 接入其余五节；原型开放练习在正式接入时转换为选择题和 Python 计算题。本机 Python 判题、JSON 作答记录按[本地运行与视觉规范修订](../ROADMAP.md#acceptance-local-design)实施，当前不属于已交付能力；配色另见下方修订记录。
