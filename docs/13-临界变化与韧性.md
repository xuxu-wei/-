## 1. 定位、先修与学习目标

以已有非线性、网络和群体模型研究临界变化与恢复，建立数24 的序参量、尺度关系和有限规模比较。把有限数据支持的结果、模型条件与普遍理论严格分开。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 比较临界变化 | 定义序参量，控制规模、暂态与随机重复，区分分岔和相变语言 | 规模指标与证据选择 |
| T2 拆分级联机制 | 分别控制网络结构、初始损伤和后续失效规则 | 级联计算与机制选择 |
| T3 评价恢复和预警 | 区分恢复速度、吸引域与预警指标，统计误报和漏报 | 窗口函数及误报漏报题 |
| T4 解释尺度与误差 | 比较参数、观测和模型结构不确定性，限定结论范围 | 差异统计与结论辨析 |

## 2. 各章内容、实验与练习

### 13.1 相变、临界性与有限规模

- **直接先修**：12.5、4.3、6.4；数学：数11、数24。
- **教学目标**：选择可测量的序参量，对有限系统的变化给出规模与统计证据，不把一次突变当作相变证明。
- **内容顺序**：①回顾分岔与群体行为；②序参量、波动和尺度关系的含义；③系统规模、观察时长及重复实验对阈值判断的影响。
- **核心实验**：定义同步二值群体模型，推导一步条件期望与方差；固定抽样规则，在三个规模和统一参数网格上作独立重复与有限时长比较。
- **练习 E1（选择题）**：从有限种群灭绝、确定性分岔与无限规模相变的候选证据要求中选择正确项。
- **练习 E2（计算题）**：输入同一条件的重复轨迹与固定暂态，返回尾窗序参量均值和重复间波动；另核对平均映射的固定点与斜率。
- **练习 E3（选择题）**：给定两种转变判据和有限尺度拟合，选择可支持的阈值及不确定性结论，排除未经验证的普适性声明。
- **核验与反馈**：条件矩和单步抽样可手算；尺度比较报告暂态、重复次数和波动。平均映射的局部边界不等于有限系统的精确相变点，更不能单独证明普适指数。
- **编写参考**：R12、R13（资料与主题对应见本篇末表）。


### 13.2 级联失效与结构鲁棒性

- **直接先修**：13.1、11.3；数学：数21、数24。
- **教学目标**：区分直接移除造成的损伤与阈值规则传播造成的级联，解释结构、阈值与连通性代理。
- **内容顺序**：①节点失效及同步更新；②正整数邻居阈值与逐轮级联；③固定种子和边数时比较链与星，再单独改变阈值。
- **核心实验**：逐轮记录初始损伤、继发失效，并计算幸存最大连通分量占原节点数的比例；该比例只代理连通性，不模拟真实负载或处理容量。
- **练习 E1（选择题）**：从连通性、负载功能与级联规则的关系中选择正确项，识别连通但功能失效的反例。
- **练习 E2（计算题）**：按指定阈值、网络和初始失效集逐轮模拟，返回新增失效集合与剩余连通性代理；检查零种子与高阈值边界。
- **练习 E3（选择题）**：在固定节点数、边数、种子和阈值的对照下，选择结构差异能够支持的结论。
- **核验与反馈**：零初始损伤及高阈值有预期边界；失效节点不无故恢复或重复计数，连通性不能直接说明真实功能容量。
- **编写参考**：R13（资料与主题对应见本篇末表）。


### 13.3 扰动、恢复与早期预警

- **直接先修**：13.2、4.5、6.5；数学：数09、数17、数24、数43。
- **教学目标**：测量局部恢复率，区分恢复速度与吸引域大小，并评价方差、自相关等指标的条件和失败。
- **内容顺序**：①小扰动响应、线性化与恢复时间；②有限扰动、吸引子与吸引域，区分回到长期集合和回到原时间相位；③滑动窗口预警、趋势与观测影响、误报及漏报。
- **核心实验**：具有正向吸引域边界的一维模型固定局部恢复系数，改变边界并比较小扰动与有限扰动；独立的稳定 AR(1) 序列对照恢复系数变化和纯噪声增强，不声称发生真实转变。
- **练习 E1（选择题）**：从小扰动恢复速度、吸引域和有限扰动返回的例子中选择相容结论，辨认混用韧性定义。
- **练习 E2（计算题）**：输入固定采样间隔的序列、过去窗口和样本滞后，返回方差与自相关；测试不得读取未来样本。采样间隔改变时须重新换算物理滞后。
- **练习 E3（选择题）**：给定独立评估的预警结果表，选择误报、漏报与提前量的正确解释及指标失效条件。
- **核验与反馈**：预测时刻不能使用未来数据；采样变化时“滞后（lag）一步”不等于相同物理滞后；预警指标变化只支持所声明模型与观测条件。
- **编写参考**：R16（资料与主题对应见本篇末表）。


### 13.4 多尺度、粗粒化与不确定性

- **直接先修**：13.3、12.5、9.5；数学：数11、数17、数24。
- **教学目标**：识别粗粒化丢失的局部相关，区分参数、观测和结构条件变化的影响及结论范围。
- **内容顺序**：①局部状态与平均密度；②相关性和宏观闭合；③分来源单因素对照与尺度排序。
- **核心实验**：局部异或规则给出同均值、不同排列的闭合反例；另用固定人工条件表分别计算参数、观测、结构单因素差异，并比较粗/细尺度的方案排序。两组实验不冒充同一现象的完整误差分解。
- **练习 E1（选择题）**：从相同平均曲线对应不同局部结构的例子中选择可识别结论与无法区分的机制。
- **练习 E2（计算题）**：输入固定基线与三种单因素改变后的结果，分别返回差异量，不将来源混为一项或称为方差分解。
- **练习 E3（选择题）**：比较粗、细尺度下方案排序是否反转，限定可支持的干预结论；计算题另核对局部规则的粗粒化闭合差。
- **核验与反馈**：模型比较须使用一致指标、单位和条件；敏感性是所选扰动范围内的数值证据，范围外不自动成立。
- **编写参考**：R12、R13、R16（资料与主题对应见本篇末表）。


## 3. 篇末综合任务：临界变化、恢复与预警题组

固定群体模型、级联规则和稳态扰动场景。选择题区分有限规模证据、恢复速度、吸引域及预警解释；Python 题计算级联、过去窗口指标、误报漏报和多尺度差异；结果判读选择题包含无转变却触发预警和漏报。

覆盖 T1—T4；窗口与事件定义预先固定，判定器检查未来信息泄漏，不要求开放式韧性报告。

题组已交付，统一梯度、分值、等级及首次/练习成绩规则见[篇末分层评分](教材设计.md#capstone-assessment)。

| 层次 | 子题与分值 | 形式 | 主要计分目标 | 核验与反馈重点 |
|---|---|---|---|---|
| 1 基础辨析 | 1. 有限规模的临界证据（10 分） | 选择 | T1 | 辨认序参量、暂态与规模条件。 |
| 1 基础辨析 | 2. 恢复速度与吸引域（10 分） | 选择 | T3 | 区分局部恢复与大扰动后的去向。 |
| 2 方法应用 | 3. 逐轮级联失效（15 分） | Python | T2 | 固定初始损伤及更新规则，检查停止条件。 |
| 2 方法应用 | 4. 比较规模与重复结果（15 分） | Python | T1 | 计算固定多规模观测的序参量摘要。 |
| 3 综合验证 | 5. 仅用过去窗口的预警（15 分） | Python | T3 | 窗口索引、缺失边界与未来信息泄漏检查。 |
| 3 综合验证 | 6. 分来源对照差异（15 分） | Python | T4 | 分别计算参数、观测与结构单因素差，不冒充方差分解。 |
| 4 迁移挑战 | 7. 更换事件条件后的误报漏报（10 分） | Python | T3 | 固定评估协议，保留无转变与漏报情形。 |
| 4 迁移挑战 | 8. 改变结构或尺度后的韧性（10 分） | 选择 | T4 | 结合级联、恢复与预警证据限定干预结论。 |

每题提供独立且完整的输入，不读取其他子题的作答；选择题提供逐项解释，计算题以公开契约、容差及独立参考判定。随机算法提供固定随机数、增量、索引或已生成结果，重复实验效果用于教材解释，不按一次随机效果判分。复习入口按本篇 T1—T4 对应章节建立，正式身份和版本随题库发布。

## 4. 教学资源与衔接

- **网页安排**：所有章都有独立页面、章内练习与篇末题组入口；以下仅说明可视化模块的取舍。13.1 用规模与参数曲线解释视图；13.2 用逐轮级联 playground；13.3 用扰动、恢复轨迹及窗口指标联动；13.4 不新增可视化模块。
- **数据与案例**：沿用总纲 A（物质交换与清除）、B（稳态与节律）、C（个体与种群）三组生命系统案例；课程生成观测与核验状态/参数分离，同一方法比较使用相同观测、数据划分与预算。
- **独立验证**：逐章独立核验与反例见下列设计；随机实验对齐场景、重复次数和不确定性，不能用单次轨迹推断一般结论。
- **出口**：衔接第 14—17 篇的外推、鲁棒性与研究证据；不把预警指标或有限系统现象直接称为因果解释。
