## 1. 定位、先修与学习目标

本篇独立建立优化基础，把模型拟合和后续决策所需的数学补齐。二次问题先用解析解与有限差分核验，再学习迭代、稀疏和约束；不提前使用自动微分（automatic differentiation，AD）。

| T1 表达优化问题 | 区分变量、参数、目标、尺度与凸性（convexity），判断结论的适用条件 | 8.1 的目标构造与解析最优解 |
| T2 实现迭代算法 | 显式计算梯度和曲率，比较步长、收敛及停止条件 | 8.2 的有限差分与二次收敛实验 |

## 2. 各章内容、实验与练习

### 8.1 目标函数与优化几何

- **直接先修**：3.4、6.4；数学：数08、数17、数19。
- **教学目标**：把估计和干预目标写成可计算函数，推导梯度与曲率，并说明局部和全局最优结论的条件。
- **内容顺序**：①以参数拟合和调节代价建立变量、尺度、目标与可行域；②引入二次型、Hessian 矩阵、正定性及凸性，区分驻点与最小值；③用一维非凸反例解释初值依赖，检查尺度变换是否改变问题含义。
- **核心实验**：以二参数二次拟合和双井目标并列实验，手算驻点，再画等高线和方向导数；固定变量单位及损失权重。
- **练习 E1（选择题）**：从给定二次型的驻点、曲率和约束中选择可支持的最优性结论，排除梯度为零必为全局最小。
- **练习 E2（计算题）**：输入对称二次目标矩阵、线性项和点，返回目标、梯度与 Hessian；正定小问题同时返回线性方程解。
- **练习 E3（选择题）**：比较改变单位、重标定目标与真正改变权重三种操作，判断解及代价解释的变化。
- **核验与反馈**：解析梯度与中心差分对照；正定问题用配方法或线性方程核验，非凸反例包含鞍点或局部极值。先声明对称化和维数约定。
- **编写参考**：R11、R04（资料与主题对应见本篇末表）。


### 8.2 梯度、曲率与迭代算法

- **直接先修**：8.1；数学：数19、数33。
- **教学目标**：实现梯度法与带步长控制的牛顿法，按残差和条件判断停止，区分数值失败与问题无解。
- **内容顺序**：①由局部近似推出梯度下降与牛顿方向，复习线性方程求解；②加入固定步长的稳定范围、回溯线搜索与下降条件；③比较条件数、尺度和初值对收敛的影响，记录停止原因与计算预算。
- **核心实验**：在同一二次目标上改变特征值比，再在非凸小例子上比较原始牛顿步和回溯步；保留震荡、上升与迭代耗尽。
- **练习 E1（选择题）**：根据二次目标曲率选择能保证收缩的固定步长范围，识别目标值小与梯度残差小的区别。
- **练习 E2（计算题）**：输入目标的公开系数、初值、步长参数和最大迭代数，返回迭代轨迹、残差与停止状态；题目分别固定梯度法和回溯牛顿法。
- **练习 E3（选择题）**：根据病态目标和不同变量缩放的记录，选择合理诊断与公平的算法比较。
- **核验与反馈**：正定二次问题与精确解、特征方向递推对照；线搜索验收条件独立重算。不把步数耗尽或数值异常标为收敛。
- **编写参考**：R11、R04（资料与主题对应见本篇末表）。


### 8.3 正则化与稀疏优化

- **直接先修**：8.2、6.4；数学：数17、数19、数33、数34。
- **教学目标**：推导二范数与一范数正则化的作用，实现软阈值更新并独立选择正则强度。
- **内容顺序**：①由不稳定回归引入二范数惩罚，区分拟合误差与参数收缩；②从一维绝对值惩罚推导软阈值，再构造近端梯度（proximal gradient）步骤；③比较稀疏性、偏差和共线性，正则强度只用训练与验证数据选择。
- **核心实验**：对含冗余变量的小型机制字典比较普通、二范数和一范数估计；使用已固定的留出轨迹检查稀疏模型能否外推。
- **练习 E1（选择题）**：选择正则项、尺度和共线性对系数的正确影响，辨认稀疏系数自动证明机制的错误。
- **练习 E2（计算题）**：输入设计矩阵、观测、当前系数、步长与惩罚系数，返回一次近端更新及目标值；独立测试软阈值边界。
- **练习 E3（选择题）**：从正则强度选择协议中识别使用最终评估真值调参、标准化泄漏及错误的结构解释。
- **核验与反馈**：正交设计用闭式软阈值核验；零惩罚退化为对应无惩罚更新，正则强度与目标归一化配套。变量缩放参数只从训练集得到。
- **编写参考**：R11、R34；R28用于后续稀疏辨识衔接（资料与主题对应见本篇末表）。


### 8.4 约束与最优性条件

- **直接先修**：8.3；数学：数19、数33、数35。
- **教学目标**：写出约束问题的最优性条件，检查原始与对偶残差，区分可行、最优及求解器失败。
- **内容顺序**：①从盒约束和等式约束引入拉格朗日乘子与对偶直觉；②建立 KKT（Karush–Kuhn–Tucker，卡鲁什—库恩—塔克）条件，说明约束资格及凸性所支持的结论；③对小型二次规划检查活动约束、不可行和数值残差，区分软约束与硬约束。
- **核心实验**：低维二次目标分别加兼容和冲突约束，用枚举活动集合或一维区间解核验求解结果。
- **练习 E1（选择题）**：从原始可行性、驻点、对偶可行性和互补条件中选择缺失项，判断结论所需假设。
- **练习 E2（计算题）**：输入小型二次规划与候选原始/对偶解，返回各类残差及按公开容差判断的状态；包括不可行输入。
- **练习 E3（选择题）**：比较放松约束、加大惩罚和增加迭代预算，判断操作改变的是问题还是求解过程。
- **核验与反馈**：小问题用独立枚举核验最优值；对偶间隙只在相应可行条件下解释。求解器状态不替代约束与最优性残差检查。
- **编写参考**：R11、R25（资料与主题对应见本篇末表）。


## 3. 篇末综合任务：拟合、稀疏与约束优化

固定小型辨识数据和资源预算，逐题给出完整目标与参数，比较目标最小化、独立预测和可行性。

以下题组已交付，版本为1；统一梯度、分值、等级及首次/练习成绩规则见[篇末分层评分](教材设计.md#capstone-assessment)。每题都给出完整参数，四层各20、30、30、20分。

| 层次 | 子题与分值 | 形式 | 主要计分目标 | 核验与反馈重点 |
|---|---|---|---|---|
| 1 基础辨析 | 1. 目标、尺度与凸性（10 分） | 选择 | T1 | 以一元和二维反例区分驻点、局部极小和凸问题全局解。 |
| 1 基础辨析 | 2. 正则化能保证什么（10 分） | 选择 | T3 | 区分训练误差、验证误差、稀疏性及可辨识性。 |
| 2 方法应用 | 3. 梯度与曲率核验（15 分） | Python | T1 | 对题定二次目标返回值、梯度及 Hessian，与解析和有限差分对照。 |
| 2 方法应用 | 4. 带回溯的一步下降（15 分） | Python | T2 | 提供起点、搜索规则、阈值及最大回溯次数，检查接受步长和新点。 |
| 3 综合验证 | 5. 近端稀疏拟合（15 分） | Python | T3 | 给定矩阵、目标、惩罚系数与固定迭代数；以正交设计解析解及目标核验。 |
| 3 综合验证 | 6. 约束解与最优性残差（15 分） | Python | T4 | 正定二维问题返回唯一解和四残差；乘子可不唯一，独立边界几何检查最优值。 |

每题提供独立且完整的输入，不读取其他子题的作答；选择题提供逐项解释，计算题以公开契约、容差及独立参考判定。随机算法提供固定随机数、增量、索引或已生成结果，重复实验效果用于教材解释，不按一次随机效果判分。复习入口按本篇 T1—T4 对应章节建立，正式身份和版本随题库发布。

- **网页安排**：8.1 展示等高线、梯度与曲率；8.2 比较迭代轨迹和步长；8.3 用惩罚路径和软阈值；8.4 用可行域与活跃约束。小规模计算可即时交互，大规模求解不进入网页。
