# 第 4 篇：非线性动态行为

本文为篇章大纲，教学内容尚待实施。章号、数学与参考编号见[教材设计](教材设计.md#part-04)，实施与验收见 [M5](../ROADMAP.md#milestone-m5)。前篇：[03-多变量相互作用](03-多变量相互作用.md)；后篇：[05-随机性与信息](05-随机性与信息.md)。

本篇全部习题只使用选择题和提交 Python 代码的计算题。E1—E3 仅是维护者记录概念、实现和迁移出题方向的索引，不向学生展示。每节配置 3—5 道题，重难点优先 4—5 道；本大纲的章级三条设计不限制最终题量。选择题提交后显示判定与逐项解析，计算题在本机教材 Python 子进程中按公开契约运行判定，作答以 JSON 文件记录。核心实验是 Notebook 讲解与演示内容，核验提示用于标准答案和程序测试，不增加报告或自由文本提交。规则见[本地判题系统设计](交互练习与判题系统设计.md)；每章均有独立网页和练习入口，页面及 Notebook 图表共同遵循[网页与图表设计规范](网页设计规范.md)。

## 1. 定位、先修与学习目标

入口为多变量线性化与数值检查。本篇用低维理想模型建立多稳态、振荡、分岔和混沌的区分，再引入 Lyapunov 函数（数09）；生命案例是机制简化，不作为真实系统的完整描述。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 分析多稳态 | 求平衡，结合局部分析和初值扫描解释吸引域 | 平衡辨析与初值计算题 |
| T2 区分动态行为 | 区分衰减、受迫与自维持振荡，检查暂态影响 | 周期计算和扫描结论题 |
| T3 限定预测结论 | 检查初值敏感性及数值误差，不凭不规则图形认定混沌 | 轨迹分离函数与解释选择题 |
| T4 论证稳定性 | 检查候选函数及沿轨迹导数，说明结论的区域与条件 | 函数导数计算和条件辨析 |

## 2. 各章内容、实验与练习

### 4.1 多稳态与吸引域

- **直接先修**：3.4；数学：数04、数08。
- **教学目标**：区分平衡点、局部稳定与吸引域，解释同一参数下的初值依赖。
- **内容顺序**：① 从线性近似过渡到多个平衡；② 一维流向与局部导数判断；③ 初值扫描和扰动跨越边界。
- **核心实验**：以无量纲开关模型 dx/dt = x − x³ 建立直觉，再说明与理想基因开关的类比及不能直接对应的生物量。
- **练习 E1（选择题）**：对 dx/dt = x-x³，从平衡、局部导数及精确/扰动初值的结论中选择正确项。
- **练习 E2（计算题）**：对给定初值列表与观察时刻返回题定模型的终值及按规定阈值分类的状态；包含接近不稳定平衡的初值。
- **练习 E3（选择题）**：加入给定恒定偏置后，选择符合平衡分析和流向图的吸引域结论，辨认有限网格无法支持的断言。
- **核验与反馈**：无偏置时平衡为 −1、0、1；非零稳定点两侧的方向与局部导数应一致；初值网格只提供边界的数值近似。

### 4.2 自维持振荡与极限环

- **直接先修**：4.1；数学：数07、数08。
- **教学目标**：根据输入、暂态和多初值长期行为区分三种振荡，测量周期和振幅。
- **内容顺序**：① 回顾阻尼振荡并加入周期驱动；② 引入一个简化自激振子及其变量；③ 用相图与周期测量辨认长期行为。
- **核心实验**：比较阻尼模型、受迫模型与选定的二维自激模型；明确生理类比和人工参数，不只展示一条漂亮曲线。
- **练习 E1（选择题）**：给定有/无周期输入的对照轨迹，选择可以支持的振荡类型判断与仍不能排除的解释。
- **练习 E2（计算题）**：输入均匀采样轨迹、暂态截断位置与题定峰值规则，返回后段振幅和峰间周期；固定端点和平台峰处理规则。
- **练习 E3（选择题）**：给定短扰动后的相图与时间曲线，选择“回到同一轨道”和“回到同一时间相位”的正确区别。
- **核验与反馈**：周期测量方法、峰值筛选及暂态窗口需明确；三组初值的数值趋同不替代极限环存在性的数学证明。

### 4.3 分岔与参数变化

- **直接先修**：4.2；数学：数07、数08。
- **教学目标**：区分参数改变引起的行为转变与暂态、扫描方向、数值误差造成的假象。
- **内容顺序**：① 平衡分支与稳定性标记；② 开关和振子的参数扫描；③ 正反扫描、步长细化及暂态检查。
- **核心实验**：对 4.1 的偏置开关与 4.2 的振子分别扫描一个参数，记录平衡或长期振幅，不将不同量混在同一纵轴。
- **练习 E1（选择题）**：从参数扫描中的跳变成因及补充检查中选择正确项，辨认暂态不足、初始化和真正分支变化。
- **练习 E2（计算题）**：根据题定低维模型、参数网格和扫描方向返回长期状态/振幅摘要；补充测试改变扫描步长与初始化方式。
- **练习 E3（选择题）**：从固定初值重启与沿用上一步终态两种实验方案的解释中选择正确项，说明各自能回答的问题。
- **核验与反馈**：分支标记需有平衡分析或局部证据；转变位置报告分辨率和未解决的不确定性，不能声称扫描得到精确阈值。

### 4.4 混沌与可预测范围

- **直接先修**：4.3、2.4；数学：数02、数05、数08。
- **教学目标**：在确定性映射中测量邻近初值的分离，区分初值误差、数值误差与随机机制。
- **内容顺序**：① 离散种群映射与参数范围；② 邻近轨迹及有限时间增长率；③ 有限精度、饱和分离和预测阈值，说明与连续 ODE 的差别。
- **核心实验**：使用 xₙ₊₁ = rxₙ(1 − xₙ)，明确 x 为无量纲比例、r 为每步参数；对照周期区域和不规则区域。
- **练习 E1（选择题）**：从有界轨迹分离、初值敏感性及有限时间增长率的说法中选择成立项，不把距离饱和误判为不敏感。
- **练习 E2（计算题）**：输入 logistic 映射参数、两初值、误差阈值和最大步数，返回首次超阈值步数及约定距离序列；未超阈值按契约返回。
- **练习 E3（选择题）**：从离散映射和连续 ODE 的误差检查方案中选择适用项，辨认对原映射错误使用“减小积分步长”的做法。
- **核验与反馈**：有限时间增长率仅作为指定轨迹与窗口下的数值证据；不得引入尚未学习的随机统计结论来证明混沌。

### 4.5 用 Lyapunov 函数分析稳定性

- **直接先修**：4.4；数学：数08、数09。
- **教学目标**：逐项检查候选函数的正定性、沿轨迹导数与适用区域，区分稳定、渐近稳定及证据不足。
- **内容顺序**：① 能量式函数的直觉与定义；② 多变量链式法则计算沿轨迹导数；③ 检查条件和区域，区分 Lyapunov 函数与 Lyapunov 指数。
- **核心实验**：先用 dx/dt = −x、V = x²/2 做完整论证，再尝试二维偏差系统和不能直接得出严格衰减的候选函数。
- **练习 E1（选择题）**：从候选函数、沿轨迹导数及稳定性结论中选择满足给定区域条件的组合，区分 Lyapunov 函数与指数。
- **练习 E2（计算题）**：对 dx/dt=-x+x³ 和 V=x²/2，在输入点返回 V、沿轨迹导数与严格衰减布尔标记；边界 ±1 和 0 单独测试。
- **练习 E3（选择题）**：给定导数非正但存在非静止轨迹的例子，选择能够得到的结论以及宣布渐近稳定还缺少的条件。
- **核验与反馈**：E2 的严格负导数区域为 0 < |x| < 1；区分解析符号判断与网格采样，后者不能证明区域内处处成立。

## 3. 篇末综合任务：非线性行为与证据辨析题组

提供开关和节律模型的固定场景。选择题辨认平衡、振荡类型、行为转变、预测范围和 Lyapunov 条件；Python 题计算指定模型的扫描摘要、轨迹分离及函数导数；结论选择题区分解析证明和有限模拟证据。

覆盖 T1—T4；不要求读者为任意模型构造全局证明，测试与选择题分别检查数值操作和结论条件。

本篇综合题组按以下八题设计，具体题面与测试随本篇交付。统一计分、等级、首次与练习成绩的区别见[篇末分层评分](教材设计.md#capstone-assessment)；这里仅维护本篇任务分配。
