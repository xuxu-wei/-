## 1. 定位、先修与学习目标

入口为多变量线性化与数值检查。教学主线为“平衡与吸引域 → 吸引子（attractor）的统一语言 → 周期吸引与分岔 → 离散混沌（discrete-time chaos） → 稳定性与有界性 → 连续时间混沌（continuous-time chaos）与奇异吸引子（strange attractor）”。原五章的编号和顺序保留；4.1 在已有两个小节之后增加概念桥接，4.5 的函数沿轨迹变化为 4.6 的有界性分析提供依据。

前三组生命系统案例继续承担机制迁移；洛伦兹系统（Lorenz system）作为来源明确的热对流简化模型与数值基准单独引入，不把它的三个变量解释为生理量。原流体方程的完整截断推导留到具备偏微分方程背景后的拓展阅读，本篇从给定的三维常微分方程完整分析。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 解释长期去向 | 求平衡，区分吸引子、吸引域与单条轨迹，检验集合吸引与初值依赖 | 定义反例、点到集合距离与初值扫描题 |
| T2 区分动态行为 | 区分衰减、受迫、自维持及非周期行为，用分支与返回记录连接参数和长期运动 | 周期、定向截面计算与分岔条件题 |
| T3 核验混沌证据 | 实现离散与连续敏感性分析，分开初值误差、积分误差和长期几何，不凭一幅图认定混沌 | 短时收敛、分段增长率及证据组合题 |
| T4 限定解析结论 | 检查稳定性函数与有界性函数的不同用途，说明局部、吸引、有界及混沌结论各自需要的条件 | 导数恒等式、区域条件及结论边界题 |

### 4.1 多稳态与吸引域

- **直接先修**：3.4；导数、解析解、平衡与局部线性化。
- **数学索引**：数04、数08、数43。
- **教学目标**：区分平衡点、局部稳定与吸引域，解释同一参数下的初值依赖；4.1.3 补充吸引子、不变集与点到集合距离的统一解释，并以纯旋转区分不变与吸引。

- **核心实验**：以无量纲开关模型 dx/dt = x − x³ 建立直觉，再说明与理想基因开关的类比及不能直接对应的生物量。
- **练习 E1（选择题）**：对 dx/dt = x-x³，从平衡、局部导数及精确/扰动初值的结论中选择正确项。
- **练习 E2（计算题）**：对给定初值列表与观察时刻返回题定模型的终值及按规定阈值分类的状态；包含接近不稳定平衡的初值。
- **练习 E3（选择题）**：加入给定恒定偏置后，选择符合平衡分析和流向图的吸引域结论，辨认有限网格无法支持的断言。
- **核验与反馈**：无偏置时平衡为 −1、0、1；非零稳定点两侧的方向与局部导数应一致；初值网格只提供边界的数值近似。

新增 4.1.3“从长期去向到吸引子的统一语言”先建立点到集合距离，再给出本篇采用的定义：吸引子是吸引某个开邻域且作为集合稳定的非空紧不变集。先用有限维空间中的“闭且有界”解释紧性；作为集合稳定指：任给到集合的容许距离，都能找到足够小的初始距离，使后续轨迹始终不超过该容许距离。说明不变集（invariant set）与仅向前不变的区域的区别；吸引域（basin of attraction）是长期趋近该集合的初值集合。集合稳定性的条件在 4.5 用邻域语言回扣，不要求先学一般拓扑。给出一个点与一个圆的精确距离，区分“趋近集合”与“轨迹彼此同步”；反例包括不稳定平衡、无阻尼中心的一条闭轨道，以及仅被有限轨迹访问过的点云。不同文献的吸引子定义可能增加最小性等条件，本篇的约定须明确，不能仅凭有界或不变就称吸引子。

该小节提供四题：两道选择题检查定义与反例，两道 Python 题分别计算到有限平衡点集和给定圆的距离；每题独立给定集合及输入点，以直接代数式核验。现有 4.1.1—4.1.2 的题目保持原样；4.2 教学用径向解析式把稳定极限环接回这一语言，不改变已有题目契约。

### 4.4 混沌与可预测范围

- **直接先修**：4.3、2.4；离散递推、导数、自然对数与数值误差。
- **数学索引**：数02、数05、数08。
- **教学目标**：在确定性映射中测量邻近初值的分离，区分初值误差、数值误差与随机机制。
- **内容顺序**：① 离散种群映射与参数范围；② 邻近轨迹及有限时间增长率；③ 有限精度、饱和分离和预测阈值，说明与连续 ODE 的差别。
- **核心实验**：使用 xₙ₊₁ = rxₙ(1 − xₙ)，明确 x 为无量纲比例、r 为每步参数；对照周期区域和不规则区域。
- **练习 E1（选择题）**：从有界轨迹分离、初值敏感性及有限时间增长率的说法中选择成立项，不把距离饱和误判为不敏感。
- **练习 E2（计算题）**：输入 logistic 映射参数、两初值、误差阈值和最大步数，返回首次超阈值步数及约定距离序列；未超阈值按契约返回。
- **练习 E3（选择题）**：从离散映射和连续 ODE 的误差检查方案中选择适用项，辨认对原映射错误使用“减小积分步长”的做法。
- **核验与反馈**：有限时间增长率仅作为指定轨迹与窗口下的数值证据；不得引入尚未学习的随机统计结论来证明混沌。

### 4.5 用 Lyapunov 函数分析稳定性

- **直接先修**：4.4、3.4；梯度、链式法则、二维旋转与范数。
- **数学索引**：数08、数09。
- **教学目标**：逐项检查候选函数的正定性、沿轨迹导数与适用区域，区分稳定、渐近稳定及证据不足。
- **内容顺序**：① 能量式函数的直觉与定义；② 多变量链式法则计算沿轨迹导数；③ 检查条件和区域，区分 Lyapunov 函数与 Lyapunov 指数。
- **核心实验**：先用 dx/dt = −x、V = x²/2 做完整论证，再尝试二维偏差系统和不能直接得出严格衰减的候选函数。
- **练习 E1（选择题）**：从候选函数、沿轨迹导数及稳定性结论中选择满足给定区域条件的组合，区分 Lyapunov 函数与指数。
- **练习 E2（计算题）**：对 dx/dt=-x+x³ 和 V=x²/2，在输入点返回 V、沿轨迹导数与严格衰减布尔标记；边界 ±1 和 0 单独测试。
- **练习 E3（选择题）**：给定导数非正但存在非静止轨迹的例子，选择能够得到的结论以及宣布渐近稳定还缺少的条件。
- **核验与反馈**：E2 的严格负导数区域为 0 < |x| < 1；区分解析符号判断与网格采样，后者不能证明区域内处处成立。

### 4.6 连续时间混沌与奇异吸引子

- **直接先修**：4.5、2.4、3.4；吸引子与吸引域、周期运动、离散增长率、雅可比矩阵（Jacobian matrix）和函数沿轨迹导数。
- **数学索引**：数05、数08、数09、数43、数44、数45。
- **教学目标**：分析洛伦兹系统（Lorenz system）的平衡、对称性与有界性，显式实现连续求解和切向扰动更新，结合截面、增长率及误差检查解释奇异吸引子的几何与混沌证据。
- **内容顺序**：① 连续流与维数条件，说明平面自治系统的限制及外部周期驱动的例外；② Lorenz 方程、变量含义、平衡与局部稳定；③ 有界性和体积收缩，区分集合吸引与内部轨迹分离；④ 显式积分、短时收敛与有限预测期限；⑤ 定向截面、返回关系、分段切向增长率与奇异几何；⑥ 汇总解析、数值与引用定理的证据边界，对照稳态、周期与混沌。
- **核心实验**：采用 σ=10、β=8/3 的无量纲 Lorenz 方程，比较 ρ=0.5、10、28；固定普通初值、邻近初值及精确平衡初值，记录暂态和观察时域。将单轨迹、成对距离、定向截面和增长率联动，与前章解析周期振子对照。
- **练习 E1（选择题）**：给定参数、平衡、散度和有限轨迹，选择能支持的结论；识别负散度等于所有方向收缩、存在不稳定平衡就没有吸引子等误解。
- **练习 E2（计算题）**：输入正参数及状态列表，返回向量场、雅可比矩阵 和题定有界性函数的沿轨迹导数；零状态、非零平衡、对称状态均有独立代数核验。
- **练习 E3（选择题）**：比较步长细化、截面、窗口和切向增长率的结果，判断连续时间混沌的证据范围；区别奇异几何、轨迹敏感性和吸引性，识别尚不能从有限实验得到的严格结论。
- **核验与反馈**：以平衡残差、对称关系、沿轨迹导数恒等式及解析线性方程验证实现；短时间窗比较积分器和步长，长时间比较限定的几何与时间摘要，不要求混沌轨迹长时逐点重合。单次正增长率、蝴蝶形图像、负散度均不能独自证明奇异吸引子存在。

#### 模型、数学桥接与可独立核验量

核心模型为

$$\dot x=\sigma(y-x),\qquad \dot y=\rho x-y-xz,\qquad \dot z=xy-\beta z,$$

其中状态、时间与参数均按给定缩放无量纲化。x 表示对流强度，y、z 是温度场相关模态的幅度；负值不是“负浓度”，ρ 不是人口增长率。σ、ρ、β 均取正值；原点始终为平衡，ρ>1 时另有 $(\pm\sqrt{\beta(\rho-1)},\pm\sqrt{\beta(\rho-1)},\rho-1)$，两处符号配对。局部稳定性从 雅可比矩阵 分析，不将某次参数扫描跳变直接命名为混沌起点。

有界性推导使用 $W=\rho x^2+\sigma y^2+\sigma(z-2\rho)^2$，独立核对

$$\dot W=-2\sigma[\rho x^2+y^2+\beta(z-\rho)^2-\beta\rho^2].$$

进一步由配方得到 $\dot W\le-cW+C$，其中 $c=\min(2\sigma,2,\beta)>0$、$C=4\sigma\beta\rho^2$；用积分因子推出 $W(t)\le W(0)e^{-ct}+(C/c)(1-e^{-ct})$。任取 $K>C/c$，相应子水平集给出最终进入并保持的有界区域。这里 W 的用途是约束轨迹范围，不能据此宣布所有轨迹收敛到同一平衡。散度为 $-(\sigma+1+\beta)$，需另用例子说明总体体积收缩与某个方向伸长可以同时成立。

数43 在 4.1.3 首次建立；数44 的散度、连续变分方程和对数伸长分别在 4.6.2、4.6.4 建立；数45 的 RK4、时间网格对齐与定向交点插值在 4.6.2—4.6.3 建立。连续方向增长率使用 $\sum_i\log(\|\delta_i^-\|/\varepsilon)/\sum_i\Delta t_i$，其中每段起始范数为 ε，终点向量归一后进入下一段；明确初始方向、方向预热与暂态，零向量输入不合法。有限窗结果不标作严格渐近指数，也不能承诺任意初始方向都给出最大指数。

计算题按确定性小步骤判分：显式公式、单步/短窗积分、给定轨迹的事件提取、给定伸长序列的汇总。交点契约为 $z_i<c\le z_{i+1}$，按线性插值返回同一交点的时间和状态，严格递增时间戳、无交点及边界重复规则公开；相切轨迹与过粗采样可能漏检需解释。代码题不通过“生成足够像蝴蝶的图”“长时轨迹逐点相同”或某次实验指数超过阈值判分，容差以独立参考和短窗误差标定。

另给一个准周期（quasiperiodicity）反例：两个相位满足 θ′=1、φ′=√2，在两圆的乘积上运动。说明该轨道非周期、相位差却不指数增长，因此非周期本身不等于混沌；这个不变环面是否吸引邻近状态还需检查横向动力学，不由轨道图直接决定。相位与两圆乘积的含义在此用已有圆周运动解释，完整环面与频率共振理论为拓展。

核心学习需能推导上述恒等式、实现并验证有限实验。吸引子的严格存在性及几何结构引用原始研究，庞加莱–本迪克松完整证明、分形维数严格理论、全部 Lyapunov 谱和计算机辅助证明均是拓展，不成为后续课程的隐含先修。
