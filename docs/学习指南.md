# 学习指南

先按 [README 的安装说明](../README.md#run-m1)准备环境，再从 [样章第一节：系统边界、变量与单位](../notebooks/samples/accumulation-clearance/01-boundaries-units.ipynb)按顺序学习。样章可供学习和制作参考，独立于尚待编写的正式教材。Notebook 是完整教学入口，练习和可视化是它的配套入口。

## 在 Notebook 中学习

在支持 Notebook 的 IDE 中打开文件，选择项目 `.venv` 的 Python 内核，按顺序运行单元格。需要检查自己的修改时，重启内核并运行全部单元格；每节的代码都可单独运行。遇到环境或安装问题回到 README，不需要在每一节重新安装。

正文中的 Python 代码可以修改；图中 `Amount` 表示物质量，`Time` 表示时间。图轴上的 U 与 T 是教学单位，具体含义和假设在各节正文中说明。

## 打开可视化与练习

在项目根目录启动本机程序，并保持终端运行：

```powershell
.\.venv\Scripts\python.exe tools/serve.py
```

- [概念可视化](http://127.0.0.1:8000/samples/accumulation-clearance/explore/)：在浏览器中观察存量、流量和数值步长。
- [单元练习](http://127.0.0.1:8000/samples/accumulation-clearance/practice/)：选择题提交后查看逐项解析；代码题可用示例试算或提交完整判定。每节 Notebook 也有指向具体题目的链接。

点击这些 HTTP 链接应显示网页；不要把项目中的 HTML 源文件当作教材阅读入口。如果显示源码，先核对打开的是否为以上本机地址。连接失败时检查本机程序是否运行；更新后需停止旧程序再启动。

网页中的“在默认 IDE 中复习本节”通过系统的 `.ipynb` 文件关联打开 Notebook 原文件。若没有关联，使用系统的“打开方式”选择支持 Notebook 的 IDE。

## 保存练习与复习

代码草稿保存在当前浏览器。正式作答记录保存在本机 `.local/learning/`，不会同步到 Git；样例通过不计入正式通过。刷新或返回题目后可继续编辑，旧判定仍对应提交时的代码或选项。

选择题只有单选和多选；计算题按题面返回指定数据。题面中的解释、预测和迁移能力通过选项辨析或代码结果核验，无需上传自由报告。

## 目录、进度和代码编辑

从[全书目录](http://127.0.0.1:8000/)按篇章跳转。正式章节目前提供重点与知识体系导览；制作样章单列。页面自动展开当前目录，章内用“本章导览 / 可视化与探索 / 练习”切换。灰色是未开始，橙色是进行中，浅蓝色是全部题目完整通过；阅读页面不自动增加进度，样章不计入正式课程。

练习按小节和题目标题选择。编辑代码时，Tab 插入四个空格，Shift+Tab 取消缩进，Enter 延续当前缩进；先按 Esc 再按 Tab 可把焦点移出编辑器。输入输出示例默认折叠，用于说明函数如何接收、返回数据。先“用示例试算”，再“提交判定”；仅通过示例不表示整题完成。
