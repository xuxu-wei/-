# 学习指南

先按 [README 的安装说明](../README.md#run-m1)准备环境，再从[第 1 篇 Notebook 目录](../notebooks/01-看见系统/README.md)按顺序学习。Notebook 是完整教学入口，练习和可视化是它的配套入口。第 1 篇之后继续[第 2 篇 Notebook 目录](../notebooks/02-系统随时间演化/README.md)。

## 在 Notebook 中学习

在支持 Notebook 的 IDE 中打开文件，选择项目 `.venv` 的 Python 内核，按顺序运行单元格。需要检查自己的修改时，重启内核并运行全部单元格；每节的代码都可单独运行。遇到环境或安装问题回到 README，不需要在每一节重新安装。

正文中的 Python 代码可以修改；图中 `Amount` 表示物质量，`Time` 表示时间。图轴上的 U 与 T 是教学单位，具体含义和假设在各节正文中说明。

## 打开可视化与练习

在项目根目录启动本机程序，并保持终端运行：

```powershell
.\.venv\Scripts\python.exe tools/serve.py
```

- [概念可视化](http://127.0.0.1:8000/chapters/02-04-数值模拟、误差与迁移/explore/)：以 2.4 为例，比较连续解析解与数值步长造成的偏差；其他探索页从对应章进入。
- [单元练习](http://127.0.0.1:8000/chapters/02-04-数值模拟、误差与迁移/practice/)：选择题提交后查看逐项解析；代码题可用示例试算或提交完整判定。每节 Notebook 也有指向具体题目的链接。

点击这些 HTTP 链接应显示网页；不要把项目中的 HTML 源文件当作教材阅读入口。如果显示源码，先核对打开的是否为以上本机地址。连接失败时检查本机程序是否运行；更新后需停止旧程序再启动。

网页中的“在默认 IDE 中复习本节”通过系统的 `.ipynb` 文件关联打开 Notebook 原文件。若没有关联，使用系统的“打开方式”选择支持 Notebook 的 IDE。

## 保存练习与复习

代码草稿保存在当前浏览器。正式作答记录保存在本机 `.local/learning/`，不会同步到 Git；样例通过不计入正式通过。刷新或返回题目后可继续编辑，旧判定仍对应提交时的代码或选项。

选择题只有单选和多选；计算题按题面返回指定数据。题面中的解释、预测和迁移能力通过选项辨析或代码结果核验，无需上传自由报告。

## 目录、进度和代码编辑

从[全书目录](http://127.0.0.1:8000/)按篇章跳转。第 1—3 篇提供完整教学，其余篇目前提供设计导览。页面自动展开当前目录，章内用“本章导览 / 可视化与探索 / 练习”切换；没有额外可视化的章节只显示导览和练习。灰色是未开始，橙色是进行中，浅蓝色是全部题目完整通过；篇进度包含篇末题组。阅读页面不自动增加进度。样章已从教学入口移除，历史记录保留在本地且不计入正式课程。

练习按小节和题目标题选择。编辑代码时，Tab 插入四个空格，Shift+Tab 取消缩进，Enter 延续当前缩进；先按 Esc 再按 Tab 可把焦点移出编辑器。输入输出示例默认折叠，用于说明函数如何接收、返回数据。先“用示例试算”，再“提交判定”；仅通过示例不表示整题完成。

## 环境与已有虚拟环境

`.venv` 只有执行 README 的学习依赖安装后，才包含当前已交付内容需要的包；新篇引入依赖时按说明更新，不承诺预装未来全书环境。当前第 1—3 篇已在同一 Python 3.13 环境验证，依赖快照为 [constraints.txt](../tools/constraints.txt)。需要复现该组合时，可在安装命令末尾加 `-c tools/constraints.txt`。

VS Code 的终端解释器和 Notebook 内核分别选择；其他本地虚拟环境不会因打开本工作区而消失。解释器列表未显示时，使用“Python: Select Interpreter → Enter interpreter path”选择它的 `python.exe`；Notebook 右上角使用“Select Kernel → Python Environments”选择对应环境，并确保该环境安装了 ipykernel。未找到环境不等于需要重新创建或删除环境。新版 Python Environments 扩展也可通过用户级 `python-envs.globalSearchPaths` 添加工作区外的环境目录，再刷新环境管理器；具体入口见 [VS Code 环境说明](https://code.visualstudio.com/docs/python/environments)与[内核选择说明](https://code.visualstudio.com/docs/datascience/jupyter-kernel-management)。
