# 第 8 篇：目标、优化与约束

本文为篇章大纲，教学内容尚待实施。章号、数学与参考编号见[教材设计](教材设计.md#part-08)，实施与验收见 [M9](../ROADMAP.md#milestone-m9)。前篇：[07-反馈、估计与控制](07-反馈、估计与控制.md)；后篇：[09-网络上的系统](09-网络上的系统.md)。

本篇全部习题只使用选择题和提交 Python 代码的计算题。E1—E3 仅是维护者记录概念、实现和迁移出题方向的索引，不向学生展示。每节配置 3—5 道题，重难点优先 4—5 道；本大纲的章级三条设计不限制最终题量。选择题提交后显示判定与逐项解析，计算题在本机教材 Python 子进程中按公开契约运行判定，作答以 JSON 文件记录。核心实验是 Notebook 讲解与演示内容，核验提示用于标准答案和程序测试，不增加报告或自由文本提交。规则见[本地判题系统设计](交互练习与判题系统设计.md)；每章均有独立网页和练习入口，页面及 Notebook 图表共同遵循[网页与图表设计规范](网页设计规范.md)。

## 1. 定位、先修与学习目标

先明确目标和约束，再从静态优化走向动态规划、LQR 与 MPC。数19、数20 在本篇首次引入；连续时间最优控制的完整推导作为拓展，不成为后续核心任务的隐含先修。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 写出可检查的优化问题 | 定义变量、目标、单位、约束和可行性，核验梯度与最优性条件 | 目标/梯度计算与条件题 |
| T2 推导动态决策 | 完成有限时域 Bellman 与 Riccati 递推，解释权重和终端代价 | Riccati 测试与价值辨析 |
| T3 实施滚动约束控制 | 构造 MPC，检查求解状态、约束残差与模型失配 | MPC 可行性与数值测试 |
| T4 公平比较方法 | 在相同信息、输入约束和预算下比较 PID、LQR、MPC | 统一评价函数与协议选择 |

## 2. 各章内容、实验与练习

### 8.1 从目标函数进入优化

- **直接先修**：3.4、6.4、7.3；数学：数08、数17、数19。
- **教学目标**：定义目标、约束和决策变量，理解梯度、Hessian、二次型、凸性与正则化，说明最优性结论的条件。
- **内容顺序**：① 跟踪误差与输入代价的尺度；② 梯度、曲率与凸优化直觉；③ 等式/不等式约束、可行性、最优性条件及求解状态。
- **核心实验**：低维二次目标先用解析或网格方法核验，再调用求解器；显式构造不可行情形。
- **练习 E1（选择题）**：最小化 (x-2)²+0.5x²，选择无约束解及 0≤x≤1 时的解和约束是否活跃的正确组合。
- **练习 E2（计算题）**：输入正定二次目标参数与题定盒约束，返回目标、解析梯度及限定小问题的最优解；用独立枚举/解析值检查。
- **练习 E3（选择题）**：从互相冲突约束的求解结果与处理方案中选择正确项，辨认将最后迭代值当可行解的错误。
- **核验与反馈**：E1 解分别为 4/3、1；需要同时检查可行性和目标值，求解器返回成功也须核对约束残差；最优性条件写出适用假设。

### 8.2 动态规划与 LQR

- **直接先修**：8.1、7.3；数学：数07、数19、数20。
- **教学目标**：从一步决策推到有限时域 Bellman 递推，以二次价值函数推导离散 Riccati 递推与反馈增益。
- **内容顺序**：① 有限时域与终端代价；② 倒推价值和最优决策；③ LQR、权重正定条件及有限/无限时域区别。
- **核心实验**：标量两步问题手算，与枚举控制网格及矩阵递推对照，再扩展到二状态人工调节模型。
- **练习 E1（选择题）**：对 x_next=x+u、阶段代价 x²+u²、终端代价 x_next²，选择单步 Bellman 推导、最优输入和价值函数的正确项，辨认遗漏终端代价。
- **练习 E2（计算题）**：输入离散线性模型、Q、R、终端权重与时域，返回 Riccati 和反馈矩阵序列；核验维数、对称性与小例子最优值。
- **练习 E3（选择题）**：给定无约束 LQR 与饱和后轨迹，选择原最优性结论仍然成立或失效的条件。
- **核验与反馈**：E1 最优 u = −x/2、价值为 3x²/2；Riccati 结果与小问题独立计算一致，不能将截断输入后的方案继续称为原约束问题的最优解。

### 8.3 带约束的 MPC

- **直接先修**：8.2、7.5；数学：数19、数20。
- **教学目标**：将预测模型、初始估计、时域和约束写成优化问题，理解每次只执行第一步并重新求解。
- **内容顺序**：① 状态与输入序列的优化表达；② 滚动时域及估计接口；③ 软硬约束、不可行、超时和模型误差的处理。
- **核心实验**：对相同人工模型比较无约束、输入约束和状态约束版本；同时记录预测轨迹与实际轨迹。
- **练习 E1（选择题）**：从滚动预测、模型误差与实际约束满足的关系中选择正确项，排除一次可行即永久可行的推断。
- **练习 E2（计算题）**：对限定的小型 MPC 问题返回求解状态、首步输入、目标值与约束残差；不可行情形返回题定状态，允许等价最优解。
- **练习 E3（选择题）**：从软硬约束、罚项与备用策略的说法中选择正确项，判断各方案改变了什么问题。
- **核验与反馈**：不得默认可行性或稳定性；如采用备用控制，必须独立说明其适用域并核验；禁止用未经核验的上次解掩盖求解失败。

### 8.4 估计、控制与模型误差的综合比较

- **直接先修**：8.3、6.5；数学：数11、数17、数19。
- **教学目标**：构造公平基线，区分调参条件和独立评估条件，综合解释性能、约束与计算代价。
- **内容顺序**：① 固定任务、信息和执行接口；② 验证集调参、独立场景评估；③ 成本、约束、稳健性和运行预算的联合报告。
- **核心实验**：PID、LQR、MPC 共享观测、扰动场景和实际输入上限；需要状态时共享同一估计器，说明不同方法实际使用的信息。
- **练习 E1（选择题）**：从 PID、LQR、MPC 的候选评估协议中选择观测、约束、调参预算和独立评估一致的方案。
- **练习 E2（计算题）**：输入多方法配对场景的状态、目标与实际控制序列，返回跟踪误差、输入代价、约束违反和失败统计。
- **练习 E3（计算题）**：对固定的独立失配场景及结果表实现题定比较函数，返回方法差值与不确定性摘要；不能剔除失败场景。
- **核验与反馈**：计划以不少于 30 组独立随机场景估计波动，实施时按不确定性和预算调整并记录；方法间共享场景不等于场景之间重复使用同一序列。

## 3. 篇末综合任务：约束控制与公平比较题组

固定 PID、LQR、MPC 任务、观测、执行限制及调参/评估边界。选择题判断优化条件与比较协议；Python 题实现 Riccati、有限 MPC 或统一评价子题；给出失配结果并选择性能、约束与预算的正确解释。

覆盖 T1—T4；多解以可行性和目标/残差判定，不强求某一实现的控制序列，失败场景不可从评估中删除。

本篇综合题组按以下八题设计，具体题面与测试随本篇交付。统一计分、等级、首次与练习成绩的区别见[篇末分层评分](教材设计.md#capstone-assessment)；这里仅维护本篇任务分配。

| 层次 | 子题与分值 | 形式 | 主要计分目标 | 核验与反馈重点 |
|---|---|---|---|---|
| 1 基础辨析 | 1. 目标、单位与可行性（10 分） | 选择 | T1 | 辨认决策变量、目标和约束。 |
| 1 基础辨析 | 2. 什么算公平比较（10 分） | 选择 | T4 | 固定信息、输入限制与调参/评估边界。 |
| 2 方法应用 | 3. 梯度与最优性检查（15 分） | Python | T1 | 给定小型目标，核对梯度和约束残差。 |
| 2 方法应用 | 4. 有限时域 Riccati 递推（15 分） | Python | T2 | 给定权重和终端项，返回递推结果。 |
| 3 综合验证 | 5. 滚动求解的第一步控制（15 分） | Python | T3 | 有限规模 MPC；按可行性、目标与残差核验多解。 |
| 3 综合验证 | 6. 统一评价三种策略（15 分） | Python | T4 | 给定相同条件的结果，计算跟踪、输入与违约指标。 |
| 4 迁移挑战 | 7. 改变终端条件后的决策（10 分） | 选择 | T2 | 比较时域、权重及终端代价的适用结论。 |
| 4 迁移挑战 | 8. 失配或不可行时怎样比较（10 分） | 选择 | T3 | 新约束下检查求解状态、失败处理与评价范围。 |

主要计分目标按上表归属，相关知识可跨目标；每题输入完整，独立提交。未通过题按层次回到对应目标的章节复习；本表不调整章内习题。
