# 教材制作检查表

本表用于编写与发布已有教学内容，依据 [AGENTS](../AGENTS.md)、[教材设计](教材设计.md#lesson-standard)和[网页设计规范](网页设计规范.md)。检查的是读者实际看到和使用的成品，不把设计文档或文件存在当作教学验收。

## 1. 内容位置

- [ ] “学习目标与先修知识”仅包含能够学会的知识/能力、直接先修及复习入口。没有网页安排、安装命令、内核说明、运行时间、版本、实现状态或验收提示。
- [ ] 问题、模型假设、推导、代码、对照实验和结果解释各归其位。必要导入代码出现在第一次使用前，算法步骤在 Notebook 中可见。
- [ ] 环境和打开方式集中在 [README](../README.md#run-m1) 与[学习指南](学习指南.md)；制作决策在设计文档；进度与证据在 ROADMAP。学习正文不向读者交代开发计划。

## 2. 练习成品

- [ ] 每题明确为单选、多选或 Python 计算；前两者均属于选择题。概念、实现和迁移是教学目标，不是额外题型。
- [ ] 选择题具有完整选项、唯一正确集合和逐项解析；代码题具有函数契约、单位、输入输出、公开样例、允许库、容差及实际限制。
- [ ] 每道代码题在题面给出带类型的 `def solve(具名参数)`，并逐项解释含义与单位；所求结果、返回类型/顺序、规则、约束与样例解释分开呈现。不能用 `payload`、通用 `data` 或可变参数代替参数设计。
- [ ] 实际复制代码模板并按展示的具名参数调用；参考解、样例、补充测试和判题器一致，没有旧字典接口或临时适配器。单一结果直接返回标量/列表，多项结果的命名与顺序明确。自动检查拒绝包装接口及签名漂移。
- [ ] 函数接口变化后升题目版本；旧草稿可找回，旧记录保留，新题不沿用旧通过状态，旧页面提交收到版本更新提示。
- [ ] Notebook 内保留自洽题面，每题有“作答”链接，直接进入相同题号和版本的页面；不能用目录、未来入口、源码或仅答案文档替代。
- [ ] 题面、页面、参考解与测试使用同一版本。以 `exercises/<篇目录>/questions.json` 为公开题面来源，通过 `lesson_exercises.render_exercises` 生成 Notebook 题面，避免双份题面漂移。
- [ ] 实际尝试正确/错误选项、样例/完整提交和错误代码。解析、失败差异及提交快照能帮助纠错；样例通过不计完整完成，取消、系统错误和写入失败不误记成绩。

篇末综合另按[分层评分规范](教材设计.md#capstone-assessment)检查：

- [ ] 由易到难排列，逐题目标、分值、独立输入及核验材料齐全；分层、目标与总分合计一致。章内习题没有随综合评分调整。
- [ ] 实际完成“首次答错 → 订正通过”，确认首次分保留、练习分增加且不重复累计；样例、取消、故障、未保存不计分，实质改题的旧版本隔离。
- [ ] 首轮未完成、基础缺口、全组完成、历史记录与损坏记录均按规范显示；分层/目标明细、答题与复习链接可用，刷新及重启后结果一致，原有个人记录保持不变。

## 3. 链接打开的对象

| 入口 | 预期结果 | 不合格结果 |
|---|---|---|
| Notebook → 可视化 | 本机 HTTP 地址在浏览器显示渲染页面 | IDE 打开相对 `.html` 文件、HTML 源码、下载文件 |
| Notebook → 某道练习 | 对应题号的实际答题界面 | 空页、泛目录、仅核验提示、题号不匹配 |
| 网页 → Notebook | 系统默认 IDE 打开项目原 `.ipynb` | 浏览器源码/Notebook、下载副本、无反馈 |

- [ ] 从渲染后的 Notebook 实际点击链接，不只检查字符串或文件存在。记录地址、题号/页面标题与打开结果。
- [ ] HTML 响应是 `text/html`，脚本能完成初始化；直接打开、刷新深链接与往返导航都有效。
- [ ] 点击播放后时间、存量高度和轨迹实际变化；暂停保持不变，重播可用；加载或本机连接失败给出恢复说明。PC 鼠标与键盘均可操作。

## 4. 专业术语

- [ ] 每个独立 Notebook、概念页及可直达题目的正文首次使用专业术语时，按[术语规范](教材设计.md#terminology-style)标注英文全称与必要的通行缩写；学习目标中的首现也算，标题和导航无需长括注。
- [ ] 首次引入解释概念、单位、用途及适用条件；英文括注不能替代教学解释。后文统一中文或选定的缩写。
- [ ] 扫描新引入而尚未收入[术语表](术语对照.json)的概念；查证通行写法后补入。检查正文、题面、解析与图注一致，避免自动替换损坏普通词语。

## 5. 执行与证据

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe tools/check_teaching.py
.\.venv\Scripts\python.exe tools/check_notebooks.py --part 01-看见系统 --work m3-part01 --write
.\.venv\Scripts\python.exe tools/check_notebooks.py --part 02-系统随时间演化 --work m3 --write
.\.venv\Scripts\python.exe -m pytest -q
```

第一项检查全部已交付正式题面、目标区、两类题、深链接与词表术语首现；随后按篇分别启动新内核并保存输出；pytest 检查数学、本机入口和判题异常。新增篇时使用相应目录，不把检查范围固定为前两篇。JavaScript 模型与共用组件另运行 `node --test tools/tests/*.test.mjs`。按改动范围选择检查，不为单纯文档调整新增程序测试。

程序检查通过后，人工查看 Notebook 正文、公式和图，完成上表的实际点击。将检查环境、范围、结果、未覆盖事项及交付文件摘要记录到 `docs/validation/`，再更新 ROADMAP 与 README。模拟数据、个人草稿、作答记录及临时预览不进入同步内容。

## 6. 内容生命周期、目录与交互回归

- [ ] 正式学习入口无样章依赖；退役内容的路由与导航同步移除，个人历史记录保留且不误计当前进度，历史证据链接到固定版本。
- [ ] 篇章文件夹包含内容名称，不仅是 m1/m2；每节 3—5 题，重难点更多，记录题目对应的知识或常见误解。
- [ ] 从导览、可视化、练习三个页面确认同一导航与布局，当前祖先展开、选中项可见；直接深链接、刷新与前进后退仍定位正确。题目和章节标题可理解，不出现 S01/E01 等内部编码。
- [ ] 章导览显示目标、重难点和知识体系。未交付正式内容明确标注，不将设计导览计为正式教学完成。
- [ ] 全书的每张篇卡片有“第 N 篇”，各篇的每张章卡片有“篇.章”，编号、名称、顺序与侧栏一致。检查全部 12 篇、55 章；首屏标题与网格紧凑，没有固定高度造成的空卡片、过大间距或长标题截断。
- [ ] 用真实作答检查灰色未开始、橙色进行中、浅蓝色已完成；跨页/刷新保持一致。空题组、样例通过、取消、写入失败或旧版本不能冒充完成；样章不改变正式篇章进度。
- [ ] 代码实际输入检查 Tab、Shift+Tab、多行选区、Enter、Esc 后 Tab，以及行首 Backspace 的四空格、部分缩进与 Tab 删除；普通文本不整段误删。实际检查括号补全、跳过已有闭括号、空括号成对删除和匹配标记；Python 关键字、字符串、数字与注释有可读的 Monokai 高亮。检查撤销/重做、中文输入、切题和刷新保留草稿、恢复模板可撤销。
- [ ] 真实点击“用示例试算”和“提交判定”：结果在代码区上方展开并可见，可收起/展开，继续编辑不被抢焦点。提交缺少冒号、缩进错误、运行异常和嵌套调用代码，核对 traceback 的源码、行号、箭头、调用链及复制；定位后光标和行标记对应源码，修改草稿后停用旧行号定位并说明结果属于上次提交。旧记录没有 traceback 时仍正常显示，系统故障不伪装成语法错误。
- [ ] 目录可隐藏、展开、鼠标拖宽和键盘调宽，双击/Enter 恢复默认；跨页及刷新保留偏好，窄窗口仍能恢复目录。题目/答题双栏可调节比例，代码区随窗口扩大；各页面主体填满目录以外的可用宽度，无固定宽度造成的大片右侧空白。
- [ ] 使用长代码、长标识符与长输出检查默认自动换行及关闭换行。开关、拖动、复制和下载不修改源码字符或 Python 缩进；单栏时编辑器仍全宽，提交按钮可达。目录变化后图表、标签与动画按实际容器重绘，两栏滚动互不干扰。
- [ ] 输入样例和输出样例各有含义/单位/数据表及 Python 代码；输入含构造与调用，输出含预期结构与原始精度数值。实际复制并运行所有计算题示例，对照题面容差；网页和 Notebook 一致，复制不覆盖草稿，没有整块协议 JSON 替代解释。
- [ ] 展开最大样例，表格和代码限高且内部滚动，代码至少 14 px，不遮题干或作答控件；复制有结果反馈，复制失败仍可手动选取。“用示例试算”的用途和不计完成明确。
- [ ] 成对示例至少往返两次；按钮显示下一步目标，说明显示当前参数；穿插手动改参、减小步长和重置，标签、图形、读数保持一致。2.4 的负值→正值→负值应分别出现第一步 −5、2.5、−5 U，连续模型不变。
- [ ] 错误选择提交后为红字、透明红底；正确、系统错误、取消具有相应不同语义。切换/hover/选中反馈平滑且无持续跳动，减少动画设置有效。
- [ ] PC 1024、1366、1440、1920、2560 宽及短窗口检查主要入口、图形和代码可读性，覆盖目录开关与宽度极值；实际播放/暂停/重播，实际点击 Notebook 默认 IDE 入口。按本轮改动记录实际覆盖事项，不把历史验收写作本轮运行。
