# 第 1 篇：看见系统

本文为篇章大纲，教学内容尚待实施。课程章号、数学索引与参考编号以[教材设计](教材设计.md#part-01)为准；交付顺序与验收状态见 [M2](../ROADMAP.md#milestone-m2)。下一篇：[02-系统随时间演化](02-系统随时间演化.md)。

本篇全部习题只使用选择题和提交 Python 代码的计算题。E1—E3 仅是维护者记录概念、实现和迁移出题方向的索引，不向学生展示。每节配置 3—5 道题，重难点优先 4—5 道；本大纲的章级三条设计不限制最终题量。选择题提交后显示判定与逐项解析，计算题在本机教材 Python 子进程中按公开契约运行判定，作答以 JSON 文件记录。核心实验是 Notebook 讲解与演示内容，核验提示用于标准答案和程序测试，不增加报告或自由文本提交。规则见[本地判题系统设计](交互练习与判题系统设计.md)；每章均有独立网页和练习入口，页面及 Notebook 图表共同遵循[网页与图表设计规范](网页设计规范.md)。

## 1. 定位、先修与学习目标

从可观察的生命现象进入系统建模。读者只需入口 Python 与中学数学；本篇补齐量纲、读图及最小数组和绘图操作（数01），不使用导数、概率或稳定性判据。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 描述系统 | 围绕给定问题辨认合理边界及状态、输入、观测和参数的分类 | 变量表选择题判定 |
| T2 核对收支 | 根据时间段和流率计算存量，定位单位或重复计数错误 | 收支函数测试 |
| T3 解释反馈 | 辨认带作用方向与延迟的反馈结构，判断图中关系的假设性质 | 反馈与延迟辨析结果 |
| T4 设计比较 | 选择能区分两种解释的实验，计算结果并辨认有效结论 | 规则计算与实验方案题组 |

## 2. 各章内容、实验与练习

以下小节是编写顺序建议；每节独立运行并按[小节规范](教材设计.md#lesson-standard)补齐概念、实现和迁移目标对应的客观题。这里列出的设计是各章必须覆盖的练习骨架。

### 1.1 从生理现象提出系统问题

- **直接先修**：入口；数学：数01。
- **教学目标**：把“为什么会变化”改写成含观察对象、时间范围与可测量结果的问题；说明状态与观测的区别。
- **内容顺序**：① 以物质清除和体温变化比较系统边界；② 建立变量、单位、输入、参数与观测表；③ 读取短序列，绘图并解释坐标、尺度和缺失的机制信息。
- **核心实验**：用人工物质量序列绘图，比较改变时间单位与改变系统边界的后果；数值仅用于练习，不代表个体测量。
- **练习 E1（选择题）**：从体温问题的四组边界、状态、输入与观测表中选出全部合理项，辨认把体表测量直接等同内部状态的错误。
- **练习 E2（计算题）**：输入时间列表、物质量列表与时间单位换算因子，返回换算后的 times 与原 amounts；测试包含空序列、不同单位因子及长度保持。
- **练习 E3（选择题）**：给定细胞数量变化场景，从候选问题卡中选出可测量、变量分类正确且不预设机制的方案；提交后逐项解释排除理由。
- **核验与反馈**：变量不能只写符号而不写含义与单位；换单位后的同一时刻必须对应同一物质量；问题卡应包含一个能由观测反驳的预期。

### 1.2 存量、流量与守恒

- **直接先修**：1.1；数学：数01。
- **教学目标**：从一段时间内的输入输出计算存量变化，区分流率和该段累计量。
- **内容顺序**：① 容器与箭头表示“多少”和“多快”；② 按时间段手算收支，再用循环累计；③ 通过单位、边界与总量定位错误，不提前形式化差分方程。
- **核心实验**：复制改编样章“系统边界、变量与单位”中的变量说明和手算收支；加入不等长时段及内部转移重复计数的反例。
- **练习 E1（选择题）**：选择所有量纲正确的收支表达式，辨认缺少时间间隔及重复计算内部转移的选项；示例选项见判题系统设计。
- **练习 E2（计算题）**：输入 initial 与 segments（时长、流入速率、流出速率），返回包含初值的 amounts；公开例为 5 U 经两段后得到 [5, 7, 11]，补充测试含不等时长和空时段。
- **练习 E3（选择题）**：给定两个容器的内部转移、外部输入和外流，从整体及分室收支结论中选择全部正确项，解释内部流量的抵消。
- **核验与反馈**：E2 两段末应为 7 U、11 U；E3 整体净增应为 1 U。出现负存量时检查规则及条件，不能直接裁剪后宣称守恒。

### 1.3 反馈、延迟与层级

- **直接先修**：1.2；数学：数01。
- **教学目标**：根据局部作用方向判断反馈环的符号，并通过规则实验说明延迟可能改变响应。
- **内容顺序**：① 因果箭头是待检验的作用假设；② 比较增强与抵消偏差的回路；③ 用给定人工调节规则观察即时、延迟以及局部与整体响应。
- **核心实验**：提供无需微积分的温度偏差更新模板，每步根据当前或前两步偏差调节；保持其他参数一致，先预测再运行。不在本篇要求一般递推推导。
- **练习 E1（选择题）**：从带符号的回路与关于负反馈的说法中选择正确项，辨认“负反馈必然单调接近目标”的错误。
- **练习 E2（计算题）**：按题面给定的离散温度规则、增益、延迟和初始历史计算 trajectory、最大绝对偏差与转向次数；用零延迟和两步延迟核验。
- **练习 E3（选择题）**：给定两个相互影响的调节环，选择能够导致局部改善但另一变量恶化的路径，以及可用于区分这些机制的观测组合。
- **核验与反馈**：检查环路方向是否由各边关系推出；延迟对照必须使用相同初值、增益与观察长度；有限轨迹只支持该规则下的观察，不作为普遍稳定性结论。

### 1.4 模型假设与计算实验

- **直接先修**：1.3；数学：数01。
- **教学目标**：区分结构改变与参数改变，为一个假设设置对照、观测量和可能的反例。
- **内容顺序**：① 把文字机制转为给定的计算规则；② 区分初值、参数、结构和观测设置；③ 形成“预测—对照—核验—限制”的实验记录。
- **核心实验**：比较每段移除固定量与移除现有量固定比例的两种规则；选取两者都保持非负的短观察区间，记录规则失效的边界。
- **练习 E1（选择题）**：将给定改动对应到初值、参数或结构类别，从候选分类表中选择正确表，并辨认不能由单次拟合得出的结论。
- **练习 E2（计算题）**：输入初值、固定移除量、比例和步数，返回两种规则的轨迹；测试保证不越出模型定义域。公开例初值 10、每步固定移除 1 或移除当前量的 10%，第三步为 7 与 7.29。
- **练习 E3（选择题）**：在给定的第二组初值、观察时刻和控制条件方案中，选择能区分两种清除规则且没有混入额外变量的实验。
- **核验与反馈**：E2 第三段末分别为 7 U、7.29 U；实验须保留事前预测，结论只能覆盖所比较规则与参数。

## 3. 篇末综合任务：系统边界与实验设计题组

固定物质清除、温度调节与细胞数量三个小场景。选择题检查问题、边界、变量、反馈假设和对照方案；Python 题计算指定规则的收支与轨迹；再从结果解释和适用范围选项中选择正确结论。

T1—T4 分别对应变量分类、收支函数、反馈辨析和实验方案选择；不要求上传问题卡、手绘图或文字报告。各子题独立提交和判定；全部必做题通过后记为本版本题组完成。具体格式与发布要求见[客观题评价规范](教材设计.md#assessment-design)和[判题系统设计](交互练习与判题系统设计.md)。

## 4. 教学资源与衔接

- **Notebook 与样章**：可复制样章“系统边界、变量与单位”的部分讲解和收支实验，改写为 1.1—1.2 的独立正式 Notebook；正式入口不链接样章。第 1 篇新增反馈和实验设计内容。
- **网页安排**：所有章都有独立页面、章内练习与篇末题组入口；以下仅说明可视化模块的取舍。1.1、1.4 不新增可视化模块；1.2 复制改编样章的存量与流量解释面板，并独立验收；1.3 安排可视化与 playground，以延迟和作用强度联动结构图与轨迹，具体小节在实施时标注。
- **数据与参考**：以手算表和 Notebook 内人工规则为主；使用外部观测时遵循[数据验收](教材设计.md#data-contract)。资料沿用 R01、R02、R09，引用位置在编写时核对并登记。
- **出口**：为第 2 篇提供清楚的收支问题和对照方案；差分方程、导数与一般稳定性留到其首次引入章节。
