# 第 17 篇：研究复现与综合实践

本文为新版篇章大纲，正式教学内容待按 [M18](../ROADMAP.md#milestone-m18) 交付。总目录、数学和参考编号见[教材设计](教材设计.md#part-17)。前篇：[16-自适应、鲁棒与学习控制](16-自适应、鲁棒与学习控制.md)。

教学、术语与题型规则统一引用[教材规范](教材设计.md#lesson-standard)和[练习设计](教材设计.md#assessment-design)；网页与本机执行分别见[网页规范](网页设计规范.md)及[判题设计](交互练习与判题系统设计.md)。E1—E3 是章级出题方向，正式每节题量按总纲实施，核心实验是教学演示，不增加报告或自由文本提交。

## 1. 定位、先修与学习目标

把可检查的研究问题、固定复现协议、公平基线和失效分析组织成小规模研究复现。必做两个互补专题：R18 稀疏动力学辨识（sparse identification of nonlinear dynamics，SINDy）与 R19 神经微分方程（neural differential equation）的低维实验；原论文实验与生命系统课程改编分开报告。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 界定研究主张 | 把主张拆成模型、数据、算法、指标及可证伪条件 | 17.1 的证据和任务边界选择 |
| T2 执行可追溯复现 | 固定论文/代码版本、环境、随机输入和预算，实现关键计算 | 17.2 的两项复现协议与独立参考 |
| T3 诊断收益和失效 | 安排消融、基线和失败实验，量化误差及不确定性 | 17.3 的成对统计和反例 |
| T4 比较并限制结论 | 区分原结果复现、课程改编及迁移，形成证据支持的比较 | 17.4 的固定结果表评价与结论选择 |

## 2. 各章内容、实验与练习

### 17.1 研究问题与证据

- **直接先修**：9.5、13.4、14.5、15.5、16.7；数学：数17、数24。
- **教学目标**：把论文主张转成有明确假设、对象、指标和证据范围的可复现问题。
- **内容顺序**：①固定原论文及版本，区分方法定义、原实验结论与作者解释；②将原问题缩为普通 CPU 可运行的低维实验，声明缩减改变了哪些条件；③形成主张、基线、数据和评价的对应表，区分原结果复现与课程改编。
- **核心实验**：必做案例固定为 R18 的 Lorenz 稀疏方程发现与 R19 的神经常微分方程低维实验；前者沿用 4.6 的动力学知识与 14.4 的实现，但按原论文重新核对采样、导数获取、字典、阈值和评估协议，再将方法迁移到课程生命系统。
- **练习 E1（选择题）**：从原论文摘要片段和候选问题中选择范围明确、可由给定证据检验的主张。
- **练习 E2（计算题）**：输入固定主张清单、实验条件与结果索引，返回按题定匹配规则的覆盖表及缺失项。
- **练习 E3（选择题）**：辨认复现原实验、重实现算法、改变数据的迁移实验及无法验证的宽泛结论。
- **核验与反馈**：原文实验的位置、版本与课程改动逐项登记；不把低维改编实验称为完整复现原论文全部结果，不以方法年代决定是否有效。
- **编写参考**：R18、R19、R28（资料与主题对应见本篇末表）。


### 17.2 复现协议与公平基线

- **直接先修**：17.1；数学：数11、数17、数42。
- **教学目标**：制定能运行且公平的复现协议，隔离训练和评估信息并记录计算预算。
- **内容顺序**：①定义数据、轨迹和随机流的划分边界，固定方法输入与调参资源；②建立显式算法、成熟实现和简单机制基线的对应，核对允许的信息差异；③记录环境、代码版本、参数、种子、重复次数和失败处理，先做最小核验再完整运行。
- **核心实验**：两个必做案例采用公开契约与小规模配置，原实验条件和课程条件分别保存；复用第 14—15 篇组件但使用独立评估数据。神经微分方程的原方法复现采用 15.3 已推导和核验的伴随方法；固定离散求导另列为数值对照或课程改编。
- **练习 E1（选择题）**：选择公平的训练/验证/评估划分及预算协议，识别为某方法提供额外真值。
- **练习 E2（计算题）**：输入轨迹归属、个体和时间边界，返回无交叉的划分索引及协议违规标记；判定规则公开。
- **练习 E3（选择题）**：根据环境或预算差异，选择可重复的比较方案和需要披露的限制。
- **核验与反馈**：索引集合独立交叉检查，训练变换仅由训练数据估计；记录实际运行资源，不预先声称达到尚未测量的性能。
- **编写参考**：R18、R19、R28（资料与主题对应见本篇末表）。


### 17.3 消融、失效与结论边界

- **直接先修**：17.2；数学：数11、数17、数24。
- **教学目标**：通过消融、重复和失效实验定位效果来源，区分统计波动与可支持的机制解释。
- **内容顺序**：①预先确定消融因素、配对场景和评价量，保持其他条件可比；②比较重复效果差和不确定性，保留全部失败与未复现结果；③分别排查模型、数值、优化、数据和评价差异，并限定原因解释的强度。
- **核心实验**：对稀疏发现分别移除稀疏性与改变导数噪声，对神经动力学分别改变求解精度与机制修正；对照表不以有利随机种子筛选。
- **练习 E1（选择题）**：选择能够隔离一个因素的消融方案，识别同时改变数据量和模型结构的混淆。
- **练习 E2（计算题）**：输入固定的配对指标、失败标记和预设分组，返回效果差、标准误或题定重采样（resampling）区间以及失败比例。
- **练习 E3（选择题）**：根据正常和失败条件下的统计结果，判断哪些原因已被实验区分、哪些仍只是猜测。
- **核验与反馈**：小表手算与完整结果汇总对照；配对结构不被打乱，重复次数与不确定性计算一致，不将未复现结果改写为成功。
- **编写参考**：R18、R19、R28（资料与主题对应见本篇末表）。


### 17.4 研究方法综合比较

- **直接先修**：17.3；数学：数17、数24、数27。
- **教学目标**：把机制、推断和学习结果组织为可追溯比较，在新条件下判断结论仍成立的范围。
- **内容顺序**：①以三组贯穿案例整理观测条件、状态/参数问题及可选择的方法；②连接独立评估、预算、失效与不确定性，分别给出可以和不能支持的结论；③形成可再次运行的教材示例与客观综合题，展示完整研究说明但不增加自由报告提交。
- **核心实验**：基于前两项固定复现，将一个方法迁移到二室清除或稳态调节案例；与机制基线共享观测和干预范围，比较误差及守恒/约束。
- **练习 E1（选择题）**：从完整结果表选择证据充分的研究结论，辨认跨任务、跨尺度或跨信息条件的过度推广。
- **练习 E2（计算题）**：输入固定多条件预测与约束结果，返回按公开规则生成的比较指标、消融差和失败统计。
- **练习 E3（选择题）**：根据新观测通道、参数区间或时间尺度，选择需重新验证的环节及可沿用的已证结论。
- **核验与反馈**：关键函数与先前章节的独立参考一致；已知真值仅供核验。研究成果以有限实验及客观题检验，明确区分课程复现、迁移和新研究主张。
- **编写参考**：R18、R19、R26、R28（资料与主题对应见本篇末表）。


## 3. 篇末综合任务：研究复现与证据比较

每题提供独立论文片段摘要、版本信息、输入或结果表。Notebook 演示完整研究流程；读者用选择题和 Python 计算检验复现能力，不提交自由文本报告。

以下为待交付题组设计，统一梯度、分值、等级及首次/练习成绩规则见[篇末分层评分](教材设计.md#capstone-assessment)。章内题不因综合题组调整而改变。

| 层次 | 子题与分值 | 形式 | 主要计分目标 | 核验与反馈重点 |
|---|---|---|---|---|
| 1 基础辨析 | 1. 主张与证据（10 分） | 选择 | T1 | 给出论文主张和实验条件，选择能检验它的指标与反例。 |
| 1 基础辨析 | 2. 复现还是课程改编（10 分） | 选择 | T4 | 区分原任务/求导方法的复现、简化实现和生命系统迁移。 |
| 2 方法应用 | 3. 协议与版本审计（15 分） | 选择 | T2 | 在完整候选协议中识别论文版本、代码提交、数据划分和预算缺口。 |
| 2 方法应用 | 4. 复现关键数值步骤（15 分） | Python | T2 | 给出低维模型、字典/梯度计算契约和固定输入，与独立参考核对。 |
| 3 综合验证 | 5. 消融的配对统计（15 分） | Python | T3 | 输入所有场景结果、固定重采样索引和失败标记，返回差值区间与失败率。 |
| 3 综合验证 | 6. 跨方法公平评价（15 分） | Python | T4 | 给出相同观测预算和任务的完整结果，计算预测、结构、代价与计算指标。 |
| 4 迁移挑战 | 7. 失败能否反驳主张（10 分） | 选择 | T1 | 在改变初值、观测或假设后，判断失败属于范围外还是原主张的反例。 |
| 4 迁移挑战 | 8. 复现实验的结论边界（10 分） | 选择 | T3 | 根据消融和不确定性选出可支持结论，保留负结果，拒绝跨模型过度推广。 |

每题提供独立且完整的输入，不读取其他子题的作答；选择题提供逐项解释，计算题以公开契约、容差及独立参考判定。随机算法提供固定随机数、增量、索引或已生成结果，重复实验效果用于教材解释，不按一次随机效果判分。复习入口按本篇 T1—T4 对应章节建立，正式身份和版本随题库发布。

## 4. 教学资源与衔接

- **网页安排**：17.1 展示主张—证据对应；17.2 展示版本、预算和基线表；17.3 展示消融及失效结果；17.4 展示统一指标对照。网页承载只读协议、可视化和客观练习，不承担长训练或报告上传。
- **数据与案例**：沿用总纲 A（物质交换与清除）、B（稳态与节律）、C（个体与种群）三组生命系统案例；课程生成观测与核验状态/参数分离，同一方法比较使用相同观测、数据划分与预算。
- **独立验证**：两个必做专题各有原文版本、一个原始低维实验、传统基线、独立参考和至少一种失效；课程改编单独标记，不能凭相似曲线宣称复现。
- **出口**：完成全书能力闭环：核心算法可推导、实现、验证，精选现代方法可复现并说明范围；尚未开展的读者试学和外部同行评审不作为课程已达成的学习效果。
