## 2. 各章内容、实验与练习

### 3.1 从多个室进入线性代数

- **直接先修**：2.4；数学：数04、数06。
- **教学目标**：说明向量分量、矩阵元素及维数的物理意义，理解内积、范数、秩和线性方程组。
- **内容顺序**：① 两室交换的逐项收支；② 数组、矩阵乘法与线性映射；③ 内积与投影直觉、秩、平衡方程及唯一性。
- **核心实验**：以物质量 A₁、A₂ 建立正向和反向线性交换，比较逐项循环与矩阵实现；先做封闭交换，再加外部输入和清除。
- **练习 E1（选择题）**：从二室交换矩阵、符号与单位的候选解释中选出正确项，辨认将物质量改为浓度却未引入容积的错误。
- **练习 E2（计算题）**：根据双向交换速率和初始物质量返回 system_matrix、initial_rate 与 total_rate；公开例正向 0.2/T、反向 0.1/T、初值 [6, 0] U，初始变化率为 [-1.2, 1.2] U/T。
- **练习 E3（选择题）**：给定第三室连接方式，从候选三室矩阵中选择内部交换守恒且方向正确的矩阵。
- **核验与反馈**：E2 初始变化率为 (−1.2, 1.2) U/T；封闭系统的平衡要结合初始总量确定，不能把奇异矩阵强行求逆。

### 3.2 线性状态空间与动态模态

- **直接先修**：3.1；数学：数04、数06、数07。
- **教学目标**：写出状态、输入和输出关系，用特征值解释动态时间尺度，并把复共轭模态还原为实轨迹。
- **内容顺序**：① 状态空间和不同观测映射；② 特征向量、矩阵幂与矩阵指数；③ 快慢模态、复数与阻尼振荡，说明不可对角化情况的处理边界。
- **核心实验**：二室模型用于实模态；另给明确标为人工偏差模型的二维阻尼振子，避免暗示普通封闭二室交换必然振荡。
- **练习 E1（选择题）**：给定模态、初值与观测映射，选择解释“某模态在观测曲线中不可见”的正确原因。
- **练习 E2（计算题）**：对题面指定二维阻尼系统返回约定顺序的特征值实部/虚部以及给定时刻的实数状态；公开矩阵 [[-1, -2], [2, -1]] 的特征值为 -1 ± 2i。
- **练习 E3（选择题）**：比较观测 A1 与 A1+A2 的给定轨迹，从有关模态是否存在、是否激发与是否被观测的结论中选择正确项。
- **核验与反馈**：E2 特征值为 −1 ± 2i；模态重建与矩阵指数参考一致；状态负值在偏差模型与物质量模型中含义不同。

### 3.3 耦合、相平面与平衡

- **直接先修**：3.2；数学：数04、数07。
- **教学目标**：从向量场辨认局部运动方向，解释平衡、初值与轨迹，并说明相图丢失了哪些时间信息。
- **内容顺序**：① 在状态点计算变化方向；② 方向场、相轨迹和平衡；③ 比较不同耦合与初值下的时间图和相图。
- **核心实验**：使用已知线性模型绘制方向场和多初值轨迹，调整坐标尺度，检查图形是否造成误解。
- **练习 E1（选择题）**：给定两张相图和时间标记，从几何路径、运动方向与速度的说法中选择正确项。
- **练习 E2（计算题）**：输入状态点、线性系统矩阵和正的整体倍率，返回原向量场与缩放向量场；在给定轨迹采样点返回相应速度。
- **练习 E3（选择题）**：关闭一个交换通道后，从平衡集合、总量和长期分布的候选结论中选择与题设相符的项。
- **核验与反馈**：E2 保持轨迹的几何路径但改变时间参数化；方向箭头的缩放方式需写明，不能仅靠箭头长度比较速度。

### 3.4 多变量变化与局部线性化

- **直接先修**：3.3；数学：数03、数06、数08。
- **教学目标**：由偏导构建 Jacobian，围绕指定平衡写出一阶近似，并用误差说明局部适用范围。
- **内容顺序**：① 偏导和多变量链式法则；② Taylor 展开与 Jacobian；③ 在二室模型中加入饱和清除，比较局部近似与原模型。
- **核心实验**：清除项取 vA/(K + A)，定义 v 为 U/T、K 为 U；在非负物质量区域比较不同扰动幅度，明确计算域。
- **练习 E1（选择题）**：从饱和清除函数的导数、单位与局部近似表达式中选择正确项，辨认遗漏偏差变量的线性化。
- **练习 E2（计算题）**：按给定二室非线性模型返回指定平衡的 Jacobian 与有限差分检查误差；覆盖小扰动及不同清除参数。
- **练习 E3（计算题）**：输入指定初值组和时间点，按题定方法返回原模型与线性化轨迹及误差指标；判定同时检查模型、形状和误差计算。
- **核验与反馈**：导数应为 vK/(K + A)²；线性化围绕偏差变量书写；不把有限差分一致性当作原模型长期准确性的证明。
