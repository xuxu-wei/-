## 1. 定位、先修与学习目标

从已知模型与观测设计反馈，先讲 PID 和经典稳定性，再进入状态反馈、观测器与 Kalman 滤波。本篇补齐数18 的复平面绕数；Kalman 从条件 Gaussian 推导，LQR 留到第 8 篇优化之后。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 比较反馈表现 | 在跟踪和扰动条件下比较开环与 PID，解释延迟、噪声和执行限制 | PID 计算与频域辨析 |
| T2 判断可施加的影响 | 计算能控性并在满足条件时配置闭环极点 | 能控性选择与反馈计算 |
| T3 判断可恢复的状态 | 区分参数辨识与状态估计，计算能观性并设计观测器 | 能观性选择与估计计算 |
| T4 处理有噪观测 | 推导预测更新，检查协方差并接入反馈 | Kalman 测试和性能辨析 |

## 2. 各章内容、实验与练习

### 7.1 开闭环与 PID

- **直接先修**：6.3、4.5；数学：数03、数09、数16。
- **教学目标**：从误差构造 P、PI、PID，解释积分累积、微分对噪声的敏感性及执行饱和。
- **内容顺序**：① 设定值、测量、误差和执行输入；② 三个控制项及离散实现；③ 跟踪、扰动、饱和与抗积分累积的基本处理。
- **核心实验**：人工温度偏差模型，在相同初值、执行上限与扰动下比较开环、P、PI、PID；给出各控制增益单位。
- **练习 E1（选择题）**：从恒定扰动下 P/PI 的稳态表现及积分作用条件中选择正确项，排除无条件消除误差的说法。
- **练习 E2（计算题）**：按题定离散 PI/PID 与抗积分累积规则返回请求输入、实际输入和积分状态；包含饱和与解除饱和阶段。
- **练习 E3（选择题）**：根据含噪声或延迟的给定响应，选择合理的调参判断及性能代价解释。
- **核验与反馈**：明确离散积分和微分的时间尺度；比较结果包含控制代价、超调和稳态表现，裁剪输入后必须按实际输入推进模型。

### 7.2 频域稳定性与设计

- **直接先修**：7.1；数学：数07、数16、数18。
- **教学目标**：连接闭环极点、根轨迹、Bode、Nyquist 与稳定裕度，说明判据条件及符号约定。
- **内容顺序**：① 从闭环特征方程到根轨迹；② 幅相与裕度；③ 复平面轨迹和绕数的必要几何桥接，再应用 Nyquist。
- **核心实验**：同一低阶线性回路改变增益和延迟，用极点、频域与时域相互核验；第一组例子避免轮廓上有极点的特殊情形。
- **练习 E1（选择题）**：从开环/闭环稳定、增益和延迟的关系中选择成立项，结合给定极点或频响反例判断。
- **练习 E2（计算题）**：对题面限定的低阶回路返回闭环极点和指定频率的幅相；Nyquist 计数约定由题面给定，数值结果与独立多项式核验。
- **练习 E3（选择题）**：给定不同延迟近似阶次的结果，选择可支持的稳定性结论与仍需进行的检查。
- **核验与反馈**：必须固定 Nyquist 的计数约定；裕度只支持所声明模型和回路条件，不能替代非线性饱和系统的完整验证。

### 7.3 能控性与状态反馈

- **直接先修**：7.2、3.2；数学：数06、数07。
- **教学目标**：解释输入位置决定的可达方向，在能控条件下设计状态反馈并检验闭环极点。
- **内容顺序**：① 输入经动态传播到其他状态；② 能控矩阵和秩；③ 极点配置、状态缩放与输入幅度代价。
- **核心实验**：对同一二状态人工系统改变输入位置，保留不能任意配置极点的反例。
- **练习 E1（选择题）**：对 A=[[0, 1], [0, 0]]，分别取 B=[0, 1]ᵀ 与 [1, 0]ᵀ，从能控矩阵、秩和可影响状态方向中选择正确项。
- **练习 E2（计算题）**：输入满足题目条件的二维 A、B 与目标极点，返回反馈 K 和闭环特征值；以极点残差及数值容差判定。
- **练习 E3（选择题）**：给定执行上限和状态转移任务，选择线性能控性可以或不能保证的结论。
- **核验与反馈**：E1 两种秩分别为 2、1；反馈符号约定和 A − BK 的核验一致；近似秩须报告数值容差与尺度。

### 7.4 能观性与状态观测器

- **直接先修**：7.3、6.5；数学：数06、数07、数17。
- **教学目标**：判断已知模型下哪些状态可以从输出恢复，推导观测器误差动态并分析收敛条件。
- **内容顺序**：① 状态估计与参数辨识的任务边界；② 能观矩阵及传感器位置；③ 观测器增益、误差动态与速度/噪声权衡。
- **核心实验**：固定状态模型与输入，只改变观测矩阵；从错误初始估计出发比较恢复过程。
- **练习 E1（选择题）**：对 7.3 的 A，分别取 C=[1, 0] 与 [0, 1]，从能观矩阵、秩及不可恢复方向中选择正确项。
- **练习 E2（计算题）**：给定模型、观测器增益、输入、观测和初始估计，返回估计轨迹与公开核验状态下的误差；两个误差指标分别输出。
- **练习 E3（选择题）**：从二室传感器方案中选择满足指定能观条件的项，并区分已知参数下的状态恢复与参数辨识。
- **核验与反馈**：E1 两种秩分别为 2、1；只有课程已知状态作为隔离核验答案时，才能直接报告完整状态误差。

### 7.5 Kalman 滤波与估计反馈

- **直接先修**：7.4、5.3；数学：数06、数11、数12。
- **教学目标**：由线性 Gaussian 条件更新推导均值和协方差递推，区别过程噪声与测量噪声的作用。
- **内容顺序**：① 动态预测及协方差传播；② 观测更新与 Kalman 增益；③ 接入状态反馈，比较真实状态、估计状态与错误噪声设定。
- **核心实验**：部分观测的离散线性偏差模型，记录创新、状态误差和协方差；已知状态只供独立评估。
- **练习 E1（选择题）**：标量先验均值 0、方差 4，观测为 2、观测系数 1、测量方差 1，选择更新增益、均值和方差及含义；解析参考为 0.8、1.6、0.8。
- **练习 E2（计算题）**：输入线性模型、噪声协方差、观测和缺测标记，返回 Kalman 均值与协方差序列；测试缺测时只预测及协方差性质。
- **练习 E3（选择题）**：根据缺测、噪声设定错误和估计反馈的对照结果，选择性能与不确定性的有效解释。
- **核验与反馈**：E1 结果为 0.8、1.6、0.8；协方差保持对称且在容差内半正定，已知无噪极限单独处理；理想线性条件下的性质不直接扩展到饱和和错误模型。

## 3. 篇末综合任务：部分观测下的估计反馈题组

给定人工调节模型、执行位置和传感器候选。选择题检查能控/能观条件、设计假设与失效解释；Python 题计算反馈、观测器或 Kalman 更新，并返回跟踪、扰动和输入指标；用对照结果选择有效性能结论。

覆盖 T1—T4；完整状态只在明确标记的参考条件中使用，题面和判定器均区分额外信息与可实施策略。各子题独立提交和判定；全部必做题通过后记为本版本题组完成。具体格式与发布要求见[客观题评价规范](教材设计.md#assessment-design)和[判题系统设计](交互练习与判题系统设计.md)。
