# 第 6 篇：从测量走向模型

本文为篇章大纲，教学内容尚待实施。章号、数学与参考编号见[教材设计](教材设计.md#part-06)，实施与验收见 [M7](../ROADMAP.md#milestone-m7)。前篇：[05-随机性与信息](05-随机性与信息.md)；后篇：[07-反馈、估计与控制](07-反馈、估计与控制.md)。

本篇全部习题只使用选择题和提交 Python 代码的计算题。E1—E3 仅是维护者记录概念、实现和迁移出题方向的索引，不向学生展示。每节配置 3—5 道题，重难点优先 4—5 道；本大纲的章级三条设计不限制最终题量。选择题提交后显示判定与逐项解析，计算题在本机教材 Python 子进程中按公开契约运行判定，作答以 JSON 文件记录。核心实验是 Notebook 讲解与演示内容，核验提示用于标准答案和程序测试，不增加报告或自由文本提交。规则见[本地判题系统设计](交互练习与判题系统设计.md)；每章均有独立网页和练习入口，页面及 Notebook 图表共同遵循[网页与图表设计规范](网页设计规范.md)。

## 1. 定位、先修与学习目标

把观测过程与动态模型分开，连接时域、频域、参数估计和实验设计。本篇首次建立数15—数17；高级优化算法不作为先修，简单估计先用线性代数或明确范围内的网格比较。

| 目标 | 学完能够完成的动作 | 对应证据 |
|---|---|---|
| T1 分析测量影响 | 解释采样、滤波与有限记录如何改变可见信号 | 采样函数与观测解释选择题 |
| T2 转换系统表示 | 连接状态方程、卷积、传递函数与连续/离散响应 | 表示转换选择及计算题 |
| T3 估计并验证参数 | 写出残差与误差假设，给出参数及有条件的不确定性估计 | 参数估计与误差假设题 |
| T4 判断可辨识范围 | 按时间或个体划分数据，比较激励和结构，报告不能确定的参数 | 划分、预测及验证题组 |

## 2. 各章内容、实验与练习

### 6.1 观测、采样与滤波

- **直接先修**：5.2、2.4；数学：数02、数05、数11。
- **教学目标**：区分模型时间步长、采样间隔与滤波窗口，识别混叠和滤波延迟。
- **内容顺序**：① 状态到观测及采样；② 用正弦例子观察混叠；③ 移动平均、窗口边界和在线/离线差别。
- **核心实验**：对人工节律在不同时间点采样，比较因果移动平均和居中平均；明确后者使用未来观测。
- **练习 E1（选择题）**：从求解步长、观测采样间隔和滤波窗口的作用中选择正确项，辨认“细化求解必然消除混叠”。
- **练习 E2（计算题）**：对给定采样时间和频率返回余弦样本，并实现题定因果移动平均；公开例比较整数时刻的 0.2 与 0.8 周期/T。
- **练习 E3（选择题）**：从在线节律监测候选方案中选择不读取未来数据且正确说明延迟代价的方案。
- **核验与反馈**：E2 在给定采样时刻无法区分；滤波效果同时报告噪声变化与时间偏移，禁止在在线任务中悄悄使用未来值。

### 6.2 卷积、频谱与频率响应

- **直接先修**：6.1、3.2；数学：数03、数07、数15。
- **教学目标**：从叠加解释卷积，理解复指数、频率坐标、幅度和相位，并辨认有限记录的影响。
- **内容顺序**：① 脉冲响应与离散卷积；② 正弦、复指数与 Fourier 表示；③ 频谱、窗长、泄漏及滤波频率响应。
- **核心实验**：同一有限信号分别显式求和卷积与使用库函数计算；对整周期和非整周期记录比较频谱。
- **练习 E1（选择题）**：对输入 [1, 2, 0] 与核 [1/2, 1/2]，从完整线性卷积、长度与端点含义中选择正确项，区分循环卷积。
- **练习 E2（计算题）**：按题定归一化计算有限序列的频率坐标、幅值和相位；补充测试改变记录长度、采样率与整周期条件。
- **练习 E3（选择题）**：根据给定双频信号与滤波频率响应，选择受抑制成分及有效解释，辨认把补零当新增观测信息。
- **核验与反馈**：E1 结果为 [0.5, 1.5, 1, 0]；避免把循环卷积与线性卷积混用，不把补零解释为增加独立观测信息。

### 6.3 LTI 系统、Laplace 与 Z 变换

- **直接先修**：6.2；数学：数04、数15、数16。
- **教学目标**：在明确初值和线性时不变假设下连接微分/差分方程、传递函数、极点与响应。
- **内容顺序**：① 线性与时不变的检验；② Laplace 变换、必要收敛域直觉及初值项；③ Z 变换和离散表示，与状态空间对照。
- **核心实验**：对单室清除比较连续解析响应、状态空间计算和离散模型；区别精确采样模型与 Euler 近似。
- **练习 E1（选择题）**：从单室模型的传递函数、初值项和 LTI 假设中选择正确表达及适用条件。
- **练习 E2（计算题）**：输入 k、h、初值和步数，返回精确采样与 Euler 两种无输入衰减轨迹；覆盖零清除及大步长。
- **练习 E3（选择题）**：对饱和清除和时变系数的候选模型，选择失效的 LTI 假设与可采用的局部解释。
- **核验与反馈**：E2 因子分别为 exp(−kh) 与 1 − kh；不同离散化不能因使用相同采样间隔就被当作同一模型。

### 6.4 最小二乘与参数估计

- **直接先修**：5.3、3.4、6.1；数学：数06、数11、数12、数17。
- **教学目标**：定义残差和损失，说明最小二乘与 Gaussian 误差的关系，并为区间估计写明假设。
- **内容顺序**：① 线性回归、投影和秩；② 理想清除参数的拟合与残差；③ 重复观测、参数区间和重采样入门，区分参数不确定性与预测误差。
- **核心实验**：先做有独立测量误差的线性例子，再对给定初值的清除曲线在限定参数网格上拟合；不把带噪差分当作无误差变化率。
- **练习 E1（选择题）**：从 Gaussian 误差、平方残差和似然的对应关系中选择成立项，区分异方差与对数变换的假设。
- **练习 E2（计算题）**：输入题设清除观测、候选参数网格和误差模型，返回最小残差参数与验证残差；并列最优按公开规则处理。
- **练习 E3（选择题）**：给定独立重复与时间相关残差两种数据，选择有效的区间/重采样方案及不能解释的误差来源。
- **核验与反馈**：简单线性例子用已知参数和代数参考核验；报告区间方法、假设和重复次数，不把区间宽度当作所有模型误差的总和。

### 6.5 动态辨识、实验设计与验证

- **直接先修**：6.3、6.4；数学：数16、数17。
- **教学目标**：构建简单 ARX 模型，区分拟合、一步预测和自由运行，比较激励、结构与可辨识范围。
- **内容顺序**：① 回归量、延迟与动态模型；② 输入激励、结构选择和参数混淆；③ 时间/个体划分、验证残差、外推与缺失观测。
- **核心实验**：比较常量与变化输入下的同一理想系统；固定训练、验证和最终评估边界，预处理只从训练数据估计。
- **练习 E1（选择题）**：只有稳态观测时，选择 u、k 和 u/k 可辨识性的正确结论，以及能打破混淆的候选激励方案。
- **练习 E2（计算题）**：给定已固定的 ARX 参数、训练后观测和输入，返回一步预测与自由运行序列；补充测试检查索引与未来信息泄漏。
- **练习 E3（计算题）**：按时间/个体边界生成训练与验证索引，并返回指定回归矩阵的秩及模型评估量；测试包括缺失观测与范围外输入。
- **核验与反馈**：提交数据划分清单和回归矩阵的秩检查；已知核验参数与状态只能在评估时读取，不能作为拟合输入或调参答案。

## 3. 篇末综合任务：测量、辨识与验证题组

提供已验收的单室或二室部分观测及指定候选模型。选择题检查采样、误差假设、激励与可辨识性；Python 题实现数据划分、参数估计、一步预测、自由运行和评价函数；解释选择题转换为对验证结论的选择。

覆盖 T1—T4；预处理和拟合输入不含核验答案，固定测试检查泄漏、索引与数值结果，不上传分析报告。

本篇综合题组按以下八题设计，具体题面与测试随本篇交付。统一计分、等级、首次与练习成绩的区别见[篇末分层评分](教材设计.md#capstone-assessment)；这里仅维护本篇任务分配。

| 层次 | 子题与分值 | 形式 | 主要计分目标 | 核验与反馈重点 |
|---|---|---|---|---|
| 1 基础辨析 | 1. 采样改变了什么（10 分） | 选择 | T1 | 辨认采样、滤波和有限记录的影响。 |
| 1 基础辨析 | 2. 哪些激励有助于辨识（10 分） | 选择 | T4 | 区分拟合改善与参数可辨识。 |
| 2 方法应用 | 3. 连接表示与离散响应（15 分） | Python | T2 | 给定小系统计算卷积或指定离散响应。 |
| 2 方法应用 | 4. 参数估计与残差（15 分） | Python | T3 | 拟合固定候选模型并计算残差，限定误差假设。 |
| 3 综合验证 | 5. 划分数据并隔离预处理（15 分） | Python | T4 | 按时间或个体生成训练/验证索引，防止泄漏。 |
| 3 综合验证 | 6. 一步预测与自由运行（15 分） | Python | T3 | 给定已拟合参数独立计算两类误差。 |
| 4 迁移挑战 | 7. 更换采样率后的响应（10 分） | 选择 | T2 | 连接连续/离散表示及观察条件，选择有效转换。 |
| 4 迁移挑战 | 8. 换激励后的验证结论（10 分） | 选择 | T4 | 结合新数据、残差与参数歧义判断可支持的结论。 |

主要计分目标按上表归属，相关知识可跨目标；每题输入完整，独立提交。未通过题按层次回到对应目标的章节复习；本表不调整章内习题。
