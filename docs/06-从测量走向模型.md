## 2. 各章内容、实验与练习

### 6.1 观测、采样与滤波

- **直接先修**：5.2、2.4；数学：数02、数05、数11。
- **教学目标**：区分模型时间步长、采样间隔与滤波窗口，识别混叠和滤波延迟。
- **内容顺序**：① 状态到观测及采样；② 用正弦例子观察混叠；③ 移动平均、窗口边界和在线/离线差别。
- **核心实验**：对人工节律在不同时间点采样，比较因果移动平均和居中平均；明确后者使用未来观测。
- **练习 E1（选择题）**：从求解步长、观测采样间隔和滤波窗口的作用中选择正确项，辨认“细化求解必然消除混叠”。
- **练习 E2（计算题）**：对给定采样时间和频率返回余弦样本，并实现题定因果移动平均；公开例比较整数时刻的 0.2 与 0.8 周期/T。
- **练习 E3（选择题）**：从在线节律监测候选方案中选择不读取未来数据且正确说明延迟代价的方案。
- **核验与反馈**：E2 在给定采样时刻无法区分；滤波效果同时报告噪声变化与时间偏移，禁止在在线任务中悄悄使用未来值。

### 6.2 卷积、频谱与频率响应

- **直接先修**：6.1、3.2；数学：函数、求和与向量。复数、复指数、卷积及 Fourier 表示在本章首次引入。
- **数学索引**：数03、数07、数15。
- **教学目标**：从叠加解释卷积，理解复指数、频率坐标、幅度和相位，并辨认有限记录的影响。
- **内容顺序**：① 脉冲响应与离散卷积；② 正弦、复指数与 Fourier 表示；③ 频谱、窗长、泄漏及滤波频率响应。
- **核心实验**：同一有限信号分别显式求和卷积与使用库函数计算；对整周期和非整周期记录比较频谱。
- **练习 E1（选择题）**：对输入 [1, 2, 0] 与核 [1/2, 1/2]，从完整线性卷积、长度与端点含义中选择正确项，区分循环卷积。
- **练习 E2（计算题）**：按题定归一化计算有限序列的频率坐标、幅值和相位；补充测试改变记录长度、采样率与整周期条件。
- **练习 E3（选择题）**：根据给定双频信号与滤波频率响应，选择受抑制成分及有效解释，辨认把补零当新增观测信息。
- **核验与反馈**：E1 结果为 [0.5, 1.5, 1, 0]；避免把循环卷积与线性卷积混用，不把补零解释为增加独立观测信息。

### 6.3 LTI 系统、Laplace 与 Z 变换

- **直接先修**：6.2；数学：微积分与复指数。Laplace/Z 变换、收敛域和极点在本章首次引入。
- **数学索引**：数04、数15、数16。
- **教学目标**：在明确初值和线性时不变假设下连接微分/差分方程、传递函数、极点与响应。
- **内容顺序**：① 线性与时不变的检验；② Laplace 变换、必要收敛域直觉及初值项；③ Z 变换和离散表示，与状态空间对照。
- **核心实验**：对单室清除比较连续解析响应、状态空间计算和离散模型；区别精确采样模型与 Euler 近似。
- **练习 E1（选择题）**：从单室模型的传递函数、初值项和 LTI 假设中选择正确表达及适用条件。
- **练习 E2（计算题）**：输入 k、h、初值和分段恒定输入，返回精确采样与 Euler 两种轨迹；覆盖零清除及大步长。
- **练习 E3（选择题）**：对饱和清除和时变系数的候选模型，选择失效的 LTI 假设与可采用的局部解释。
- **核验与反馈**：E2 因子分别为 exp(−kh) 与 1 − kh；不同离散化不能因使用相同采样间隔就被当作同一模型。

### 6.4 最小二乘与参数估计

- **直接先修**：5.3、3.4、6.1；数学：矩阵、偏导、概率与似然。最小二乘、估计区间及重采样在本章首次引入。
- **数学索引**：数06、数11、数12、数17。
- **教学目标**：定义残差和损失，说明最小二乘与 Gaussian 误差的关系，并为区间估计写明假设。
- **内容顺序**：① 线性回归、投影和秩；② 理想清除参数的拟合与残差；③ 重复观测、参数区间和重采样入门，区分参数不确定性与预测误差。
- **核心实验**：先做有独立测量误差的线性例子，再对给定初值的清除曲线在限定参数网格上拟合；不把带噪差分当作无误差变化率。
- **练习 E1（选择题）**：从 Gaussian 误差、平方残差和似然的对应关系中选择成立项，区分异方差与对数变换的假设。
- **练习 E2（计算题）**：输入题设清除观测、候选参数网格和误差模型，返回最小残差参数与验证残差；并列最优按公开规则处理。
- **练习 E3（选择题）**：给定独立重复与时间相关残差两种数据，选择有效的区间/重采样方案及不能解释的误差来源。
- **核验与反馈**：简单线性例子用已知参数和代数参考核验；报告区间方法、假设和重复次数，不把区间宽度当作所有模型误差的总和。

### 6.5 动态辨识、实验设计与验证

- **直接先修**：6.3、6.4；数学：数16、数17。
- **教学目标**：构建简单外源输入自回归模型，区分拟合、一步预测和自由运行，比较激励、结构与可辨识范围。
- **内容顺序**：① 回归量、延迟与动态模型；② 输入激励、结构选择和参数混淆；③ 时间/个体划分、验证残差、外推与缺失观测。
- **核心实验**：比较常量与变化输入下的同一理想系统；固定训练、验证和最终评估边界，预处理只从训练数据估计。
- **练习 E1（选择题）**：只有稳态观测时，选择 u、k 和 u/k 可辨识性的正确结论，以及能打破混淆的候选激励方案。
- **练习 E2（计算题）**：给定已固定的 ARX 参数、训练后观测和输入，返回一步预测与自由运行序列；补充测试检查索引与未来信息泄漏。
- **练习 E3（计算题）**：按时间/个体边界生成训练与验证索引，并返回指定回归矩阵的秩及模型评估量；测试包括缺失观测与范围外输入。
- **核验与反馈**：返回数据划分索引并检查回归矩阵的秩；已知核验参数与状态只能在评估时读取，不能作为拟合输入或调参答案。

### 6.6 递推辨识与时变参数跟踪

- **直接先修**：6.5；数学：数06、数17、数29。
- **教学目标**：从批量最小二乘推导递推更新，比较遗忘因子、激励和参数漂移对估计的影响，限定不确定性解释。
- **内容顺序**：①由累计信息矩阵和正规方程引入矩阵秩一更新，先推导无遗忘的递推最小二乘（recursive least squares，RLS）；②加入遗忘因子、初始正则项和在线时钟，区分先预测后更新与读取未来观测；③比较固定参数、缓慢漂移与激励不足；区分逆信息矩阵与参数估计协方差。
- **核心实验**：对同一人工清除回归分别使用恒定参数和分段漂移参数，给定相同输入与噪声；逐时比较批量解、递推解、预测误差和信息矩阵，验证区间与最终评估时段分开。
- **练习 E1（选择题）**：选择无遗忘递推与带相同初始正则项批量解等价的条件，辨认把逆信息矩阵直接当作所有场景的参数协方差。
- **练习 E2（计算题）**：输入回归向量序列、观测、初始参数、初始逆信息矩阵与遗忘因子，返回每步更新前预测、参数和逆信息矩阵；包括空序列、零回归向量与弱激励。
- **练习 E3（选择题）**：根据漂移、噪声增大和输入激励不足的配对结果，选择遗忘因子的作用及不能支持的参数收敛结论。
- **核验与反馈**：遗忘因子等于 1 时与逐步扩大的正则化批量问题比较；小于 1 时与同一初始权重衰减规则的加权问题比较。无正则、固定满秩设计和独立同方差误差下，参数协方差为误差方差乘逆信息矩阵；有限初始正则、遗忘加权或闭环相关误差下须重新推导协方差，不能直接沿用该式。若采用高斯先验解释初始矩阵，须明确与频率学派协方差的区别；完整后验学习留到 9.1。不以跟踪改善替代参数一致性。
- **编写参考**：R04、R10、R30（资料与主题对应见本篇末表）。

- 采样间隔、求解步长和窗口长度分别定义；有限含噪记录不等于理想带限信号的无限精确重建。
- 6.1 的因果均值在启动段按已有点数归一；6.2 固定 FIR 及网页采用零延拓、始终除 W，不能混用其起始响应。频响仅解释满窗口后的正弦稳态；零增益相位未定义，题目返回 0 只是明示标记。
- DFT 明确符号、频率单位、归一化、奇偶长度和相位端点；补零不增加独立观测，窗函数以主瓣变宽换取旁瓣变化。
- 传递函数限定零状态，非零初态响应单列；精确零阶保持与 Euler 区分，包含 k=0、正性、幅度稳定性三个不同检查。
- 最小二乘先讲正交和秩，再讲高斯误差对应；未知正方差的有限联合最大似然解还要求最小平方残差和大于零。有限网格最优、参数区间、预测误差不互相替代。
- 6.4.3 的已知噪声覆盖实验用固定设计与 200 组独立误差，成对自助实验用 300 次整行重抽样；生成器、种子、样本量和蒙特卡洛误差在 Notebook 中声明，时间相关记录不能照搬独立行重抽样。
- ARX 只在明确回归量和噪声假设下解释拟合；一步预测读取上一观测，自由运行只读取段起点。常量输入有瞬态时也可能满秩；同一稳态重复不能增加独立回归方向。已知非零 u 时 A*=u/k 可确定 k；u、k 都未知或存在未知输入增益时需另论。
- 拟合与预处理只读取训练信息；按未来时段或新个体选择划分目标，缺测保留时钟，验证选结构后再作最终评估。内存实验与核验参照分离，不增加外部生成器依赖。
- 6.6.1 从固定中心正则目标、正规方程和秩一更新乘法检验推导 RLS；有限正则不能与无正则批量解混比。P 只称逆信息矩阵；固定设计、固定中心的抽样协方差单独推导，以 2000 组独立误差核对标量公式。
- 6.6.2 的初始项按 λⁿ 衰减，逐前缀核验无遗忘与指数加权批量问题；弱激励方向的信息流失与参数识别分开。代码以对称外积更新 P，避免两个三角部分采用不同运算顺序；这不代替长期病态情形的数值稳定性分析。
- 6.6.2 调参时段为索引 80—139，最终在线评估为 140—199，候选因子先固定。每拍先预测、再读取目标、记误差并更新；评估目标可以影响之后的预测，不能影响自身评分或因子选择。冻结参数或无反馈外推须另设评估协议。
